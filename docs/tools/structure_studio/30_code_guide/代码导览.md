# 代码导览

实现根目录：`E:\Mod_Dev\StructureBinder\tools\structure_studio`。

| 入口 | 职责 |
| --- | --- |
| `cli.py`、`start.ps1` | 准备本地资源、检查资产、启动只读服务。 |
| `studio/model.py` | 显式体素与语义建模、确定性 NBT 导出、重新读取产物。 |
| `studio/resources.py` | 从已有 1.20.1 client.jar 构建本地材质图集和模型缓存。 |
| `scripts/export_registry.mjs` | 从固定版本 minecraft-data 导出方块状态及碰撞盒。 |
| `studio/validate.py`、`studio/navigation.py` | 数据、标记与步行初筛；不调用游戏。 |
| `studio/server.py` | 枚举本库原创模型与夹具，受目录限制的只读 HTTP 接口。 |
| `web/main.js`、`web/style.css` | Deepslate WebGL 查看、切片、标记、相机和导航。 |
| `scripts/capture.mjs` | Playwright 截图；渲染错误与缺纹理导致失败。 |
| `studio/samples.py` | 当前兼容性夹具和面包铺的作者源码。 |
| `studio/build.py`、`studio/transport.py`、`studio/agriculture.py` | 按编号与结构族重建，交通核心与农田变体的显式作者平面。 |
| `studio/shops.py` | 不同行业商铺的独立平面、陈列、后勤与生活空间；部件共享不替代变体设计。 |
| `studio/desert.py` | 沙海公共与历史设施：内庭商旅、地下储水、交易、医疗、观测、积沙遗址与旧井；各自记录实际平面与环境。 |
| `studio/oasis_life.py` | 风塔住宅与绿洲灌溉田的独立变体；覆盖户数、楼层、转角、台地和渠旁条件，共用风塔明确打通屋顶接口。 |
| `studio/oasis_yards.py` | 兽栏、葡萄棚与货摊各四种，分别设计牵引、护理、采收、交易和寄货空间；原版视觉表达不声明作物或活体行为已接入。 |
| `studio/oasis_crafts.py` | 商人庭院宅与玻璃工坊各四种，区分会客与家居、原料与成品、操作与维护；包括转角院、双庭、楼院及高差分台。 |
| `studio/oasis_hospitality.py` | 四种旅人客栈与八种绿洲商铺，包含登记、餐饮、客房、盥洗、修补及各行业设备；窄巷、转角、内院、两层和分台分别设计。 |
| `studio/waterway.py` | 造船坞、船闸管理所、港口海关、水利会馆、旧泵房和旧水神庙；生产、贸易、水务和历史用途各自安排内饰及标记，岸线与高差单独记录。 |
| `studio/waterway_trade.py` | 四种临水货栈与四种沿河商住楼；按窄岸、双层、贯通巷、围院、街角和阶岸条件分别制作货运与家居空间，使用水网自有连续承檐构件。 |
| `studio/mountain_forge.py` | 山腹矿运、提升、锻炉、行会、纪念、旧矿口与排水核心；石台、矿道及高差分别设计，设备为静态原版几何。 |
| `studio/forest_symbiosis.py` | 森林档案、兽驿、议事、市集、学堂及历史核心；林隙、根盘、房间与树旁通路分别建模和标记。 |
| `studio/cloud_navigation.py` | 泊塔、船库、导航、气象、议事与历史核心；台地柱梁、连续外阶护栏及交通接驳分别核对，不提供飞行或浮空机制。 |
| `studio/mountain_life.py` | 六种矿工宿舍与六种工匠住宅；按多人、独室、院落和双层分别组织生活、工位与连续楼梯护栏。 |
| `studio/mountain_trade.py` | 宝石商行、矿料仓与炉边酒馆各四种，以及八种行业商铺；区分检验、原料、加工、陈列、寄存和生活后勤。 |
| `studio/mountain_outside.py` | 六种山地田与四种矿业配套棚；按梯台、窄地、温室及存料维修条件布置生产设施。 |
| `studio/forest_life.py` | 树根住宅与守林居所各六种；根盘旁通路、分户睡眠、厨房餐席、读写及家务空间随布局分别标记。 |
| `studio/forest_crafts.py` | 菌菇、药草、蜂蜜工坊各四种与八种林间商铺；原料、分拣、加工、交易和店主生活分区。 |
| `studio/forest_gardens.py` | 六种林间田、四种藤架与四种工具棚；保持根盘、采收路径及组装、晾材、药材分拣和维修发料工位。 |
| `studio/cloud_living.py` | 六种悬臂住宅、六种船员宿舍和四种旅店；稳定岩台支撑、外阶、客房与生活内饰分别设计。 |
| `studio/cloud_food.py` | 四种温室、六种台地田及四种棚亭；种植、灌溉、收获和避风休憩按台地条件标记。 |
| `studio/cloud_market.py` | 四种航运仓与八种商铺； 货运通道、行业操作台、陈列交易与商住后勤分开布置。 |
| `studio/arcane_academy.py` | 传送驿站、检疫、晶核配给、学院、卷藏与两处专项；隔离、教学、研究与驻守空间分别标记，传送及供能为静态表达。 |
| `studio/arcane_gardens.py` | 六种灌溉试验田、四种藤架与四种研究配套棚；独立构建，保留种植、观测、存放和检校站位。 |
| `studio/steppe_caravans.py` | 大帐集市、议事家帐、祖灵石阵、旧营遗存及山口营；圆帐、货车侧带、仪式场和通路视野分别设计。 |
| `studio/northern_seafarers.py` | 船屋、浴屋、史诗会堂与补给、回收、海防专项；岸线、风雪遮蔽、高差及维修生活分别设计。 |
| `web/site.js` | 与 NBT 分离的平地、岸线、微坡和两级航道条件示意，支持可选地表材质；不覆盖显式 air。 |
| `studio/publish.py` | 实际看图后填写审查记录，核对证据版本和检查结果，再归档已验收资产。 |

`package-lock.json` 固定 JavaScript 依赖；本机 `.cache/`、`dist/`、`node_modules/`、`runtime/` 不提交。模型本体、作者说明和筛选后的验收证据随资产提交。
