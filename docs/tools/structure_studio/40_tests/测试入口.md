# 测试入口

在 `E:\Mod_Dev\StructureBinder\tools\structure_studio` 执行：

```powershell
node scripts/export_registry.mjs
python -m unittest discover -s tests -v
node --test tests/site.test.mjs
node --test tests/filters.test.mjs
npm.cmd run build
python -m studio.samples
python cli.py validate SR-F01-v01
python -m studio.build SR-01 WT-01 SR-F02
```

Python 测试覆盖确定性 NBT 回读、显式 air 与方块实体、非法状态、重复坐标、门床缺半、过期标记哈希、作者角色缺失或非法取值、封闭房间、正常楼梯及低顶阻挡、杜鹃非法底座与合法土壤。角色测试回读已导出的作者 JSON，分别核对五种合法身份与 special/landmark/filler 等错误值；不以角色取值通过代替语义审查。预览验收先按实现仓 README 启动本地服务，再运行：

```powershell
npm.cmd run capture -- SR-F01-v01
node scripts/smoke.mjs
node scripts/filter-smoke.mjs
```

验证至少包括四向外观、俯视、去屋顶、各楼层、房间和标记。实际查看 PNG，发现问题回到建模源码修改并重导出。记录当前产物哈希和对应结论；**截图脚本不得自动把资产判为审美通过**。

`tests/filters.test.mjs` 检查功能层级无环、父子匹配方向、全部／任一组合、风格与原始标签交集、选址文字排除推荐情境、遗址不冒充现役能力、未知词保留检索以及 URL 往返；以当前 498 个作者资产验证归类覆盖及实际组合。`scripts/filter-smoke.mjs` 在浏览器实际操作下拉、组合切换、空结果、清空、详情标签点击、切换模型和刷新，检查桌面及窄屏布局并保留 `runtime/filter-review-*.png`。没有 Playwright 自带浏览器时，可将 `STUDIO_CHROMIUM` 指向本机 Chromium/Chrome/Edge 可执行文件；`STUDIO_URL` 可指定其他本地服务端口。这是筛选界面与预览回归，不重新批准资产图审。

坡屋顶另按实际墙线和柱线检查承托：外挑一格后内侧屋面的高程已经变化，墙顶与屋面之间需连续承檐构件；半砖区分上下半接触。高台楼梯应核对侧栏及栏下支撑。远景截图或可达性通过不能代替这些局部剖面复核。

Python 增加最终 NBT 作物/耕地/水源检查的反例测试；浏览器 smoke 同时核对地形示意改变画面但不修改模型数据，以及切换模型后清理展示状态。

`tests/site.test.mjs` 覆盖上下游参考水位、模型前后航道延伸与两岸边界、作者方块及显式 air 不被覆盖、非法航道范围/水位拒绝，以及原有岸线兼容。浏览器 smoke 同时加载 WT-04 船闸，核对航道示意确实改变画面且模型数据不变。该检查不证明流体或船闸运行。

商住、交通、农业和沙海资产不代表全部清单完成；各文明清单保留真实逐项进度。运行时导入、实际地形生成、红石和模组逻辑不在离线测试结论中。

文件替换回归用例模拟目标不可替换，验证旧报告完整保留、临时文件清除且错误向调用者传播；随后恢复替换并核对新 JSON 内容。NBT、JSON 与归档截图共用同目录临时写入后替换的方法，单文件完成不代表整个资产批次全部成功。
