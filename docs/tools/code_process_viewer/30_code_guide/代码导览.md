# Code Process Viewer 代码导览

实现位于 StructureBinder 仓库顶层 `code_process_viewer/`，是独立 Go module。

| 路径 | 职责 |
| --- | --- |
| `cmd/code_process_viewer/main.go` | CLI、默认路径、SQLite/cache 初始化和 `:6657` HTTP 服务。 |
| `internal/importer/jigsawdebug/` | 读取 trace、legend、preview，规范化为 session bundle。 |
| `internal/session/` | 会话、节点、边、表格、review 模型和 Markdown 报告。 |
| `internal/storage/` | SQLite schema、导入事务、review 保留和 JSON cache。 |
| `internal/httpapi/server.go` | 当前 API 与静态资源路由。 |
| `web/` | 内嵌单页工作台。 |
| `runtime/db` / `runtime/cache` | 本地数据库和预览/会话缓存。 |

当前只支持 Jigsaw debug importer，不触发 `city_jigsaw_solve`，不实时刷新，不做多用户权限。修改 trace importer 时同步 `importer_test.go`；修改 SQLite/review/cache 时同步 `storage_test.go`；修改 API 时同步 `20_contracts/HTTP接口.md`。
