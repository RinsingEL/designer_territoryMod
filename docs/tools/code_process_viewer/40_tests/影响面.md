# Code Process Viewer 当前影响面

工具只读取已有 `jigsaw_solver_debug/<runId>`，并写自身 SQLite、cache、review 和导出报告。它不介入求解执行，不修改源 artifact，不影响 City active fixed-template 路径。

| 模块 | 影响 |
| --- | --- |
| importer | trace 字段、步骤映射、preview/legend 缺失处理。 |
| storage | sessions、nodes、edges、tables、source refs、checkpoints、reviews、imports 和重导入保留。 |
| HTTP/UI | 会话图、节点详情、表格、审查保存、报告和静态资源。 |
| runtime | `runtime/db` 与 `runtime/cache` 本地数据。 |

主要风险是旧 Jigsaw trace 漂移、重复导入覆盖、预览路径越界和无鉴权局域网暴露。新增其他过程源、实时刷新、会话比较或多人权限都不属于当前实现。
