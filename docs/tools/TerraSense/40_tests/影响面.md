# TerraSense 当前影响面

TerraSense 负责结构扫描、截图、AI 初标、人工审核和静态导出。它是独立工具，不参与 City runtime worldgen，也不再提供 configured/Jigsaw 几何或统计 envelope 作为 City active path 真值。

| 边界 | 当前影响 |
| --- | --- |
| Forge scanner | 样本类型、放置命令、硬事实、截图时序和 workspace 写入。 |
| Studio | vocabulary、AI suggestion、review、导入 zip 和本地文件 API。 |
| exporter | v0.2 source/report/vocabulary schema，official/debug/binder 准入和 skip reason。 |
| StructureBinder | 只可能消费冻结的结构语义 profile；NBT 几何仍由当前世界模板读取。 |

当前最高风险是 binder 字段不兼容：TerraSense 的 `terrainTerms` 与 StructureBinder 的 `terrainModes` 尚未统一。其次是 AI 初标未经人工审核、样本类型误用、绝对/相对路径漂移，以及把 debug/official configured 产物误当 fixed-template 正式目录。

任何 exporter 字段或 source schema 变化都需要同步 TerraSense exporter 测试、StructureBinder importer 测试和本目录契约。扫描 UI、截图样式等不影响消费字段的实现修补，只更新 TerraSense 自身测试记录，不扩大到 City 契约。
