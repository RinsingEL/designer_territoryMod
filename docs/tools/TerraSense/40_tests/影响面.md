# TerraSense 影响面

## 当前状态（2026-05-11）

TerraSense 结构策展工具按 v1-v3 功能包记录为已完成。本影响面后续重点不再是补齐工具本体，而是跟踪 TerraSense 导出产物进入 StructureBinder / City 结构目录查询、envelope profiling、D4 候选与当前 D6/worldgen 落地主链后的影响。

## 结构策展工具

- 影响模块
  - TerraSense 结构扫描、自动样本产出、截图、AI 初标、人工审核、导出。
  - TerraSense Studio 本地工作台。
  - StructureBinder / City 结构画像导入与查询。
  - StructureBinder / City envelope、D4 候选与当前 D6/worldgen 消费链路。
- 影响接口与产物
  - `ScanWorkspace`
  - `scan_manifest.json`
  - `scan_index.json`
  - `scan_config.json`
  - `data.json`
  - `ai_suggestion.json`
  - `review.json`
  - `StructureCurationExport`
  - `StructureProfile.jsonl`
  - `TerraSenseStructureProfileSource.official.json`
  - `debug_structure_profile_catalog.json`
  - `functionTerms` / `planningRoleTerms` / `styleTerms` / City 固定 `terrainModes`
- 上下游影响
  - 上游依赖结构 mod/datapack 和 MC runtime template 数据。
  - 下游影响 D4 anchor / array 候选、D6 probe-and-lock、worldgen placement 和 ledger。
- 剩余风险
  - 旧名字关键词 catalog、`C3_5` 兼容 catalog、`function_candidates` 或 `functionTags` 若继续被使用，会重新掩盖语义错误，必须视为阻断项。
  - AI 初标可能幻觉，必须人工审核。
  - jigsaw orientation 不能压扁成 facing，否则会污染 C8 求解。
  - 若导出格式与 StructureBinder catalog 不兼容，标注无法闭环。
  - 尚未可信重标记的固定模板允许规划角色和地形要求为空；不得用结构名或已退役 placement term 自动猜值。
  - 客户端截图链路受渲染、窗口和文件写入时序影响，必须保留 mock/硬事实测试入口作为稳定验收兜底。

## MC 自动测试环境

- 影响模块
  - TerraSense Forge 客户端命令或自动测试入口。
  - 结构放置、摄影场清理、相机控制和截图输出。
  - runtime jigsaw 读取和 connector 派生逻辑。
  - `structure_assembly` 完整 configured structure 样本的命令放置、包围盒扫描和命令锚点偏移记录。
  - `jigsaw_assembly` 底层拼图系统样本的命令放置、包围盒扫描和命令锚点偏移记录。
  - `/ts_jigsaw_ui` 从 template pool registry 批量选择 start pool，复用 `jigsaw_assembly` 队列和 workspace 写出契约。
- 影响接口与产物
  - `scan_manifest.json`
  - `structures/<safe_structure_id>/data.json`
  - `structures/<safe_structure_id>/scan_config.json`
  - `structures/<safe_structure_id>/screenshots/front.png`
  - `structures/<safe_structure_id>/screenshots/right.png`
  - `structures/<safe_structure_id>/screenshots/top.png`
  - `structures/<safe_structure_id>/screenshots/iso_45.png`
  - `placement_command`
  - `footprint.origin_offset`
  - `placement.command_anchor`
  - `placement.command_anchor_offset`
  - `assembly.command_anchor_world_pos`
  - `assembly.content_origin_world_pos`
- 影响测试入口
  - v1 验收必须固定三类样本：`single`、`template`、`single_template`。
  - 整套系统验收必须优先包含 `structure_assembly` 样本，例如 `trek:village/plains` 或当前测试环境已加载的 configured structure id。
  - 底层 pool 验收可包含 `jigsaw_assembly` 样本，例如原版村庄 start pool。
  - 自动测试至少检查文件存在、manifest 状态、jigsaw 字段完整性。
- 剩余风险
  - 客户端启动、手动选档和截图渲染可能受本机 MC 客户端状态影响。
  - 三类样本的结构 id 需要选取稳定存在于当前测试环境的结构。
  - `place structure` 生成结果可能受 configured structure 自身的 biome、高度投影、地形适配和 MC 放置规则影响；整包落地消费必须读取 `placement_command`、实际命令锚点和 `origin_offset`，不能只按模板原点解释。
  - `place jigsaw` 生成结果可能受 target、pool 内容和深度参数影响，不应默认代表完整村庄。

## TerraSense Studio

- 影响模块
  - Studio 本地 Web 前端。
  - Studio 本地文件 API。
  - 动态术语表、AI 初标、人工审核和 review 写入。
- 影响接口与产物
  - `vocabulary.json`
  - `ai_suggestion.json`
  - `review.json`
  - `StructureCurationExport`
- 影响测试入口
  - v2 验收要求不启动 MC 也能读取 workspace、浏览截图和硬事实、保存 `review.json`。
  - v3 验收要求 mock AI 与真实 vision API 两条路径都能写出 `ai_suggestion.json`。
- 剩余风险
  - AI 初标只能作为建议，不能直接覆盖人工审核真值。
  - 本地文件 API 必须限制 workspace 根目录，避免误写无关文件。
