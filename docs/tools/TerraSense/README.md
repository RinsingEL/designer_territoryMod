# TerraSense

TerraSense 是独立的结构扫描与资产策展工具。它提取 NBT 硬事实、截图、语义和人工审核结果，向固定模板策展提供素材；City active runtime 不把 TerraSense 当作 configured/Jigsaw 几何真值。当前 binder exporter 与 StructureBinder importer 的地形字段尚未统一，不能宣称已完成正式接入。
