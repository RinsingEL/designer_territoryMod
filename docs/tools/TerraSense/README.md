# TerraSense 文档入口

TerraSense 是 Geomantia 的结构扫描与资产策展工具。它负责从 Minecraft 结构素材中提取硬事实、截图、jigsaw 数据和人工审核结果，再导出给 StructureBinder / Geomantia 消费。
