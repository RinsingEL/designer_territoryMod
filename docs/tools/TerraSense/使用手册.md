# TerraSense 使用手册

## 定位

TerraSense 是开发期结构扫描与策展工具，不是正式游玩内容 mod。

它用于：

- 在 Minecraft 里放置结构、完整 structure assembly、底层 jigsaw assembly、截图和导出硬事实。
- 在本地 Studio 里审核结构截图、AI 初标和人工标签。
- 给 StructureBinder / Geomantia 后续城市结构落地提供可信结构画像。

## 打包

在 TerraSense 实现仓库执行：

```powershell
cd E:\Mod_Dev\TerraSense
.\gradlew.bat build
```

成功后产物：

```text
E:\Mod_Dev\TerraSense\build\libs\terrasense-1.0-SNAPSHOT.jar
```

把 jar 放到 Forge 1.20.1 客户端的 `mods` 目录即可使用。

当前版本目标：

```text
Minecraft: 1.20.1
Forge: 47.4.13
Mod id: terrasense
```

## MC 内命令

这些命令在单人世界内执行。

### `/ts_ui`

打开普通结构 `.nbt` 选择 UI。

用途：

- 扫描当前单人世界可发现的 structure `.nbt`。
- 按 namespace / category 浏览。
- 支持搜索、多选、批量扫描。
- 适合扫描单个建筑、道路段、房屋、装饰、遗迹模板等模板级结构。

输出样本一般是普通批量扫描结果，不是整套命令生成样本。

### `/ts_structure_assembly_scan`

扫描一个完整 configured structure。整村、结构群或大型系统优先使用这个入口。

格式：

```mcfunction
/ts_structure_assembly_scan <structure_id>
```

示例：

```mcfunction
/ts_structure_assembly_scan trek:village/plains
```

用途：

- 模拟 MC `place structure` 命令。
- 生成完整村庄 / 地牢 / 大型结构系统。
- 输出 `sample_type=structure_assembly`。
- 用于后续按“整村 / 整套系统”消费。

### `/ts_structure_ui`

打开完整 configured structure 多选 UI。

用途：

- 从当前单人世界的 structure registry 中列出可用完整 structure。
- 支持搜索、多选、批量扫描。
- 生成 `sample_type=structure_assembly`。
- 适合批量扫描 `trek:village/plains`、`trek:village/swamp_vanilla` 这类可直接 `/place structure` 的入口。

这个入口不会列出 `terminators`、`streets`、`houses` 等 template pool 片段。

### `/ts_autotest_scan`

启动固定自动测试样本。

当前固定样本：

```text
single: minecraft:shipwreck/rightsideup_full
template: minecraft:village/plains/streets/turn_01
single_template: minecraft:village/plains/houses/plains_small_house_1
```

用途：

- 快速验证 TerraSense 扫描、截图、manifest 写出是否正常。
- 不弹选择 UI。
- 不用于人工挑结构。

### `/ts_quit`

停止 TerraSense 当前批量扫描队列，不关闭游戏客户端。

用途：

- 开发期批量扫描中途停止后留在当前世界继续检查。
- 自动化或人工调试时快速结束 TerraSense 当前扫描流程。

### `/ts_jigsaw_assembly_scan`

扫描一个指定的底层 jigsaw assembly。完整村庄优先使用 `/ts_structure_assembly_scan`。

格式：

```mcfunction
/ts_jigsaw_assembly_scan <start_pool> [target] [max_depth]
```

示例：

```mcfunction
/ts_jigsaw_assembly_scan minecraft:village/plains/town_centers minecraft:town_centers 7
```

注意每个参数之间必须有空格，不要把句号、逗号或提示文本一起复制进命令。下面这种写法是错误的：

```text
/ts_jigsaw_assembly_scan.minecraft:village/plains/town_centers
```

用途：

- 模拟 MC `place jigsaw` 命令。
- 调试或验证指定 template pool 的拼图展开结果。
- 输出 `sample_type=jigsaw_assembly`。
- 不默认代表完整 configured structure；如果目标是整村，应先走 `/place structure` 语义。

默认值：

```text
target = minecraft:town_centers
max_depth = 7
```

### `/ts_jigsaw_ui`

打开 jigsaw template pool 多选 UI。

用途：

- 从当前单人世界的 template pool registry 中列出可用 start pool。
- 支持搜索、多选。
- 默认从每个 pool 的模板 jigsaw `name` 推断 target，并使用统一 max depth 批量生成多个 `jigsaw_assembly` 样本。

默认行为：

```text
target 留空 = 自动使用每个 pool 的 starting jigsaw name
max_depth = 7
```

如果手动填写 target，会强制所有选中 pool 使用同一个 target。这个只适合你明确知道目标名一致的结构群。原版村庄常用 `minecraft:town_centers`，但其他 mod 的 outpost、camp、dungeon 通常不是这个值。

适合场景：

- 想一次扫描多个 start pool。
- 想从结构 mod / datapack 的 pool 中调试底层拼接结果。
- 不想一个一个敲 `/ts_jigsaw_assembly_scan`。

如果想扫描完整结构群，优先使用 `/ts_structure_assembly_scan`；如果想调试某个 template pool，再使用这个入口。

## 输出目录

默认 workspace：

```text
<minecraft game directory>\terrasense_workspace\autotest\latest
```

在开发仓库 runClient 场景中通常是：

```text
E:\Mod_Dev\TerraSense\run\terrasense_workspace\autotest\latest
```

主要文件：

```text
scan_manifest.json
vocabulary.json
structures/<safe_structure_id>/data.json
structures/<safe_structure_id>/scan_config.json
structures/<safe_structure_id>/screenshots/front.png
structures/<safe_structure_id>/screenshots/right.png
structures/<safe_structure_id>/screenshots/top.png
structures/<safe_structure_id>/screenshots/iso_45.png
```

四张截图对应标准三视图加 45 度斜俯视：正面、右侧、俯视、45 度整体视角。`scan_config.json` 的 `camera.angles` 会记录每张图的 `id/label/file/yaw/pitch`。

普通模板扫描和底层 `jigsaw_assembly` 仍使用 `(0, 100, 0)` 附近的白色摄影平台，便于隔离模板和拍摄。

完整 `structure_assembly` 会改用地表模式：

- TerraSense 先在舞台周边采样当前世界表面高度，选择地表锚点执行 `place structure`。
- 放置前清理地表以上旧结构、掉落物和实体，并把舞台地表层恢复为草方块，避免上一轮结构破坏地表后影响下一轮投影。
- 清理与地表恢复完成后等待 3 秒，再执行 `place structure`。
- 放置前记录扫描范围内的地表基线；放置后只把相对基线发生变化的非空气方块统计为本次结构内容，避免把天然地面误算进 palette。

命令生成样本会额外记录：

```text
sample_type = structure_assembly / jigsaw_assembly
profile_type = jigsaw_system
placement_command
footprint.origin_offset
placement.command_anchor
placement.command_anchor_offset
assembly.structure / assembly.start_pool
assembly.command_anchor_world_pos
assembly.content_origin_world_pos
```

## 环境变量

### `TERRASENSE_WORKSPACE_DIR`

指定 MC 扫描结果输出目录。

示例：

```powershell
$env:TERRASENSE_WORKSPACE_DIR="E:\Mod_Dev\TerraSense\run\terrasense_workspace\manual\latest"
```

### `TERRASENSE_AUTOTEST_V1`

启动客户端并进入世界后自动执行固定样本扫描。

```powershell
$env:TERRASENSE_AUTOTEST_V1="1"
```

### `TERRASENSE_ASSEMBLY_START_POOL`

启动客户端并进入世界后自动扫描一个底层 `jigsaw_assembly`。

```powershell
$env:TERRASENSE_ASSEMBLY_START_POOL="minecraft:village/plains/town_centers"
$env:TERRASENSE_ASSEMBLY_TARGET="minecraft:town_centers"
$env:TERRASENSE_ASSEMBLY_MAX_DEPTH="7"
```

### `TERRASENSE_STRUCTURE_ASSEMBLY_ID`

启动客户端并进入世界后自动扫描一个完整 `structure_assembly`。

```powershell
$env:TERRASENSE_STRUCTURE_ASSEMBLY_ID="trek:village/plains"
$env:TERRASENSE_WORKSPACE_DIR="D:\PCL2-2.8.12\.minecraft\versions\1.20.1-mod开发测试\terrasense_workspace\autotest\latest"
.\gradlew.bat runClient
```

## Studio

Studio 用于脱离 MC 浏览 workspace、查看截图、写人工审核、生成 AI 初标。

启动开发模式：

```powershell
cd E:\Mod_Dev\TerraSense\studio
node scripts\dev.mjs --workspace ..\run\terrasense_workspace\autotest\latest --port 31318
```

启动 server 模式：

```powershell
cd E:\Mod_Dev\TerraSense\studio
npm run build
node server.mjs --workspace ..\run\terrasense_workspace\autotest\latest --port 31317
```

不要用 `npm run dev -- --workspace ...` 或 `npm run server -- --workspace ...` 传 workspace；新版 npm 会把 `--workspace` 当成 npm 自己的工作区参数。

常用页面：

```text
http://127.0.0.1:31318
http://127.0.0.1:31317
```

## MCP 工具入口

MCP 工具主要给 Codex / 自动化流程使用。

### `terrasense_autotest_v1_start`

启动 Forge client，进入指定存档，自动执行固定样本扫描。

常用参数：

```text
projectRoot = E:\Mod_Dev\TerraSense
worldPath = run\saves\新的世界
workspacePath = run\terrasense_workspace\autotest\latest
```

### `terrasense_assembly_scan_start`

启动 Forge client，进入指定存档，自动扫描一个底层 jigsaw assembly。

常用参数：

```text
projectRoot = E:\Mod_Dev\TerraSense
worldPath = run\saves\新的世界
workspacePath = run\terrasense_workspace\assembly\latest
startPool = minecraft:village/plains/town_centers
target = minecraft:town_centers
maxDepth = 7
```

### `terrasense_structure_assembly_scan_start`

启动 Forge client，进入指定存档，自动扫描一个完整 structure assembly。

常用参数：

```text
projectRoot = E:\Mod_Dev\TerraSense
worldPath = D:\PCL2-2.8.12\.minecraft\versions\1.20.1-mod开发测试\saves\新的世界
workspacePath = D:\PCL2-2.8.12\.minecraft\versions\1.20.1-mod开发测试\terrasense_workspace\autotest\latest
structureId = trek:village/plains
```

### `terrasense_studio_v2_start`

启动 TerraSense Studio，读取指定 workspace。

### `terrasense_ai_tag_v3_start`

对指定 workspace 批量生成 AI 初标。

常用模式：

```text
mode = mock
mode = xunfei_vision
```

`xunfei_vision` 使用讯飞 OpenAI-compatible 接口：

```text
baseURL = https://maas-coding-api.cn-huabei-1.xf-yun.com/v2
model = astron-code-latest
key = XUN_FEI_API_KEY
```

Studio 会优先读取当前进程环境变量；在 Windows 上，如果当前进程没有该变量，会再动态读取用户环境变量和系统环境变量。不会把 key 写入日志或返回给前端。

AI 初标提示词会要求新增标签尽量使用 `中文（English）`，例如 `蘑菇图腾（Mushroom Totem）`。Studio 写入 `vocabulary.json` 时会把中文保存为主标签，把英文保存进 `aliases`；`ai_suggestion.json` 的 `source_label` 保留模型原始输出，便于人工追溯。

## 常用流程

### 扫单个模板结构

1. 把 TerraSense jar 放进 Forge 1.20.1 客户端。
2. 进入单人世界。
3. 执行 `/ts_ui`。
4. 搜索并多选结构。
5. 点击批量扫描。
6. 打开 Studio 审核 workspace。

### 扫整套村庄

1. 进入单人世界。
2. 执行：

```mcfunction
/ts_structure_assembly_scan trek:village/plains
```

3. 检查 workspace 中的 `structure_assembly__trek__village_plains`。
4. 打开 Studio 审核截图和硬事实。

### 批量扫完整 structure assembly

1. 进入单人世界。
2. 执行 `/ts_structure_ui`。
3. 搜索 `village` 或目标 mod namespace。
4. 多选 configured structure。
5. 点击 `Start Batch`。
6. 打开 Studio 审核 workspace。

### 批量扫整套 jigsaw 系统

1. 进入单人世界。
2. 执行 `/ts_jigsaw_ui`。
3. 搜索 `village`、`town_centers` 或目标 mod namespace。
4. 多选 start pool。
5. 一般保持 target 为空，让 TerraSense 自动使用每个 pool 的 starting jigsaw name。
6. 点击 `Start Batch`。
7. 打开 Studio 审核 workspace。

## 注意事项

- TerraSense 只建议用于开发环境。
- `/ts_ui` 面向 `.nbt` 模板级结构。
- `/ts_structure_assembly_scan` 面向完整 configured structure，是整村/整套系统的优先入口。
- `/ts_structure_ui` 面向完整 configured structure 的批量选择。
- `/ts_jigsaw_ui` 面向 template pool / 底层 jigsaw assembly 调试。
- 命令生成样本的 `origin_offset` 很重要，后续整包落地消费不能只看内容包围盒原点。
- AI 初标不是最终真值，正式导出应以人工审核 `review.json` 为准。
- 词表主标签优先保持中文；英文名、英文同义词和模型给出的括号英文应进入 `aliases`，不要把 `中文（English）` 整串当成 canonical label。
