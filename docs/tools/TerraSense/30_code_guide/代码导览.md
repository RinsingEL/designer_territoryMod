## 完成后对接关注点

TerraSense 本体完成后，后续不再优先补工具功能，而是确认导出产物是否被 StructureBinder 稳定消费：

- `ScanWorkspace` 中三类样本的 manifest、截图、硬事实、AI 建议和人工审核结果是否完整。
- `StructureProfile.jsonl` 与 `TerraSenseStructureProfileSource.official.json` 是否能覆盖当前 StructureBinder / City D6 消费。
- 导出画像是否保留 TerraSense 白名单 `semanticTerms/functionTerms/...`，且不再投影为 City `functionTags`。
- runtime jigsaw 原始字段是否随导出进入 C8 可读的结构详情。
- `structure_assembly` 通过 MC `place structure` 命令生成完整 configured structure 样本，是整村/整套系统优先入口；它按世界地表执行命令，并通过放置前后的基线差分识别结构内容。`jigsaw_assembly` 通过 MC `place jigsaw` 命令生成底层 pool 调试样本。两者和单个 NBT 模板扫描使用同一个 `ScanWorkspace` 协议，但多记录 `placement_command`、`footprint.origin_offset` 和命令锚点字段。

## 完成能力清单

| 能力 | 形态 | 说明 |
| --- | --- | --- |
| `autotest_scan` | Forge 客户端命令或自动测试入口 | 固定扫描模板级样本并输出 `ScanWorkspace` |

| `catalog_exporter` | Studio/脚本 | 输出 StructureBinder / City D6 可消费的 `StructureProfile.jsonl`、debug catalog 和 vocabulary snapshot |

## 与 StructureBinder 对接

当前 StructureBinder / City D6 从 TerraSense 导出的 `StructureProfile.jsonl` 或显式 debug catalog 读取结构画像。

消费入口包括：

- `CityStructureD6Planner`
- `CityStructureD7Executor`
- D7 bounded jigsaw solver / materialization backend

TerraSense 导出必须保留人工审核后的原始语义 term：`semanticTerms`、`functionTerms`、`styleTerms`、`placementTerms`、`usageTerms`、`templateRoleTerms`、`qualityTerms`。旧 `C3_5` 兼容 catalog、`function_candidates` 和 `functionTags` 不再作为当前主链真值。
