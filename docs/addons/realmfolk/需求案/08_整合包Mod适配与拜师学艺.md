# 整合包 Mod 适配与拜师学艺

**案子身份：设计中案 · 2026-10-14。** 本案负责整合包作者对 Mod 内容的说明、Mod 专属委托、从帮工到出师的身份阶梯（帮工、打工、学徒、出师）与拜师学艺，以及学院等机构模板。物品池与价格沿用 [05](05_城市物品池与多商品交易.md)，委托机制沿用 [06](06_委托系统.md)。跨系统总纲见[异世界冒险体验](../../../10_product/异世界冒险体验/README.md)；开发顺序与里程碑统一见[路线图](../../../00_nav/路线图.md)。

## 文明特色迎合玩家的 Mod 偏好

<small>原话：“我听说现在很多mc玩家都有自己的mod游玩偏好，而我就觉得我们可以靠文明特色来迎合各个玩家的游玩习惯，又或者甚至可以给玩家做某段mod的教程引导”</small>

**AI 总结：** 不同文明擅长不同的玩法，喜欢某类 Mod 的玩家会被相应的城市吸引：在那里买得到所需材料（见 [05](05_城市物品池与多商品交易.md)），接得到相关委托，也找得到愿意教自己的人。擅长的玩法不与种族或建筑风格硬绑定，规则同 05。

## 作者说明一次，各处都能用

**AI 总结：** 整合包作者为每个 Mod 说明一次：面向哪类玩家、提供什么玩法、哪些物品进入物品池、哪些成就可以作为委托目标、入门要经过哪几步。物品池、委托和拜师学艺共用这份说明，作者不必为每个系统分别配置。未安装的 Mod 内容不会出现。

## Mod 专属委托

**AI 总结：** 例如“累计学会三种魔法”“做出第一台动力装置”“驯服一只坐骑”。多数 Mod 的物品、生物与成就，可以直接沿用交付、讨伐等通用方式判定，作者只需配置；少数需要读取 Mod 内部进度的目标（如学会的魔法种类）另做专门适配。玩家在接委托前已经掌握的内容是否计入，由作者为每种目标决定。

## 从帮工到出师的身份阶梯

<small>原话：“同时自己可以去帮忙村民干活或者聊天，甚至可以暂时放下冒险家的身份去做某份工作（这个是不是和后面的拜师系统能结合？）”</small>

<small>原话：“打工我觉得经常和学徒、委托这种结合起来？或者你觉得解耦更好也可以，我是更喜欢有沉浸感的，感觉给个任务就可以了？尤其是那种和公共场所结合起来的，比如像什么给某个机器收集燃料啊，而且这里还可以用那种慢生活mod（农夫乐事、xx琐事之类的），现在很多做这种的，还有什么锻造啊那种，感觉会很有意思”</small>

**AI 总结：** 玩家与居民的劳动关系是一条逐步加深的阶梯，每一级都可以停下：

| 阶段 | 体验 |
| --- | --- |
| **帮工** | 路过时帮居民干一会儿活，例如帮农夫收麦子、帮铁匠拉风箱，几分钟结束，拿一点报酬和好感。 |
| **打工** | 暂时放下冒险者身份，到面包店、码头、公共熔炉、学院图书馆等处做一段时间的工：有东家、有班次、有工钱、有同事。 |
| **学徒** | 打工做出信任后，东家可能收玩家为徒，此后是一条委托树，每一步对应这门手艺的一个入门环节。 |
| **出师** | 获得这一行的身份，例如可以开自己的店、接更高阶的委托、被其他城市的同行认可。 |

打工和学徒的内容是**发生在真实工作场所的具体任务**，例如给公共熔炉收集燃料、在厨房按农夫乐事的做法备菜、在锻造台打出指定的器具。任务类型、完成判定与 Mod 适配和[委托系统](06_委托系统.md)共用，作者配置一次，三处都能用；玩家感受到的却各不相同：帮工是顺手的帮忙，打工有班次与工钱，学徒有师傅与进度，委托是一次性的请求。慢生活、料理、锻造等 Mod 正好提供这类工作内容。

## 拜师学艺

**AI 总结：** 每个文明都有可以拜师的手艺，能学什么由文明擅长的玩法决定：精灵林地教草药、林务与驯兽，矮人山城教锻造、采矿与机械，学院教各系魔法，农庄教种田、酿酒与料理；原版内容同样可以拜师，不依赖任何 Mod。Mod 教程由擅长这门手艺的居民来带，每一步有人示范、有理由、有回报；完成后师徒关系保留，师傅可能把玩家介绍给别的城市和更高阶的老师。拜师随时可以中断和恢复，不想学的玩家永远不会被强迫。

## 学院、骑士团等机构

<small>原话：“学院感觉你说的挺对的，这块的联系是不是就得麻烦到时候具体动态配置的LLM导演了？”</small>

**AI 总结：** 学院不单独做成一套系统，而是“大号的师门”，由已有零件拼成的机构模板：学生群体按课表上课放学（[群体日程](11_城市节奏_群体日程与城市日历.md)），课程是按学期分章的委托树，入学考试与毕业典礼在城市日历上，同学与导师来自居民关系，毕业即出师。同一模板也能拼出骑士团、商会、神殿。城市配置时由 AI 担任导演，结合文明与城市设定选用模板，决定群体、课程用到的任务类型和日历事件；游戏运行中由程序按配置运转，AI 只在学期结束、毕业等少数时刻写评语或游记。机构在学徒、群体日程与城市日历都完成后再拼装。
