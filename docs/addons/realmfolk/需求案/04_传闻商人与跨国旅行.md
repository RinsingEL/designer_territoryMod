# 传闻、商人与跨国旅行

**案子身份：实现当前案。** 本案负责玩家如何得知其他国度，以及通过商人引导完成跨国旅行。 下一案为[城际商队与传闻网络](10_城际商队与传闻网络.md)（设计中案）。

## 通过传闻探索其他国度

<small>原话：“然后玩家既可以道听途说前往下一个国度”</small>

**AI 总结：** 玩家可以通过**道听途说**得知其他国度，并根据得到的信息前往探索。

信息的来源、提供多明确的位置或路线，以及如何帮助玩家找到目的地，尚待讨论。

## 跟随路上商人旅行

<small>原话：“也可以跟着路上的商人前往下一个国度”</small>

**AI 总结：** 玩家也可以**跟着路上的商人前往下一个国度**，让世界中的旅行者成为玩家探索世界的一种引导。

商人的行程、停留地点、玩家如何得知目的地，以及途中可以发生什么，尚待讨论。

## 多种旅行途径并存

<small>原话：“然后玩家既可以道听途说前往下一个国度，也可以跟着路上的商人前往下一个国度”</small>

**AI 总结：** 通过传闻自行探索和跟随商人旅行，是同时保留的两种体验。玩家不需要只依赖一种途径认识其他国度。

## 首版试玩确认范围

<small>原话：“ok，我觉得你说的就都蛮合适的，咱们先开发出来吧，得上手玩玩了才知道具体的效果如何。”</small>

**AI 总结：** 居民可告知已知邻近城镇及大致位置，玩家可记入冒险日志并自行探索。玩家也可与商人交谈、跟随商人实际步行前往目的地，平安抵达后完成护送委托。首版先验证已探索城镇之间的同行；复杂商队、跨海路线和长期贸易网络继续讨论。
