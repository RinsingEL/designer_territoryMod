# 玩家领地与获得方式

**案子身份：实现当前案。** 本案负责玩家拥有领地的体验及获得方式。

## 玩家拥有自己的领地

<small>原话：“而玩家也可以有自己的领地”</small>

**AI 总结：** 玩家可以在世界中拥有**自己的领地**，使个人冒险之外也存在属于玩家的空间。

领地的范围、允许进行的活动，以及它与 NPC、队友和所属国度之间的关系，尚未确定。

## 购买或奖励获得

<small>原话：“感觉获得方式应该是购买或奖励？”</small>

**AI 总结：** 用户最初提出**购买或奖励**作为候选方向，本轮批准先实现两种方式并通过试玩调整。

首版由领事出售空置住房，也可以通过讨伐委托授予；更完整的地产与封地制度继续讨论。

## 首版试玩确认范围

<small>原话：“ok，我觉得你说的就都蛮合适的，咱们先开发出来吧，得上手玩玩了才知道具体的效果如何。”</small>

**AI 总结：** 购买和奖励两种方式均进入试玩：玩家向领事购买空置住房，或通过讨伐委托获得住宅奖励；已有房屋售出后不会重复售卖。获得产权后可自由改建、使用容器和存放物品。首版先体验住宅产权，税收、领主管理和封地制度继续讨论。
