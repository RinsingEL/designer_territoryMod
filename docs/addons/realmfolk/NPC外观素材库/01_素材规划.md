# 素材分类、数量与优先级

## 首批库与成本

成本用相对人时估算：低=0.5–2h，中=2–6h，高=6–16h（含常用姿态修整，不含游戏加载器开发）。这是排期起点，非工时承诺；样板仍需美术精修。

## 共享与专用版本

可共享：肤色、雀斑、伤疤、眼形、虹膜、发色、同语义 UV 的布纹和徽章图案。通过独立颜色区域复用，图案的落点仍要逐体型检查。

替换几何：粗细体型、头型、发型轮廓、长须、尖耳、帽檐、背包、厚外套、袍片。纤细不自动等于女性，壮实不自动等于男性，尖耳不自动等于精灵居民或 FS 建筑风格居民。

必须有三体型版本：贴身上衣/裤子、袖子/手套、外套、袍片、腰带、包带、胸肩徽章与围巾位置。头顶帽与眼镜在统一头尺寸时可以共享实际顶点，但仍显式声明 supports；本轮导出三体型选择，不能依靠“应该能穿”。若未来改头围，新增 headProfile 兼容条件和专用版本。

不用“全局缩放衣服”补壮实体型的腋窝。软裙/连体袍只能在程序具备分片或受控变形后入普通池；本轮袍是分腿前片，无后摆、无布料模拟，不宣称已经实现柔软的完整环裙。

## 人群组合原则

性别表现 presentation 是独立偏好标签，允许 neutral/masculine/feminine 及作者扩展；不是二元骨架选择开关。体型、肤色、species、ears、hair、服装 style 各自抽取，在适配关系上相交，不用歧视性或生物学臆测作隐藏约束。

文明偏好只决定服饰与色板权重。城市通过完整权重表表达常住、移民和访客比例，移民可采用当地服装或保留原乡服装；外来商人的人口身份与居住归属沿用现有 visitor/travel 逻辑，外观不得修改它。species 人口池必须单独由世界设定填写；未设置则 unspecified，而不是由建筑风格猜测。三个样板故意让每种风格都有圆耳和尖耳、不同肤色与身体。

配饰只负责可读外观：腰包没有库存，护目镜没有护甲值，胸徽不授予学者能力。真实书本/工具、装备、商店库存继续走当前物品系统和生活临时持物恢复机制。
