# 附属模组

附属模组的需求案与附属自有契约统一在本目录维护；代码在实现仓 `addons/<附属>/`。主模组为附属提供的公共接口（区域预留、规划流程扩展）仍属于[国度规划](../systems/realm_planning/README.md)。跨系统总纲见[异世界冒险体验](../10_product/异世界冒险体验/README.md)。

| 附属 | 负责 | 代码位置 |
| --- | --- | --- |
| [Realmfolk · 国度之民](#realmfolk--国度之民) | 居民、经济、法律声誉、领地、传闻旅行、委托 | 实现仓 `addons/realmfolk/` |
| [Adventure · 冒险内容分布](#adventure--冒险内容分布) | 大陆档位、怪物与结构池、居民区避让、地点记录 | 实现仓 `addons/adventure/` |
| [Realmsaga · 国度传说](#realmsaga--国度传说) | 剧情、游记、前世传说 | 尚未建立 |
