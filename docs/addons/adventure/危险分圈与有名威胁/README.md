# 危险分圈与有名威胁

**设计中案 · 2026-10-14**。[冒险内容分布附属模组](../冒险内容分布附属模组-v0.1/README.md)职责链的下一案：让玩家在同一档位内也能感到从文明到荒野的变化，并让危险有名字、有位置、能被讨伐。接管实现前，原案仍为实现当前案。总纲见[异世界冒险体验](../../../10_product/异世界冒险体验/README.md)。

## 现在的分档为什么感觉不到

<small>原话：“前面那俩我感觉你说的都挺对的”（指 AI 对难度分级问题的分析）</small>

**AI 总结：** 现有分档按“离初始大陆隔几块大陆”计算，整块大陆同一档，城郊与大陆深处一样危险；默认三档使用同一组怪物与结构，不改配置就没有差别；玩家也察觉不到自己进入了更危险的地方。

## 档位之内，从人烟到荒野

**AI 总结：** 每个档位内部再按离文明的远近分圈：城市与村庄周边安全；国度边境与道路远端开始出现盗匪和魔物；远离任何文明的荒野最凶险。分圈依据城区、郊区、村庄与道路的位置，作者为每圈配置怪物与结构。

## 有名字的威胁

<small>原话：“有等级mod，但我确实不喜欢，我更喜欢机制怪而不是纯粹的数值怪，就算换个皮我都觉得开心”</small>

**AI 总结：** 除了零散刷怪，各档各圈还有成形的威胁：魔物营地、盗匪据点、巢穴与首领。它们有名字和固定位置，构成与普通游荡怪不同，偏重机制而不是数值。威胁的位置被记录下来，供讨伐、清理委托和传闻引用；长期无人处理时会向外扩张，具体由剧情附属 Realmsaga 推动。

## 让玩家察觉到变化

**AI 总结：** 跨入新的档位或从人烟进入荒野时，玩家能察觉到变化，例如地名提示、环境氛围与路边警示。默认配置使用原版内容就要把三档拉开差距，例如第一档普通怪物，第二档成群敌人与袭击者，第三档精英与首领。
