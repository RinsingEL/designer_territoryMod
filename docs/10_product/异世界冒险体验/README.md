# 异世界冒险体验

**设计中案 · 总纲 · 2026-10-14**。每次新建存档，AI 依据这次随机出的地理创造文明、城市与居民；玩家在其中自由冒险，想要方向时能接到委托或卷入剧情，旅途本身就是玩家自己的故事。本页只给系统地图、推荐开发顺序和共同原则，各系统需求写在各自案子里。尚未接管实现。

<small>原话：“我做这个Mod/整合包的动机，是我在游玩MC的冒险包的时候，感觉纯数字随机找结构没太大意思，然后对于包总感觉有种主线全靠ftp的感觉，而我本身是很期望每次开游戏的时候，都能体验都不一样的异世界的”</small>

<small>原话：“总之我就是好想游玩一个能让我沉浸的异世界😢，里面能有吸引我探索的文明，偶尔能让我有目的知道做什么（因为纯沙盒很多玩家是经常会不知道该做什么的），偶尔又能够不管我想做什么就做什么，也就是这个世界是“我们的世界”，整个存档都是我共同书写的故事”</small>

**AI 总结：** 三条体验目标：每个存档的世界都不同且有来历；玩家想要方向时随时找得到，想自由时不被推着走；玩家做过的事留在这个世界里。

<small>原话：“嗯嗯我感觉这个拆法蛮好的，接下来就交给你大胆设计了，剧情和游记感觉可以独立的一个？因为感觉不一定会做得好😢，就是作为附属mod 这种”</small>

## 推荐开发顺序

**AI 总结：** 每一步做完都能玩，后做的系统使用先做系统产生的数据。

| 顺序 | 内容 | 理由 |
| --- | --- | --- |
| 0 | 居民的一天与城市人气 | 用户确认优先；城里没人，法律、委托与传闻都立不起来 |
| 1 | 委托核心：通用类型、判定、发放、结算 | 补上“偶尔有目的”的最大空缺，第四题实验已验证方向 |
| 2 | 城市内容快速配置（可与 1 并行） | 城市一多，配置成为瓶颈；委托发放也依赖它 |
| 3 | Mod 适配与拜师学艺 | 有了委托骨架，才能接 Mod 专属目标与教学 |
| 4 | 游记与前世传说 | 有委托、关系等事件可记，游记才有内容 |
| 5 | 世界设定与矛盾 | 给剧情提供素材，与第 6 步衔接 |
| 6 | 剧情 | 依赖委托、世界设定和事件记录全部就位 |

国度内部联系（道路与小村庄）、商队与传闻、危险分圈三项可在第 0 步之后按需穿插：道路与村庄让城市连成一片，商队与传闻依赖道路，危险分圈为讨伐委托提供目标。

## 共同原则

### 最强的 Agent，重活放在创世时

<small>原话：“LLM我目前直接打算用最强的agent，因为识图能力要求很高”</small>

**AI 总结：** 看图设计、文明创作、城市设计等耗时工作集中在创世与城市生成阶段；游玩中由程序依据已定下的设计即时响应，AI 只在委托链结束、剧情推进、游记成章等少数时刻介入。玩家附近的城市先完成，其余在后台跟在玩家前面生成。

### 单人优先，也能和朋友一起玩

<small>原话：“我目前是打算单人，不过当然多人也可以，因为我很想和我朋友一起玩”</small>

<small>原话：“前世传说我建议一起做呗，同一个委托也可以一起完成，因为经常有“冒险家小队”这种概念嘛，附属mod的名字你来取吧”</small>

**AI 总结：** 按单人体验设计和验收，同一世界也能和朋友一起玩：世界、城市、剧情和世界历史大家共有；每位玩家与 NPC、国度的关系和拜师进度分开记录。朋友可以组成冒险家小队，一起接取并完成同一个委托，规则见 Realmfolk 委托案。

### 开放世界，玩家的旅途就是主线

<small>原话：“主线我打算尽量开放世界，同时可以我们自己来点经典主线附属mod，如什么魔王军这种异世界剧情。”</small>

<small>原话：“其实玩家本身游玩就是一个冒险游记的主线了，在途中结识NPC、与各个国度产生联系，这就是玩家自己的故事了已经”</small>

**AI 总结：** 任何委托和剧情都是可选的，不做也不会卡住其他内容。玩家结识 NPC、与各国建立联系的旅途本身就是主线；经典异世界剧情由附属提供。
