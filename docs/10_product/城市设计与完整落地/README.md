## 已确认的三点

- **一区一个核心**：每个实际参与阵列的功能区有一个核心；多个同类区相邻组合成大片区域，不强行并成一个大阵列。同类区可以选不同核心模型。
- **台地随核心取高**：实际生成时确定核心的落地地面高度，本区共享台地沿用该高度；不同区分别取高并衔接。
- **D4 设计，实际生成适配**：D4 保留地图、地形偏好与布局检查，不因少量水域或普通高差拒绝设计。后续处理台地、支撑和桥路，生成后核对完整性。
