## 当前实现入口

| 能力 | 主要入口 | 说明 |
| --- | --- | --- |
| Forge 调试命令 | `GisPlatformEvents` | 注册 `/geomantia gis refresh` 和 `/geomantia gis test_run`。 |
| HTTP 调试接口 | `GeomantiaHttpServer`、`GisHttpController`、`GisHttpUtil` | MC server 启停时绑定 `127.0.0.1:5000`，暴露 `/gis/status`、`/gis/refresh`、`/gis/test_run`。 |
| MCP 工具 | `country_designer_mcp/src/gis/tools.ts`、`handlers.ts` | 提供 `gis_status`、`gis_refresh`、`gis_test_run`。 |
| 主刷新服务 | `GisRefreshService` | 创建 RefreshJob，按采样、指标、分类、Patch、导出顺序推进主链。 |
| 半径规划 | `RadiusRefreshPlanner` | 把中心点和区块半径转换为 Region 内 PlannedCell，并区分 stable 与 dependency margin。 |
| prior 采样 | `MinecraftPriorAtlasSampler` | 使用当前维度 `ChunkGenerator`、`NoiseColumn`、`Biome` 等接口采样，不主动预生成 chunk。 |
| 合成采样 | `SyntheticAtlasSampler` | 供固定样例和 GameTest 使用。 |
| 指标层 | `AtlasMetricsComputer` | 计算 slope、localRelief、roughness、tpiSmall、tpiLarge、waterDistance。 |
| 地貌分类 | `LandformClassifier` | 按规则写入 Cell 级 landformType。 |
| Patch 合并 | `PatchMerger` | 以四邻接、同地貌类型 flood fill 生成 LandformPatch 摘要。 |
| 调试导出 | `ProgressExporter`、`PreviewExporter` | 写出 progress、preview 图层和 manifest。 |
| 快照读写 | `AtlasRegionSnapshotIo` | 轻量 JSON 快照，用于测试复现和现场还原，不是生产持久层。 |
| 自动测试 | `GisBaselineRunnerTest`、`AtlasRegionTest`、`GisGameTests`、`GisTestRunner` | 覆盖单元、合成样例、GameTest 和测试报告。 |

## 当前边界

- G8 消费者查询接口未纳入当前 GIS v1 基线；`query` 包暂不提供正式消费者 API。
- 当前 RegionStore 是内存级组织；生产级 SavedData / 二进制长期持久层未实现。
- `AtlasRegionSnapshotIo` 是轻量快照工具，只用于测试复现和现场还原。
- `PatchMerger` 当前只做同类型四邻接合并，未实现小碎片吸收、近似地貌合并、跨 Region 缝合或真实轮廓持久化。
- `LandformPatch` 的 bbox 字段语义是 PatchEnvelope，只能做查询粗筛和定位；真实 shape 当前由 Cell 的 `patchId` 成员关系表达。
- `patch.png` 当前按 Cell 的 `patchId` 渲染 Patch 成员边界，不使用 PatchEnvelope 代替真实形状。
- `DevAutoLoadClient` 是临时客户端验收辅助，启用条件由 Gradle/system property 控制，不是正式客户端功能。

- `AtlasCell` flag 推进。
- sampler、metrics、classifier、patch 任一阶段。
- debug preview、snapshot、HTTP/MCP 输出字段。
- 临时代码进入正式主链的风险。
