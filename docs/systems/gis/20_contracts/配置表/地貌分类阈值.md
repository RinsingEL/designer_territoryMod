# 地貌分类阈值

本文记录 GIS v1 地貌分类需要的阈值配置。具体数值需要通过固定 seed 和预览图校准，本文先定义配置项和用途。

## 坡度与起伏

| 配置 | 初始建议 | 说明 |
| --- | --- | --- |
| plainMaxSlope | 待校准 | 平原允许的最大坡度。 |
| slopeMaxSlope | 待校准 | 普通坡地允许的最大坡度。 |
| cliffMinSlope | 待校准 | 判为 cliff 的最小坡度。 |
| plainMaxRelief | 待校准 | 平原允许的最大局部起伏。 |
| roughTerrainMin | 待校准 | 判为崎岖区域的粗糙度下限。 |

## TPI

| 配置 | 初始建议 | 说明 |
| --- | --- | --- |
| ridgeTpiLargeMin | 待校准 | 大尺度山脊判定下限。 |
| valleyTpiLargeMax | 待校准 | 大尺度谷地判定上限。 |
| terraceTpiLargeMin | 待校准 | 台地候选下限。 |
| basinTpiLargeMax | 待校准 | 盆地候选上限。 |
| tpiNeutralAbsMax | 待校准 | 近似平坦区域的 TPI 绝对值上限。 |

## 水体与岸线

| 配置 | 初始建议 | 说明 |
| --- | --- | --- |
| shoreMaxWaterDistanceCells | 待校准 | 判为岸线的最大水距。 |
| deepWaterMinDepth | 待校准 | 判为深水的最小水深。 |
| shallowWaterMaxDepth | 待校准 | 浅水上限。 |
| shoreMaxSlope | 待校准 | 岸线允许的最大坡度。 |

## Patch 与消费者适配

| 配置 | 初始建议 | 说明 |
| --- | --- | --- |
| cityCoreMinPatchCells | 待校准 | 城市消费者可参考的主体候选最小 Patch 大小。 |
| fragmentMaxPatchCells | 待校准 | 判为碎片 Patch 的最大 Cell 数。 |
| structureProfileMinMatch | 待校准 | 结构消费者自行计算适配度时可参考的最低匹配值，不属于 GIS 输出字段。 |

## 校准规则

- 阈值必须通过固定 seed 的预览图校准。
- 每次调整后输出 PreviewManifest。
- 不同地貌的阈值不要只看单点样例，至少覆盖平原、山地、水域、复杂过渡区。
- 消费者不应硬编码这些阈值，应通过 GIS 查询结果或配置读取。
- GIS 分类阈值只决定地貌事实和 Patch 状态，不决定结构是否允许落地。
