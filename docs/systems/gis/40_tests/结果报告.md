## 发现的问题

- 初次接入 GameTest 时缺少 `gameteststructures/gisgametests.empty.snbt`，已补最小空结构模板并由 `processResources` 同步到 `run/gameteststructures`。
- synthetic mountain 样例初始海平面过高，谷地被水体优先规则吞掉；已调整为陆上山地样例。
- mixed 样例最终定位为复杂过渡区，覆盖 water、shore、terrace、cliff，不承担 ridge / valley 验收职责。
- 收口复核时发现分类和 Patch 合并会把半径外未采样格子纳入结果，已修正为仅已采样且指标完成的格子进入分类 / Patch；最终报告中的 `pending=14820` 用于验收半径外状态保持。
