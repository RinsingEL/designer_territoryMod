# GIS 测试入口

GIS 测试以“数值可解释、图像可检查、消费者可复用”为核心。v1 初版稳定版不追求一次性覆盖所有世界地形，但必须覆盖固定 seed、固定中心点、固定半径的可重复样例，并能作为后续回归基线。

## 测试分层

| 层级 | 目标 |
| --- | --- |
| 单元测试 | AtlasCell 状态、Region 坐标、指标计算、分类规则。 |
| 人造网格算法测试 | 使用固定高度矩阵验证坡度、TPI、地貌分类和 Patch 合并。 |
| 固定样例测试 | 使用固定 seed、生成器配置和中心点验证 prior 采样、指标、分类结果稳定。 |
| Forge prior 自动测试 | 通过 Forge GameTest 测试维度，默认不预生成 chunk，自动刷新 GIS、导出报告和预览图。 |
| 局部验证对照 | 对少量候选点执行 observedIfLoaded 或 verifySurface，对照 prior 与真实地表差异。 |
| 预览图验收 | 输出高度、坡度、TPI、地貌、Patch 图层，人工检查合理性。 |
| MCP/HTTP 调试验收 | 通过本地 MCP 工具触发 status、合成 test_run 和真实世界 refresh，减少对客户端窗口焦点的依赖。 |
| 性能测试 | 验证半径刷新不会阻塞运行时预算。 |
| 消费者联调 | City、Roads、Realm、Structure 通过查询接口读取 GIS。 |

## v1 样例

v1 至少准备以下样例：

| 样例 | 目的 |
| --- | --- |
| 平原样例 | 验证 plain、低坡度连续区和 Patch 合并。 |
| 山地样例 | 验证 ridge、valley、cliff、tpiLarge。 |
| 水域样例 | 验证 water、shore、waterDistance。 |
| 复杂过渡区 | 验证 edgeDirty、unknown、Patch fragment。 |

当前实现仓库固定样例入口为 `GisTestCase.baselineCases()`：

| caseId | 覆盖重点 |
| --- | --- |
| plain | plain 主导、低坡连续区、单大 Patch。 |
| mountain | ridge、valley、slope、大尺度 TPI。 |
| water | water、shore、waterDistance、少量 unknown。 |
| mixed | water、shore、terrace、cliff、复杂过渡 Patch。 |

## 通过条件

- 同一 seed、中心点、配置下重复运行输出一致。
- prior 测试不应大范围触发 chunk 预生成。
- AtlasCell 状态不会把未完成数据伪装成可用数据。
- 自动测试能通过 `./gradlew.bat test` 跑完 JVM 单元和人造网格测试。
- agent 能通过 `runGameTestServer` 执行固定 seed/prior 样例的 GIS 集成测试。
- 每个固定样例能输出 `test_report.json`、`progress_manifest.json` 和 `PreviewManifest`。
- 地貌分类图肉眼可解释，明显地貌不应大面积误判。
- 刷新半径边缘能正确标记脏区或低置信区域。
- G8 消费接入不属于 GIS v1 基线开发目标，本轮不以消费者联调作为通过条件。

## 自动测试入口

详细方案见：`自动测试方案.md`。

v1 推荐 agent 执行顺序：

1. `./gradlew.bat test`
2. `./gradlew.bat runGameTestServer`
3. `npm run build`（目录：`country_designer_mcp`）
4. 如需真实 MC 运行态验收，用 `./gradlew.bat runClient` 或 `./gradlew.bat runServer` 打开固定 seed 测试世界，并通过 MCP 工具或 GIS 调试命令执行验证。

当前实现已接入：

- JVM 单元与算法测试：`src/test/java/com/rinsing/geomantia/systems/gis/`
- Forge GameTest：`GisGameTests.gisPriorSyntheticBaseline`
- 调试命令：`/geomantia gis refresh <radiusChunks> [sampleMode] [cellStepBlocks]`、`/geomantia gis test_run <caseId>`
- 本地 HTTP 接口：`GET /gis/status`、`POST /gis/refresh`、`POST /gis/test_run`
- MCP 工具：`gis_status`、`gis_refresh`、`gis_test_run`

MCP/HTTP 接口契约见：`../20_contracts/接口契约/GIS调试MCP接口.md`。
