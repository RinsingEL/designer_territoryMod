# GIS 指标层

GIS 指标层把基础采样转换成规划系统更容易消费的地貌特征。它不追求传统 GIS 的完整精度，而是追求在 Minecraft 中足够稳定、足够快、足够可解释。

## 基础采样层

| 指标 | 来源 | 用途 |
| --- | --- | --- |
| elevation | 地表高度。 | 一切坡度、起伏、TPI 的基础。 |
| surfaceType | 表面方块粗分类。 | 判断沙地、雪地、岩石、草地等风格倾向。 |
| biome | 生物群系。 | 辅助结构风格、生态限制和调试筛选。 |
| isWater | 是否为水体。 | 岸线、水距、道路避障、城市临水评价。 |
| waterDepth | 水深估计。 | 区分浅滩、湖泊、海岸和深水。 |

## 派生指标层

| 指标 | 含义 | 首版用途 |
| --- | --- | --- |
| slope | 周围高度变化强度。 | 判断可建性、道路代价、缓坡和陡坡。 |
| localRelief | 局部最高点与最低点差值。 | 判断地形破碎程度。 |
| roughness | 邻域高度变化的离散程度。 | 识别崎岖地形，避免城市落在噪声过强区域。 |
| tpiSmall | 小尺度地形位置指数。 | 识别微地形中的凸起、凹陷、坡面。 |
| tpiLarge | 大尺度地形位置指数。 | 识别山脊、谷地、盆地、台地等大地貌。 |
| waterDistance | 到最近水体或岸线的距离。 | 城市临水、道路桥位、港口和岸线结构。 |
| buildability | 综合可建性评分。 | 供城市和结构系统快速筛选候选区。 |

## TPI 说明

TPI 可以理解为“当前 Cell 高度减去邻域平均高度”：

- TPI 明显为正：当前位置比周围高，可能是山脊、丘顶、台地边缘。
- TPI 接近 0：当前位置与周围高度接近，可能是平原、坡面或台地内部。
- TPI 明显为负：当前位置比周围低，可能是谷地、盆地、河谷。

小尺度 TPI 用于识别局部微地貌，大尺度 TPI 用于识别区域地貌。两者结合后，才能避免把小土包误判为山脊，或把大高原误判为普通平原。

## 可建性评分

`buildability` 是给消费者快速使用的综合评分，不取代原始指标。

首版建议由以下因素组成：

| 因素 | 影响 |
| --- | --- |
| 坡度 | 坡度越大，可建性越低。 |
| 局部起伏 | 起伏越剧烈，可建性越低。 |
| 水体 | 深水通常不可建，浅滩和岸线需要特殊标记。 |
| 地貌类型 | 平原、台地内部更适合城市；山脊和谷底更适合道路或景观结构。 |
| 面积连续性 | 单个 Cell 可建不够，必须考虑周围连续可建区域。 |

消费者需要保留读取原始指标的能力，避免只用一个分数做所有决策。

## 性能原则

- 指标计算基于 Atlas Cell，而不是逐方块。
- 邻域统计尽量使用滑动窗口、前缀和或分批缓存。
- 大尺度 TPI 和水距允许延迟计算，不阻塞基础预览。
- 边缘 Cell 可以先输出基础层，再等待依赖补齐。
