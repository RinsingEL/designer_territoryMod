# GIS 指标层

GIS 指标层把基础采样转换成规划系统更容易消费的地貌特征。它不追求传统 GIS 的完整精度，而是追求在 Minecraft 中足够稳定、足够快、足够可解释。

GIS 指标层默认基于当前世界生成器的先验采样计算，不要求 chunk 已经生成。已生成 chunk 的后验观测可以覆盖或校正先验结果，但 v1 Atlas 建库不以大范围 chunk 预生成为前提。

这里的先验采样不是读取“原版固定 6 个噪声参数”，而是调用当前维度实际使用的 `ChunkGenerator`、`BiomeSource`、`RandomState` 等接口。这样能兼容多数地形 Mod 的生成器，同时避免把未生成区域强行推进到 `FULL`。

## 基础采样层

| 指标 | 来源 | 用途 |
| --- | --- | --- |
| elevation | 生成器基础高度，或已生成 chunk 的真实高度图。 | 一切坡度、起伏、TPI 的基础。 |
| surfaceType | 可预测表面类型，或真实表面方块粗分类。 | 判断沙地、雪地、岩石、草地等风格倾向。 |
| biome | 生成器生物群系采样，或真实 chunk 生物群系。 | 辅助结构风格、生态限制和调试筛选。 |
| isWater | 基于海平面和生成器列的水体关系，或真实流体。 | 岸线、水距、道路避障、城市临水评价。 |
| waterDepth | 预测水深或真实水深估计。 | 区分浅滩、湖泊、海岸和深水。 |

## 采样模式

| 模式 | 说明 | v1 用途 |
| --- | --- | --- |
| prior | 只调用世界生成器接口，不主动生成 chunk。 | Atlas 建库、大范围规划、预览和自动测试。 |
| observedIfLoaded | chunk 已加载或已生成时读取真实高度图和方块，否则回退 prior。 | 调试对照、玩家附近区域修正。 |
| verifySurface | 只对候选点小范围推进或等待到足够表面阶段。 | 结构物化前局部校验。 |

v1 默认使用 `prior`。`verifySurface` 不应被半径刷新滥用，只能由结构落地或强验收流程对小范围候选点触发。

## 派生指标层

| 指标 | 含义 | v1 用途 |
| --- | --- | --- |
| slope | 周围高度变化强度。 | 判断道路代价、缓坡、陡坡和消费者适配度。 |
| localRelief | 局部最高点与最低点差值。 | 判断地形破碎程度。 |
| roughness | 邻域高度变化的离散程度。 | 识别崎岖地形，避免城市落在噪声过强区域。 |
| tpiSmall | 小尺度地形位置指数。 | 识别微地形中的凸起、凹陷、坡面。 |
| tpiLarge | 大尺度地形位置指数。 | 识别山脊、谷地、盆地、台地等大地貌。 |
| waterDistance | 到最近水体或岸线的距离。 | 城市临水、道路桥位、港口和岸线结构。 |

## TPI 说明

TPI 可以理解为“当前 Cell 高度减去邻域平均高度”：

- TPI 明显为正：当前位置比周围高，可能是山脊、丘顶、台地边缘。
- TPI 接近 0：当前位置与周围高度接近，可能是平原、坡面或台地内部。
- TPI 明显为负：当前位置比周围低，可能是谷地、盆地、河谷。

小尺度 TPI 用于识别局部微地貌，大尺度 TPI 用于识别区域地貌。两者结合后，才能避免把小土包误判为山脊，或把大高原误判为普通平原。

## 消费侧适配评分

GIS 不输出通用 `buildability`。同一片地形对不同消费者的意义不同：深水可能不适合村庄，却适合船坞；悬崖可能不适合普通建筑，却适合灯塔、哨塔或景观结构。

消费者应读取原始指标和地貌标签，并在自己的 profile 中计算适配度。GIS 只保证事实稳定、可缓存、可解释，不替消费者做最终落地判断。

## 性能原则

- 指标计算基于 Atlas Cell，而不是逐方块。
- 邻域统计尽量使用滑动窗口、前缀和或分批缓存。
- 大尺度 TPI 和水距允许延迟计算，不阻塞基础预览。
- 边缘 Cell 可以先输出基础层，再等待依赖补齐。
