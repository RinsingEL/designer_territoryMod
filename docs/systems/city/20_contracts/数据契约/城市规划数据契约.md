# 城市规划数据契约

## 定位

本文定义 City 系统 C1-C4 城市规划过程的结构化产物。字段命名先作为契约草案，进入实现时应保持版本化和兼容说明。

## 版本

| 字段 | 当前值 | 说明 |
| --- | --- | --- |
| `schemaVersion` | `city_planning.v0.1` | City 规划契约初版。 |
| `coordinateUnit` | `block` | 对外坐标默认使用 block 坐标。 |
| `gridUnit` | `cell` | 规划图层可使用局部 cell 网格，并必须提供 block 转换。 |

## CityPlanningPackage

城市规划总包，索引 C1-C4 的主要产物。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 当前为 `city_planning.v0.1`。 |
| `cityId` | string | 是 | 城市唯一 ID，来自 T4 或 C 阶段锁定。 |
| `realmId` | string | 是 | 所属国度 ID。 |
| `dimensionId` | string | 是 | 维度 ID。 |
| `seedId` | string | 是 | 对应 `CitySeed` ID。 |
| `siteCandidateId` | string | 是 | 对应 `CitySiteCandidate` ID。 |
| `bounds` | object | 是 | 城市规划范围，block 坐标。 |
| `grid` | object | 是 | 局部规划网格定义。 |
| `terrainPatchMapRef` | string | 是 | C1 产物路径或引用。 |
| `grammarPlanRef` | string | 是 | C2 产物路径或引用。 |
| `functionZoneMapRef` | string | 是 | C3 产物路径或引用。 |
| `boundaryIntentRef` | string | 是 | C4 边界 / 缓冲区意图引用。 |
| `roadIntentRef` | string | 是 | C4 道路意图引用。 |
| `buildOperationPlanRef` | string | 否 | D5 WorldEdit 执行计划引用。 |
| `worldMutationReportRef` | string | 否 | D5 真实执行报告引用。 |
| `previewRefs` | string[] | 否 | 调试预览图。 |
| `quality` | object | 是 | 质量评分和 hard block。 |
| `createdAt` | string | 是 | ISO 时间。 |

## PatchGroupPlan

D4 首版的 C2 `PatchGroupPlan` 由 MCP 调用方侧 AI / Codex 看 `landform_review_map.png` 后生成并提交；Java 运行时只做引用校验、功能类型校验、实体化和产物导出，不内置 LLM 调用。D4 使用 D3 `city_landform_review_package.json` 中的 `memberCells` 合并功能区真实 mask；只有缺少成员格子时才显式降级到 envelope。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | `city_patch_group_plan.v0.1`。 |
| `cityId` | string | 是 | 必须与 D3 审查包一致。 |
| `groups` | object[] | 是 | AI 草案功能区分组。 |

`groups[]` 关键字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `groupId` | string | 是 | AI 草案临时 ID。 |
| `zoneName` | string | 是 | 转成 City 功能区后的名称。 |
| `functionType` | string | 是 | 固定枚举之一：`civic_core`、`residential`、`production`、`market`、`farm_or_pasture`、`defense`、`harbor_or_waterfront`、`sacred_or_cultural`。 |
| `patchLabels` | string[] | 否 | 引用 D3 图上 `mapLabel`；与 `landformPatchRefs` 至少提供一个。 |
| `landformPatchRefs` | string[] | 否 | 引用 GIS `landformPatchId`。 |
| `mainBuildingRole` | string | 否 | 给后续 D6 / C5 使用的主要建筑角色，不在 D4 校验结构 catalog。 |
| `supportingBuildingRoles` | string[] | 否 | 辅助建筑角色。 |
| `groupReason` | string | 否 | AI / Codex 看图后的分组理由；远距离拼接无理由时进入 needs_review。 |
| `adjacencyIntent` | string | 否 | 靠近 / 远离意图，仅记录。 |
| `splitRequested` | bool | 否 | D4 v0.1 只记录 warning，不实际切 patch。 |

## FunctionZoneMap

C3 功能区图。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 例如 `function_zone_map.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `grid` | object | 是 | 局部网格。 |
| `zones` | object[] | 是 | 功能区实例。 |
| `cellAssignments` | object[] | 是 | cell 到 zone 的映射，可压缩。 |
| `quality` | object | 是 | 比例、连通、越界等评分。 |

`zones[]` / `FunctionZonePatch` 关键字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `zonePatchId` | string | 是 | 功能区实例 ID。 |
| `sourceGroupId` | string | 是 | 来源 `PatchGroupPlan.groups[].groupId`。 |
| `zoneName` | string | 是 | 可读名称，例如 `东市`、`中心广场`。 |
| `functionType` | string | 是 | 功能类型。 |
| `landformPatchRefs` | string[] | 是 | 该功能区引用的 GIS patch。 |
| `cellShape` | object | 是 | 正常为 `patch_member_cells_union` + `memberCells`；缺少成员格子时降级为 `patch_envelope_union` + block 包围盒。 |
| `areaBlocks` | int | 是 | 面积估算。 |
| `mainBuildingRole` | string | 否 | 主要建筑角色。 |
| `terrainStatsRef` | string | 是 | 对应 `FunctionZoneTerrainStats`。 |
| `groupReason` | string | 否 | AI 分组理由。 |
| `generationNotes` | string | 否 | 程序实体化说明。 |

## BuildOperationPlan

D5 WorldEdit 执行计划。`city_plan_d5` 生成，`city_execute_d5` 执行。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | `build_operation_plan.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `templateDirectory` | string | 是 | 默认 `geomantia_templates/d5`，相对 server root / run 目录约定。 |
| `operations` | object[] | 是 | 世界编辑操作。 |

`operations[]` 关键字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `operationId` | string | 是 | 操作 ID。 |
| `operationType` | string | 是 | `clearVegetation`、`surfaceFill`、`surfaceReplace`、`carveBuffer`、`pasteTemplate`。 |
| `sourceIntentId` | string | 否 | 来源 road / boundary ID。 |
| `polyline` | object[] | 否 | 对道路 / 缓冲区操作使用的 block 折线。 |
| `widthBlocks` | int | 否 | 操作宽度。 |
| `material` | string | 否 | 目标方块 ID，例如 `minecraft:gravel`。 |
| `templateId` | string | 否 | 小模板 ID，例如 `gate_small`。 |
| `anchorBlock` | object | 否 | 模板粘贴位置。 |

## WorldMutationReport

D5 真实执行报告。首版由 WorldEdit 后端生成，不提供持久化 rollback。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | `world_mutation_report.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `backend` | string | 是 | 首版为 `worldedit`。 |
| `executed` | bool | 是 | 是否进入执行流程。 |
| `undoSupported` | bool | 是 | 首版为 false。 |
| `changedBlocks` | int | 是 | 估算变更方块数。 |
| `executedOperations` / `skippedOperations` / `failedOperations` | int | 是 | 操作结果统计。 |
| `operationResults` | object[] | 是 | 每个 operation 的状态和原因。 |
| `warnings` / `failures` | string[] | 是 | 执行 warning 和失败原因。 |
