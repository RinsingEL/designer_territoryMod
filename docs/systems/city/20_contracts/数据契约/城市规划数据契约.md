# 城市规划数据契约

## 定位

本文定义 City 系统 C1-C4 城市规划过程的结构化产物。字段命名先作为契约草案，进入实现时应保持版本化和兼容说明。

## 版本

| 字段 | 当前值 | 说明 |
| --- | --- | --- |
| `schemaVersion` | `city_planning.v0.1` | City 规划契约初版。 |
| `coordinateUnit` | `block` | 对外坐标默认使用 block 坐标。 |
| `gridUnit` | `cell` | 规划图层可使用局部 cell 网格，并必须提供 block 转换。 |

## CityPlanningPackage

城市规划总包，索引 C1-C4 的主要产物。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 当前为 `city_planning.v0.1`。 |
| `cityId` | string | 是 | 城市唯一 ID，来自 T4 或 C 阶段锁定。 |
| `realmId` | string | 是 | 所属国度 ID。 |
| `dimensionId` | string | 是 | 维度 ID。 |
| `seedId` | string | 是 | 对应 `CitySeed` ID。 |
| `siteCandidateId` | string | 是 | 对应 `CitySiteCandidate` ID。 |
| `bounds` | object | 是 | 城市规划范围，block 坐标。 |
| `grid` | object | 是 | 局部规划网格定义。 |
| `terrainPatchMapRef` | string | 是 | C1 产物路径或引用。 |
| `grammarPlanRef` | string | 是 | C2 产物路径或引用。 |
| `functionZoneMapRef` | string | 是 | C3 产物路径或引用。 |
| `boundaryTreatmentMapRef` | string | 是 | C4 边界处理图引用。 |
| `roadNetworkPlanRef` | string | 是 | C4 道路网络引用。 |
| `previewRefs` | string[] | 否 | 调试预览图。 |
| `quality` | object | 是 | 质量评分和 hard block。 |
| `createdAt` | string | 是 | ISO 时间。 |

## Grid

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `originBlockX` | int | 是 | 局部网格原点 block X。 |
| `originBlockZ` | int | 是 | 局部网格原点 block Z。 |
| `cellStepBlocks` | int | 是 | 城市局部规划 cell 尺寸。 |
| `cellsX` | int | 是 | X 方向 cell 数。 |
| `cellsZ` | int | 是 | Z 方向 cell 数。 |
| `blockBounds` | object | 是 | 规划范围 block 包围盒。 |

## TerrainPatchMap

C1 局部地貌事实图。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 可独立版本化，例如 `city_terrain_patch.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `grid` | object | 是 | 局部网格定义。 |
| `patches` | object[] | 是 | 地貌 patch 列表。 |
| `cells` | object[] | 是 | 可压缩存储；每个 cell 指向 patch 和指标摘要。 |
| `metricsProfile` | object | 是 | step、采样半径、micro-sampling 参数。 |
| `previewManifest` | object | 否 | 预览图图例和路径。 |

`patches[]` 关键字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `patchId` | string | 是 | 局部 patch ID。 |
| `landform` | string | 是 | 地貌类型，例如 plain、slope、ridge、waterfront。 |
| `areaBlocks` | int | 是 | 面积估算。 |
| `meanSlope` | number | 否 | 平均坡度。 |
| `waterDistanceBlocks` | number | 否 | 到水体距离。 |
| `tags` | string[] | 否 | 岸线、山麓、台地、森林、湿地等标签。 |

## CityGrammarPlan

C2 城市语法计划。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 例如 `city_grammar.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `cityRole` | string | 是 | 城市功能类型。 |
| `scaleClass` | string | 是 | `hamlet`、`village`、`town`、`city` 等。 |
| `layoutArchetype` | string | 是 | 沿河、环广场、山麓、分散等。 |
| `functionRatios` | object | 是 | 功能区比例目标。 |
| `roadStyle` | object | 是 | 道路风格和连通偏好。 |
| `boundaryStyle` | object | 是 | 边界处理偏好。 |
| `densityProfile` | object | 是 | 密度、留白和公共空间比例。 |
| `aiReview` | object | 否 | AI 给出的风格说明和人工 review 记录。 |

## FunctionZoneMap

C3 功能区图。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 例如 `function_zone_map.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `grid` | object | 是 | 局部网格。 |
| `zones` | object[] | 是 | 功能区实例。 |
| `cellAssignments` | object[] | 是 | cell 到 zone 的映射，可压缩。 |
| `quality` | object | 是 | 比例、连通、越界等评分。 |

`zones[]` 关键字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `zoneId` | string | 是 | 功能区实例 ID。 |
| `name` | string | 是 | 可读名称，例如 `东市`、`中心广场`。 |
| `functionType` | string | 是 | 功能类型。 |
| `areaBlocks` | int | 是 | 面积估算。 |
| `preferredLandforms` | string[] | 否 | 选择依据。 |
| `requiredAnchors` | string[] | 否 | 下游需要落的 anchor 类型。 |
| `roadAccessRequired` | bool | 是 | 是否必须道路接入。 |
| `waterAccessRequired` | bool | 否 | 是否必须水岸接入。 |

## BoundaryTreatmentMap

C4 边界处理图。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 例如 `boundary_treatment.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `edges` | object[] | 是 | 功能区边界对象。 |

`edges[]` 关键字段：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `edgeId` | string | 是 | 边界对象 ID。 |
| `fromZoneId` | string | 否 | 起始功能区。 |
| `toZoneId` | string | 否 | 相邻功能区或外部区域。 |
| `treatmentType` | string | 是 | road、wall、waterfront、green_buffer、stairs、soft_transition 等。 |
| `polyline` | object[] | 是 | block 或 cell 坐标序列。 |
| `widthBlocks` | number | 否 | 宽度。 |
| `priority` | int | 否 | 结构落地时的保留优先级。 |

## RoadNetworkPlan

C4 道路网络。

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 例如 `road_network.v0.1`。 |
| `cityId` | string | 是 | 所属城市。 |
| `nodes` | object[] | 是 | 道路节点。 |
| `edges` | object[] | 是 | 道路边。 |
| `entryNodes` | string[] | 是 | 城市入口。 |
| `coreNodes` | string[] | 是 | 中心区或核心 anchor 接入点。 |
| `connectivityReport` | object | 是 | 连通性报告。 |

## Quality

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `passed` | bool | 是 | 是否通过当前质量门。 |
| `score` | number | 是 | 0-100。 |
| `hardBlocks` | string[] | 是 | 阻断项。 |
| `warnings` | string[] | 是 | 可继续但需 review 的风险。 |
| `metrics` | object | 是 | 面积比例、连通性、越界率、可物化率等。 |
