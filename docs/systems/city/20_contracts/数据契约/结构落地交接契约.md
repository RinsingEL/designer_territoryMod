# 结构落地交接契约

## 定位

本文定义 City 系统向结构落地层交付的最小结构化对象。它不是 Materialization 系统的完整契约，只用于保证 C1-C4 城市规划结果可以被 C5-C8 消费。

## 版本

| 字段 | 当前值 | 说明 |
| --- | --- | --- |
| `schemaVersion` | `structure_landing_intent.v0.1` | City 到结构落地交接初版。 |

## StructureLandingIntent

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `schemaVersion` | string | 是 | 当前为 `structure_landing_intent.v0.1`。 |
| `cityId` | string | 是 | 城市 ID。 |
| `realmId` | string | 是 | 国度 ID。 |
| `dimensionId` | string | 是 | 维度 ID。 |
| `planningPackageRef` | string | 是 | 对应 `CityPlanningPackage`。 |
| `anchorRequests` | object[] | 是 | 关键建筑和公共空间需求。 |
| `reservedAreas` | object[] | 是 | 保留区。 |
| `constraintInputs` | object | 是 | 约束场计算输入。 |
| `poolPreferences` | object[] | 是 | 结构池倾向。 |
| `budgetInputs` | object | 是 | 预算计算输入。 |
| `quality` | object | 是 | 交接质量。 |

## AnchorRequest

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `anchorId` | string | 是 | Anchor 需求 ID。 |
| `zoneId` | string | 是 | 所属功能区。 |
| `anchorType` | string | 是 | plaza、town_hall、well、gate、harbor_core、temple、mine_entrance 等。 |
| `priority` | int | 是 | 放置优先级，数值越高越优先。 |
| `candidateArea` | object | 是 | 候选范围。 |
| `footprintHint` | object | 否 | 尺寸或形状提示，不是最终坐标。 |
| `orientationHint` | object | 否 | 朝路、朝水、朝广场等。 |
| `requiredRoadAccess` | bool | 是 | 是否必须道路接入。 |
| `failurePolicy` | string | 是 | `block_city`、`degrade`、`skip_with_warning`。 |

## ReservedArea

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `reservedAreaId` | string | 是 | 保留区 ID。 |
| `source` | string | 是 | anchor、road、boundary、waterfront、public_space 等。 |
| `geometry` | object | 是 | block 或 cell 坐标几何。 |
| `hardness` | string | 是 | `hard` 或 `soft`。 |
| `reason` | string | 是 | 保留原因。 |

## ConstraintInputs

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `terrainPatchMapRef` | string | 是 | C1 地貌图。 |
| `functionZoneMapRef` | string | 是 | C3 功能区图。 |
| `boundaryTreatmentMapRef` | string | 是 | C4 边界处理图。 |
| `roadNetworkPlanRef` | string | 是 | C4 道路图。 |
| `hardNoBuildSources` | string[] | 是 | 需要转成硬禁止的来源。 |
| `softCostSources` | string[] | 是 | 需要转成软代价的来源。 |

## PoolPreference

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `targetId` | string | 是 | `zoneId` 或 `anchorId`。 |
| `targetType` | string | 是 | `zone` 或 `anchor`。 |
| `functionType` | string | 是 | 功能类型。 |
| `styleTags` | string[] | 是 | 国度和城市语法给出的风格标签。 |
| `materialTags` | string[] | 否 | 材料倾向。 |
| `densityIntent` | string | 否 | low、medium、high。 |
| `heightIntent` | string | 否 | low、mixed、tall。 |
| `poolWhitelist` | string[] | 否 | 可选结构池白名单。 |
| `poolBlacklist` | string[] | 否 | 可选结构池黑名单。 |

## BudgetInputs

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `zoneAreas` | object | 是 | 功能区面积。 |
| `usableAreaHints` | object | 是 | 扣除道路、保留区和硬禁止后的可用面积估计。 |
| `averageFootprintHints` | object | 否 | 结构 catalog 给出的平均 footprint。 |
| `machineBudgetClass` | string | 是 | 当前执行预算等级。 |
| `retryPolicy` | object | 是 | 重试次数和降级策略。 |

## MaterializationTrace 引用

结构落地层执行后应回写 trace。City 契约只要求 trace 能被索引：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `traceId` | string | 是 | trace ID。 |
| `cityId` | string | 是 | 城市 ID。 |
| `intentRef` | string | 是 | 对应 `StructureLandingIntent`。 |
| `status` | string | 是 | `passed`、`partial`、`failed`。 |
| `failureCategories` | string[] | 否 | 失败分类。 |
| `debugRefs` | string[] | 否 | 调试图、报告或日志路径。 |

## 交接质量门

| 检查 | 通过口径 |
| --- | --- |
| Anchor 完整 | 所有必需 anchor 都有候选范围和失败策略。 |
| 保留区完整 | 道路核心、公共空间、anchor 范围被标记。 |
| 约束输入可回溯 | 每个 hard / soft 来源能回到 C1-C4 产物。 |
| 预算可计算 | 面积、密度和机器预算字段齐全。 |
| AI 不越界 | AI 只提供风格和倾向，不直接填最终 jigsaw 深度、半径和 piece budget。 |
