# City 产品案类型入口

本目录已经位于 `systems/city`，第一层不再重复设置 `City/`，只按**案子类型或跨模块职责**分类，不直接暴露内部阶段目录。进入具体工作时先选择类型，再读取该目录自己的索引；不得为了定位一个需求而预加载其他类型。

| 类型 | 入口 | 收录范围 |
| --- | --- | --- |
| 具体流程的案子 | [`具体流程的案子/README.md`](./具体流程的案子/README.md) | City 内部蓝图、建筑阵列、LandUse、城市基面、路网、边界与装饰的具体实现流程。 |
| GIS | 有实际产品案时创建 `GIS/README.md` | GIS 采样、地貌分析和空间数据产品；当前没有独立案。 |
| 跨模块 | [`跨模块/README.md`](./跨模块/README.md) | 同时改变多个大功能且无法归入单一负责人时使用；不得把普通跨阶段案误放进来。 |

新增案子类型时只在本页增加一条入口；具体案子身份、阶段分类和职责链唯一性写在对应类型索引中。
