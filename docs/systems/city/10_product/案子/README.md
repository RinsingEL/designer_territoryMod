# City 当前产品案

本目录只保留当前实现案、明确的设计中案和仍被当前实现引用的能力参考。已替代方案、完成后的开发计划、未来草案和单次测试城市均不保留；legacy/debug endpoint 的精确输入输出只维护在 MCP 契约和测试入口。

## 当前案子

| 案子 | 职责身份 | 当前作用 |
| --- | --- | --- |
| `City单次递归蓝图与自愈编译-v0.1` | **实现当前案**（D4 蓝图编译链） | AI 先读取 GIS 地形和模板材料并提交一份递归蓝图；程序先按蓝图落第一批建筑，再由建筑形成初始功能区，处理相向连接、两两冲突和占比扩张，显式 Patch 禁止搬家。 |

## 维护规则

- 产品案只解释当前职责和取舍，字段真值回到 `20_contracts/`。
- 同一职责链只能有一个 **实现当前案**；**设计中案**在用户明确接管前不得参与实现和验收；**能力参考**不得覆盖所属职责链的实现当前案。
- 能力并入主线后继续更新现有案子，不新增“最终版”或并行版本说明。
- 不为已删除实现保留当前目录文档；需要追溯时使用 Git 历史。
- 未进入实现的方向不放入本目录，先在对话中完成方案冻结。
