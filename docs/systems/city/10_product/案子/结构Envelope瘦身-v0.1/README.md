# 结构Envelope瘦身-v0.1

## 修改目的

当前结构 envelope 仍带有旧路径的保守兜底特征：`safetyEnvelope` 会把结构之间的避让距离撑得过大，使 D4 阵列在已经由程序预选点、程序排布的情况下仍表现得像是在防御 AI 随机落点，导致结构 plan 完成后建筑群过散、组团感弱、缺少真实聚落应有的生活气息。

本案的修改目的，是删除 `safetyEnvelope` 这一层硬语义，让结构布局回到更直接的两层边界：用统计预处理得到的稳定 `collisionEnvelope` 控制结构本体不相撞，用小边距 `maskEnvelope` 负责 D5 保留区与世界生成保护；从而让阵列中的建筑间距收敛到更紧凑、可读、有人居密度的范围。
