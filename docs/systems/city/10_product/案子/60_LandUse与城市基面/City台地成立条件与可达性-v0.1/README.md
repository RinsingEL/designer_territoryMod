# City 台地成立条件与可达性

## 案子身份

- 职责身份：**设计中案**，尚未接管当前实现。
- 主责任阶段：D6 后 LandUse / Foundation 编译与 worldgen 执行。
- 涉及阶段：D4 冻结建筑、建筑地块、入口和道路需求；D6 锁定 footprint；LandUse 决定台地；D7 验收真实可达性。
- 上游输入：冻结建筑 footprint、建筑地块、真实入口、正式道路、显式景观与 Foundation mask。
- 下游产物：有用途的台地组件、台地邻接图、挡土边界、楼梯或短引路、结构 datum 和可审查原因。

## 开发状态

2026-08-30 记录。当前只完成问题定位和修改口径，**尚未开发、尚未测试**。在本案完成前，既有《City城市基面与路网形态-v0.1》继续负责已经验证的台地合并、孔洞闭合、建筑同高、道路直梯与左右分流梯；本案只处理新发现的成立条件和可达性缺口。

## 验收发现

全量农业 Catalog 大城完成 D5-D7、33/33 结构与 306/306 LandUse owner 后，真实游玩发现：

1. 城市中存在面积较大但没有建筑、景观或交通用途的空台面。
2. 很多台面没有楼梯；检查确认当前主动楼梯只在正式道路跨越高低台地时触发。

本次确认的简要问题定义：**空台面会被错误保留；楼梯只认道路。台面必须有真实用途才能独立保留，承载建筑的独立台面必须至少有一个可通行入口。**

## 当前错误机制

当前执行层先把局部主高程按 4 格一级量化，再将同高连续格组成台地。面积小于 64 格的组件会并入邻台；达到 64 格的组件可以直接保留。这里的 `64` 只证明图形面积，不证明台地有使用价值，因此空地也能成为正式独立台面。

当前主动楼梯只扫描同一正式道路来源的相邻 `ROAD_SLAB`：道路两格跨越至少一个台地等级时，才尝试生成直梯或左右分流梯。建筑 footprint、建筑入口、建筑地块和“该台地必须可达”的义务没有进入楼梯候选，因此没有道路穿越的建筑台地可能只有挡土墙。

```text
当前：

面积 >= 64 ───────────────→ 保留独立台地
                                │
道路跨越高差 ─────────────→ 才生成楼梯

结果：空台面可以成立；无道路的建筑台面可能不可达。
```

## 修改口径

### 1. 面积不是台地成立理由

独立城市台地必须同时满足：

- 高度差达到正式台地等级；
- 几何面积能够承载其冻结内容；
- 至少命中一种真实用途：冻结建筑、建筑地块、显式开放空间、显式景观主体或 Blueprint 明确保留的地形节点；
- 能够获得合法通行入口，或 Blueprint 明确声明为不可进入的纯景观高地。

没有任何用途锚点的组件即使超过 64 格，也不能仅凭面积成为独立台地。程序应优先把它并入共享边界最长、其次高度最近的相邻主台地；无法安全合并时缩减 Foundation，而不是制造铺装空台。

农业、林场等显式保留自然地形的 Landscape Parcel 不属于城市铺装台地，不得因为本案被强制整平成城区平台。

### 2. 每个占用台地必须有可达性义务

台地锁定后，程序应建立台地邻接图。每个包含建筑、建筑地块或可进入开放空间的独立台地至少产生一个 `accessDemand`：

- 首选复用已经穿越高差的正式道路，在道路边界生成楼梯；
- 没有道路穿越时，从真实建筑入口或开放空间入口选择最近合法高低边界，生成短引路和楼梯；
- 正面纵深足够时使用直梯；不足而两侧低地空间足够时使用已确认方向的左右分流梯；
- 无法生成合法入口时必须输出明确失败原因，不能静默留下不可达建筑台地。

纯景观且明确不可进入的高地可以没有楼梯，但必须携带显式用途和不可进入声明，不能由程序从面积自行猜测。

### 3. 楼梯仍然稀疏且服务真实目的地

本案不是沿每条挡土边缘铺满楼梯。默认每个占用台地先满足一个主要入口；只有多个冻结入口、台地尺度或真实交通需求证明需要时才增加第二入口。其余高差边继续使用挡土墙。

```text
目标：

冻结建筑/景观用途
        │
        ▼
台地是否值得独立存在？──否──→ 合并邻台或缩减 Foundation
        │是
        ▼
是否可进入？──────────否──→ 显式纯景观高地
        │是
        ▼
已有道路跨越？──是──→ 道路楼梯
        │否
        ▼
入口到最近合法边界的短引路 + 直梯/分流梯
```

## 计划中的执行顺序

1. D4 冻结建筑、建筑地块、显式景观、真实入口和正式道路，不在此时猜最终高度。
2. D6 后按真实地形形成初始量化台地组件。
3. 为每个组件汇总用途锚点和占用内容，再执行独立台地成立判断。
4. 合并无用途组件，锁定最终台地高度和结构 datum。
5. 闭合台地内部偶发干坑与小水坑。
6. 建立台地邻接图，为所有可进入的占用台地满足至少一个 `accessDemand`。
7. 生成直梯、左右分流梯或明确失败；其余边界生成挡土墙。
8. D7 通过 worldgen 账本和真实游玩验证用途、可达性、楼梯方向与数量。

## 验收标准

- 不存在仅因面积达到 64 格而保留的铺装空台面。
- 每个包含建筑或可进入开放空间的独立台地至少有一个实际可走入口。
- 没有正式道路穿越时，建筑入口仍可通过短引路和楼梯连接相邻可达台地。
- 楼梯只服务真实目的地，不沿整圈挡土墙泛滥生成。
- 直梯与左右分流梯保持既有方向口径：分流梯左右两端连接低地、中央连接高地。
- 农田、林场等自然地形 Landscape 不被误并入城市铺装台地。
- 预览与 D7 报告能分别显示台地用途、合并原因、入口需求、楼梯选择和失败原因。
