# D4 建筑朝向与面向公共空间

**设计中案 · 2026-10-14**。让 D4 设计者能决定重要建筑的正面朝向，使地标与二级建筑面向广场、主轴或街道。所属职责链为 D4 设计循环，接管前[按功能区设计城市](../按功能区设计城市/README.md)仍为实现当前案。

## 为什么需要

<small>原话：“广场主要是因为他设计进入到水体了，也不知道为什么没有假设起台地，不过我觉得其他的还可以了”</small>

<small>原话：“其他的都麻烦你处理一下呗”（2026-10-14，授权整理设计缺口）</small>

**AI 总结：** D4 构图手法要求公共空间被建筑围合、重要建筑面向广场与主轴。目前只有庭院阵列里的建筑能统一朝内，其他建筑的朝向无法由设计者决定：工作台对照示范中藏书馆、食堂面向广场依靠的是工作台专有的旋转设置，正式 D4 做不到；独立 Agent 的学院方案里，广场旁的建筑也因此没有面向广场。

## 由设计者决定重要建筑的朝向

**AI 总结：** 设计者可以为单栋核心建筑、二级地标或一组建筑指定正面朝向：朝向某个公共空间（广场、庭院、花园）、朝向主轴或某条街道，或直接指定东南西北。程序依据作者标注的入口方向换算建筑的实际摆放，入口前留出可通行的空间，并让道路接到这个入口。未指定时保持现有的自动朝向。作者没有标注入口的素材不能被指定朝向，预览中如实提示。

## 检查与预览

**AI 总结：** 预览中能看出每栋重要建筑的正面朝向。朝向与地形、碰撞或道路冲突时，以反馈说明原因，由设计者调整位置或朝向，不悄悄改成别的朝向。D4 构图手册中的“围合公共空间的建筑面朝公共空间”据此由庭院以外的建筑也能做到。
