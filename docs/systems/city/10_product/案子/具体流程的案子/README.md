## 维护规则

- 产品案只解释当前职责和取舍，字段真值回到 `20_contracts/`。
- 分类目录表示主责任，不表示案子只能涉及该阶段；案子 README 必须注明主责任阶段和涉及阶段。
- 同一职责链只能有一个 **实现当前案**；**设计中案**在用户明确接管前不得参与实现和验收；**能力参考**不得覆盖实现当前案。
- 能力并入主线后继续更新现有案子，不新增“最终版”或并行版本说明。
- 已替代方案、完成后的开发计划、未来草案和单次测试城市不保留；需要追溯时使用 Git 历史。
