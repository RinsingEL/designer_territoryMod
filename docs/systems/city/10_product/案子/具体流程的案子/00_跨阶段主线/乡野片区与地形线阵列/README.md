# 乡野片区与地形线阵列

**案子身份：实现当前案（乡野拼图、稀疏组合与地形线排布新增能力）· 2026-10-21 用户授权接管；程序与手册已接入，自动验证通过，真实画面待验收。** 用户希望在录制第一期开发日志之前完成，排入 0.3.0。本案新增两类空间组织：大片田林中稀疏散布小房屋组的“乡野片区”，以及让建筑沿海岸、河岸、等高线或峡谷排开的“地形线阵列”。接管开发时，需与现行的[景观独立空间与代价生长](../City景观独立空间与代价生长-v0.1/README.md)（景观链）和[阵列主从骨架与街带](../../30_D4蓝图编译/City阵列主从骨架与街带-v0.2/README.md)（阵列链）明确分工：本案新增的景观形态与阵列算法由本案负责，既有能力保持原样。AI 如何在设计中使用，见 D4 [按功能区设计城市](../../30_D4蓝图编译/按功能区设计城市/README.md)的“场地盘点”。

## 大片田林，中间散着几户农舍

<small>原话：“我昨晚有点疑惑农田、树林的landuse的作用，感觉他们没有达到过我的设计预想，我最开始是希望能够形成一种大片大片的一块一块的不规则麦田或者树林，中间稀稀疏疏偶尔来点小房屋组（如谷仓+风车+几个小房子）。这个是不是一种阵列方式呢？”</small>

**AI 总结：** 现在的农田景观每块只有 192～512 格，一处最多 12 块，最大约 39×39 格，拼出来是几块菜地，不是大片麦田；林地同样从一个种子点按格数长出，规模也小。景观又挂在某个功能区下面，作为附属存在，没有办法在田野里稀疏地点缀建筑。

你描述的画面分两层：

```text
底：大片田林拼图（景观）          点：稀疏的农舍组（阵列）
┌───────┬──────┬────┐
│ 麦田   │ 树林  │麦田│          [谷仓+风车+2～3 小屋]  ← 一组是一个小组合
│  ~~~~  ├──┬───┘    │              …… 相隔很远 ……
├────┬──┘  │ 菜田     │          [谷仓+风车+小屋]
│ 林  │ 麦田 │  ～～   │          放在平地、路边、水边，
└────┴─────┴──────┘          不排成网格
```

### 底：田林拼图

- **大块、不规则、顺着地形。** 每块可以有几千格，轮廓沿等高线和水边弯曲，不切成方格。
- **多种内容拼在一起。** 不同作物（麦、菜、果园）与树林块相邻，块与块之间用田埂、小路、树篱或水渠分开。
- **顺应地形，不大动土方。** 缓坡上的田沿等高线排列，陡坡、洼地留给树林或草地。
- **树林可以保留或种植。** 城外乡野中成片的原生树林可以作为林块保留；需要新林块时种作者提供的树木。城区内部仍按[城区地表与公共绿化](../聚落空间与地表升级/03_城区地表与公共绿化.md)的规定，不用原生植被凑数。

### 点：散布阵列

- **一个单位是一个小组合。** 例如谷仓、风车加两三间小屋，组合内部按普通阵列排布。
- **单位之间相隔很远、不排成网格。** 间距大且不规则，彼此之间是大片田地；AI 决定大致数量与疏密，程序负责具体落位。
- **挑合适的位置。** 优先平地、路边、水边，面朝道路；每个单位用小路接到乡间道路上。

### 乡野片区

田林拼图与散布阵列合起来是一种功能区类型：乡野片区。它属于【工作】（农林）与少量【居住】（农户住在农舍组里），可以是城市的外围片区，也是 0.6.0 小村庄与城际乡野的同一套机制。

## 沿地形线排布的阵列

<small>原话：“还有就是比如港口这种，我的感觉是他们和‘海岸’之类的是相关联的，所以是不是可以加上新的阵列算法呢，感觉这样就可以处理峡谷这种了。”</small>

**AI 总结：** 现在的直线阵列只能按固定方向排成一条直线；景观有“沿水生长”，建筑阵列没有。新增一类阵列：让建筑沿着一条地形线排开。

| 地形线 | 怎么排 | 例子 |
| --- | --- | --- |
| 海岸、河岸、湖岸 | 第一排贴岸、正面朝水，第二排在其后；码头、栈桥伸入水中 | 港口货栈、渔村、河埠 |
| 等高线 | 沿山坡一层层排列，每层一个台阶，层间用阶梯相连 | 山城、坡地民居 |
| 峡谷 | 两侧崖边各排一列、面朝峡谷，用桥连接两岸；或沿谷底河道排列 | 峡谷城、矮人凿壁排屋 |

- **AI 说“沿哪条线”，程序找线。** 程序从 D3 地形中提取岸线、等高线和峡谷边缘，作为可选的地形线提供给 AI；AI 按方位或名称选用（例如“沿东岸”“沿北坡”），不需要描坐标。
- **程序处理排布细节。** 沿线按间距放置成员，朝向取最接近地形线法向的正方向，按排数向内侧后退；弯曲处分段处理，高差交给台地与基础。
- **端点设施。** 码头、栈桥、桥梁作为地形线阵列的配套：码头接在第一排前方伸入水中，峡谷两岸的桥作为明确的道路连接。

## 为什么值得早做

<small>原话：“可以的！而且我希望更早一些？我感觉可以作为0.1.0版本的小尾巴补充？”</small>

**AI 总结：** 这两类组织让城市的形状由地形长出来：港城沿岸弯成一条弧，峡谷城夹在两岸，大城外面是大片田野。这是“每局都不一样”最直观的来源，也是固定阵列做不到的。用户希望在第一期开发日志录制之前完成，因此排入 0.3.0，在 D4 失败验收整改之后进行；整改让 AI 学会展开功能、盘点场地，本案再给它在场地上表达的新工具。

验收以真实画面为准：用一座有海岸或大片平地的城市，由 AI 设计乡野片区和沿岸港区，看田野是否大片、不规则、点缀稀疏，港区是否贴岸成弧、面朝水面。不设面积、数量或覆盖率门槛。

### 沿崖与港口起重机（2026-10-21 确认）

<small>原话：“对的我不想要挂在上面的，我要的就是这种沿着的，这个在港口上也适用。”</small>

**AI 总结：** 多个起重机沿崖顶或岸线排布，底座在高侧或岸侧、作业面朝峡谷或水面，不要求挂在垂直崖壁上。沿线排列与道路是否铺设应能分开决定；当前程序仍自动规划沿线小路，独立道路开关尚未实现。底座精确贴边、吊臂悬挑还受素材支撑范围和退距处理限制。
