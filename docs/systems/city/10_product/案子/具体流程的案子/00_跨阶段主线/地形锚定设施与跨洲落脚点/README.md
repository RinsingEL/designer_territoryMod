# 地形锚定设施与跨洲落脚点

**设计中案 · 2026-10-14**。在阵列式城市之外，增加一种沿着特定地形生成的建造方式：港口、堤坝、河边栈桥、峡谷边的吊车与升降台等。它们既是城市贴着地形长出的边缘设施，也能独立成为其他大陆上的落脚点。总纲见[异世界冒险体验](../../../../../../../10_product/异世界冒险体验/README.md)。

```mermaid

  D --> E[跨大陆旅行的第一站]
```

## 沿着地形长出的建造

<small>原话：“对于这个城市生成过程，我在考虑要不要做一个沿着某个地形的生成方式，比如港口、堤坝、河边的栈桥、还有峡谷外面一圈的吊车这种”</small>

**AI 总结：** 现有城市按阵列在平整的台地上排布建筑；本案新增另一种方式：先在地形上找出一条线或一处边缘，再沿着它布置设施。

| 地形 | 设施 |
| --- | --- |
| 海岸、海湾 | 港口、码头、栈桥、灯塔、船坞 |
| 河岸、湖岸 | 河埠、栈桥、渡口、堤坝与水车 |
| 峡谷与断崖边缘 | 沿崖的吊车、升降台、悬空栈道、崖边哨所 |
| 山口与高地 | 关隘、瞭望塔、沿坡的阶梯与缆道 |

设施的形状跟随地形走向，例如栈桥垂直伸向水面，吊车沿峡谷边缘排成一圈，堤坝顺着河道延伸。现有的岸边接驳与港口预留只留出位置，本案让这些位置真正建起来。

## 城市的边缘设施

**AI 总结：** 临水、临崖的城市在设计时可以选择沿边缘生成设施，使城市与地形连成一体：港口城有码头和灯塔，河边城有栈桥和堤坝，峡谷城有吊车往来于崖上崖下。设施与城市道路相连，属于该城的一部分。

## 跨大陆的落脚点

<small>原话：“如果有这个我们从一个大陆到另一个大陆到时候，就有落脚点了”</small>

**AI 总结：** 在没有城市的海岸、河口与峡谷边，也可以单独生成小型地形设施，例如一座小港、一处渡口、一个崖边哨站。它们是玩家抵达新大陆后的第一站：可以靠岸、歇脚、补给，并从这里听到附近城市的消息。落脚点有少量居民和委托，与城际道路、商队和传闻相连；其风格属于所在国度，无主之地则为中立或荒废的设施。
