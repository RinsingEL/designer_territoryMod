# 案子 02：D4 程序化城市编译器

## 目的

把 D4 中已经具备的模板校验、候选生成、阵列扩张、碰撞检查、occupied 冻结和锚点输出能力，收束成一个完全程序化的城市编译器。

编译器消费案子 01 的 `CityBlueprint`，自动完成结构 Group 的实际落点选择。正式主链不再等待 AI 或人工选择候选。

## 输入与输出边界

输入：

- 已校验的 `city_blueprint.json`。
- D3 地形与 patch 真值。
- TerraSense 结构画像与 tag 真值。
- structure envelope facts。
- 模板池、算法和选择策略目录。
- 已有结构 ledger 或 occupied 上下文。

输出：

- `city_generation_compile_trace.json`
- `group_extent_map.json`
- 标准 `structure_anchor_plan.json`
- 标准 `structure_anchor_map.json`
- 结构锚点与 Group 范围预览。

标准锚点产物继续交给现有 D5/D6，不为新编译器建立下游特殊分支。

## 编译过程

### 1. 蓝图装载

- 重新校验 D3 hash、目录 hash 和 schemaVersion。
- 解析结构 Group、关系、硬约束和软目标。
- 为所有 Group 建立稳定的执行顺序。

### 2. 核心种子落地

- 按优先级先处理所有 `requiredStructureRefs`。
- 从 `primaryPatchRef` 的 member cells 生成候选。
- 过滤越界、碰撞、patch 所有权和地形策略不允许的候选。
- 核心结构全部成功后，才允许自由扩张。

### 3. 程序化扩张

- 从 Group 开放边缘生成阵列候选。
- 只使用 `algorithmProfileRef` 指向的算法配置。
- 从 `fillPoolRef` 指向的模板池选择结构。
- 使用 `selectionPolicyRef` 控制权重、数量上限和连续重复。
- 每次提交后原子更新 patch 所有权与 occupied field。

### 4. 自动评分与选择

候选评分至少考虑：

```text
符合 Group 关系
+ 符合扩张算法
+ 保持 Group 紧凑
+ 合理使用可认领空间
+ 地形兼容程度
- 碰撞风险
- 越界代价
- 过度地形改造代价
```

评分相同或接近时，使用稳定排序键与 `generationSeed` 做可复现选择。禁止依赖系统时间、集合遍历顺序或未记录随机源。

### 5. 锚点冻结

- 冻结结构 anchor、旋转、collision envelope 和入口端点。
- 冻结 Group 实际认领范围和 `actualScale`。
- 输出现有 D5/D6 能直接消费的标准锚点产物。

## 硬约束与软目标

硬约束：

- `requiredStructureRefs` 必须全部落地。
- 平级 Group 起始 patch 不得冲突。
- 已认领 patch 不得被其他平级 Group 抢占。
- collision envelope 不得与已冻结结构重叠。
- 程序不得自行删除 Group 或替换城市主题。

软目标：

- `scale`。
- 自由填充数量。
- 景观和结构密度。
- 在多个合法方向之间的偏好。

软目标可以因真实容量缩小，但必须记录 `actualScale` 和停止原因。

## 失败规则

- 蓝图或目录失效：立即停止，返回蓝图校验错误。
- 必要结构无合法落点：编译失败，不进入自由扩张。
- patch 容量不足：允许软规模缩小，不允许省略必要结构。
- 所有候选都被过滤：记录每类过滤原因和最终停止原因。
- 不得在失败后重新请求 AI 逐候选处理。
- 不得通过放宽 collision、伪造 patch 所有权或跳过 D6 来制造成功。

## 现有 D4 能力处理

保留并内部化：

- 关键结构先于阵列的顺序约束。
- candidate generation。
- array layout algorithms。
- collision / occupied 校验。
- anchor freeze 与标准 finalize。
- 候选与最终锚点预览。

降级为显式调试入口：

- 顺序候选 session。
- AI/Codex 候选选择。
- 结构群整组比较。
- 手工 `candidateId` 提交。

## 不做事项

- 不实现 `LANDSCAPE` Group。
- 不生成道路、城墙或道路附属物。
- 不实现 Foundation Program。
- 不实现最终地表细节填充。
- 不改变 D5/D6/D7 的 artifact 与 worldgen 准入边界。
- 不负责删除旧装饰系统。

## 验收口径

- 输入合法蓝图后，无需 AI 或人工即可生成最终结构锚点产物。
- 所有必要结构先于自由扩张落地。
- 每次选择都有候选、过滤、评分和提交 trace。
- 同一输入和随机种子产生相同结果。
- 输出可直接进入现有 D5/D6。
- 容量不足、碰撞和地形失败均有明确 reason code，不出现静默降级。
