## 真实游玩测试

启动：

```bash
.\gradlew.bat runClient -PgeomantiaDevUseReTerraForged=false -PgeomantiaDevUseStructurePacks=true
```

规则：

- 使用 vanilla-like 新存档，禁用 RTF。
- 启用结构包。
- 必须使用未生成目标区域，或删除目标区域 region 后测试；不得复用已生成森林现场作为正式验收。
- 不复用旧 `city_realm_green_court_2_port`。
- 从新的 `city_seed_registry.json` 选择未跑过 D3 的新城市。
- 优先非港口样本、较大平地 / 缓坡 patch、少水体切割、离玩家近的城市。

流程：

```text
realm_run_acceptance 或已有新 run
city_plan_d3
city_profile_structure_envelopes
city_plan_d4 { terrasenseProfileSource, structureAnchorPlan }
city_plan_d5
city_plan_d6
city_execute_d5 { confirmWorldMutation: true }
city_execute_d7 { executeStructurePlacement: false }
从目标 chunk 外侧靠近/TP 触发首次 worldgen
city_execute_d7 { executeStructurePlacement: true }
```

chunk 未生成：

- 如果 D6 / D7 trace 出现 `WAITING_FOR_WORLDGEN`，按 trace 中 anchor / required chunk range 从目标 chunk 外侧触发首次生成。
- worldgen 后重复 `city_execute_d7` 查询 ledger。
- waiting 不算失败。

真实验收：

- D4 reservedEnvelope 之间不重叠。
- Trek 测试结构有 `structure_envelope_facts.json`，D4 使用 P95 collision envelope / P99 mask envelope。
- worldgen hook 写入的 actual bbox 未突破 D4 reservedEnvelope。
- D7 ledger `startSignature` 与 worldgen hook 记录一致。
- `placed_structure_ledger.json` 无重复、无重叠。
- 结构没有漂移、错位或压到其他结构。
- 新生成 chunk 的 road / envelope mask 内不生成树。
- 原版自然结构不抢占 `noVanillaStructureMask`。
- trace 能解释等待、失败、越界、重叠和耗时。

## 质量阻断

以下情况不得通过验收：

- D4 / D6 仍接受旧 `patchGroupPlan`、`functionType`、`functionTag`、`structureChoicePlan`、`plannedFixedPlacementMap` 等字段。
- active endpoint 仍产出或消费 `function_zone_map.json`、`buildable_area_map.json`、`planned_fixed_placement_map.json`、`structure_pool_map.json`。
- D6 dry-run 修改世界或 execute_d7 false 写入真实 ledger。
- execute_d7 正式路径调用 `StructureStart.placeInChunk` late paste。
- Trek 测试结构缺少 envelope facts 却回退旧保守半径。
- debugLateMaterialize 结果被当作正式验收通过。
- mask hook 不可用却静默退化。
- chunk waiting 被当作结构失败。
