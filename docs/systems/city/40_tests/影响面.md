# City LandUse、Decoration 与建筑群生活感影响面

## 主链变化

当前新增可选步骤：`D4 -> D5 预案 -> D6 locked footprint -> LandUse -> Decoration -> execute_d5`。它不改变 D4 先落建筑的职责，也不恢复旧 FunctionZone 主线。

| 环节 | 变化 | 回归重点 |
| --- | --- | --- |
| D3 | 新增 `LandUseTerrainField` 粗格事实；临水生活感切片只消费现有 `water`、`shore`、`waterDistance`、`plain` 与坡度。 | 不主动加载 chunk；原 patch / biomeSummary 不回归；不得引入虚构资源扫描。 |
| D4 | anchor / array / composite 输出稳定 group provenance；阵列项可按中心、水体或 cardinal 目标自动选择模板朝向。 | 不恢复旧 FunctionZone；自动朝向只枚举目录允许旋转，不改变候选点与 collision / mask 口径。 |
| D5 / D6 | D5 仍是轻量预案；D6 locked footprint 成为 LandUse 最终硬排除。 | 不提前冻结 LandUse，不改变结构锁定与城墙 reservation。 |
| LandUse / Decoration | intent v0.2 按需覆写地表印刷、自动连接、方块与方向；程序对 64 格内兼容 PAVE / CULTIVATE 做双向引导扩张。SurfacePrintPlan 接管批量地板、耕地、作物和 lined 水槽，Decoration 只保留稀疏内容。 | `autoConnect=false`、超距、异类或地形阻断不得连接；不得恢复事后桥线。Surface-owned area 的 `uniform_fill/cross_section_repeat/parallel_rows` Decoration 必须拒绝，scatter / edge / grid 稀疏程序仍可用。 |
| 关键装饰候选 | `city_plan_decoration_anchor_candidates` 在正式 dressing 前，为 required 单点 prefab 生成完整 footprint + clearance 候选；多个关键装饰按顺序选，前面已固定 programs 作为障碍。 | 不改变最终 DecorationProgram schema；只返回相对 `coordinateFramePatch`。普通 Pattern 不进入候选；不得采样地形、加载 chunk、自动选择或伪造空集 fallback。 |
| execute_d5 | 校验 area / surface / completion / catalog identity，预构建 owner index，再与 Decoration frozen plan 一起激活。 | sampler 不加载 chunk；缺 surface artifact、hash / catalog 漂移和批量职责冲突在 registry mutation 前 hard fail；legacy v0.1 active/ledger 仍可读取。 |
| noise worldgen | Beardifier 合并 Decoration 与 LandUse 的 common fill-only foundation；后续规划的全部 `geomantia:` 城市模板仍以单-piece `StructureStart` 进入 `beard_thin`。 | 两来源 segment 按 owner 索引、稳定去重并取最大正贡献，不叠加抬高；停用 plan 后立即为空，compute 内无 registry mutation / IO / 高度采样。 |
| FEATURES | owner 只消费 prepared 局部索引，按 `BASE -> NBT -> CROP -> BOUNDARY` 落地；水槽 targetY 与完整 footprint `MATERIALIZE|FALLBACK` decision 均由首次相关 owner 在首写前冻结并跨 owner / 重启复用。 | 内容不适配只回退该 placement 的精确 crop/boundary cells；不可写、快照或写入失败仍整 owner 回滚；decision 落盘失败零首写，跨 chunk 不得各自重判。 |
| RoadWeaver | 仍按真实路线后写。 | 道路可覆盖 LandUse，LandUse 不猜路线、不抢最终 surface 权威。 |

## 配置与兼容

- 新配置根目录 `config/geomantia/city_land_use/` 含 `settings.json` 与 `profiles/<profileId>.json`；默认 `enabledInWorkflow=false`、profile 为 `default_v0_1`，规则档案保持严格 `city_land_use_rules.v0.1`。64 格自动连接距离是程序默认，不进入 profile 或 AI 配置；缺失 bundled 文件才补装，不覆盖用户文件。
- 请求 `enableLandUseLayer` 优先于 settings；未显式开启且配置关闭时，现有 workflow 行为与 artifact 保持不变。
- 独立 `city_plan_land_use` 是显式规划入口，可不传 intent；服务端自动使用空 overrides。
- intent 使用 `city_land_use_intent_plan.v0.2` 严格 schema；旧 continuity 语义明确拒绝且不自动迁移。省略 intent 时服务端生成空 v0.2 intent，并按 policy 使用稳定的印刷 / 自动连接 / 方块 / 方向默认值。area plan 保持 v0.1，SurfacePrintPlan 为 v0.1，active 为 v0.2；ledger 升 v0.3 并兼容读取 v0.1/v0.2。
- 默认 material palette 新增 `MICRO_FILL_SUBGRADE=minecraft:dirt` 并进入 `paletteHash`；因此只对新激活计划启用。已冻结的旧 active palette 缺少该键时保持关闭，不因代码升级改变未生成 owner 的地形行为。
- Decoration content index / program 当前为 v0.3。v0.2 可只读解释但 query 必须显式报告 upgrade required；仅 managed 且未改动的旧默认 catalog 可经确认、备份后升级，自定义 catalog 不自动改写。
- 关键装饰候选不新增配置或持久化 selection state；复用当前 decoration catalog/style、program v0.4 target、D5/D6/LandUse 硬障碍和现有相对坐标字段。
- 已到 FEATURES 的 chunk 不回填。启用后只影响未来首次生成 chunk；停用不回滚已写世界。

## 风险与验收责任

- 算法风险：引导目标漏选 / 误选、背向仍扩张、地形阻断失效、大片单色或农田整体矩形。以 v0.3 `automaticSurfaceConnections[]`、64 格边界测试、spans 非 bbox、单轴 / 辐射预览和固定 seed 验收。
- 朝向风险：目标引用不可解、入口声明含糊、自动旋转破坏紧凑度或结果不稳定。以候选组合测试、`orientationDecision` 和现场门面复核验收。
- 关键装饰风险：只检查 anchor 点导致大 prefab 越界、AI 独立规划多个点后互相重叠、把未采样地形误报为安全，或空候选时退回手写世界坐标。以完整 footprint/clearance、`fixedDecorationObstacles`、`terrainSampling=not_performed`、空集 rejectionCounts 和候选回填后单 slot 一致性验收。
- 世界写风险：材质覆盖自然 / 结构、水槽上层覆盖、跨 chunk 接缝、partial write。以完整 footprint 共享 decision、精确 fallback、系统错误 owner 回滚、prefab/crop/boundary footprint 冲突、无通知 `x=15/16` 连接回归与 ledger 验收；真实 `WorldGenRegion` 跨 chunk 只读预检仍需实机复验。
- 微整地风险：把开放沟谷误判为坑、跨 owner 判定不一致、邻水造地或局部半填。以同 area halo、连通面积 / span / depth 上限、水体拒绝、旧 palette 门控、GameTest 和新区块现场验收。
- 顺序风险：Decoration 早于 LandUse、RoadWeaver 被 LandUse 回盖。以集成测试和新存档实际道路穿越验收。
- 生命周期风险：area/surface/catalog hash 漂移、重启重复写、旧 chunk 混入或 datum / decision 丢失。以 activation 全 owner status preflight、v0.1/v0.2 ledger 迁移、v0.3 幂等、半落地 materialize 推导及跨 owner/restart 一致性验收。
- 性能风险：每 owner 扫全城 area/placement/NBT、datum JSON 线性查找、全局锁内地形采样或大账本逐 block 写入。以 prepared owner index、O(1) datum map、锁外 sample、owner 级摘要 ledger 和大田 lookup/scan count 测试验收。
- 连续地形风险：chunk 边界重启 run、水槽在水体前后不一致、缓降累计穿越阈值、end-cap 各 chunk 猜测不同。以 SurfacePrintPlan 冻结 run、跨 chunk 单 runId / global phase、现场 datum 与 restart 测试验收。
- foundation 风险：噪声递归、过深填充、肩部硬切、端点外延、重复 segment 密度叠高、fluid 下造地。以 common segment view、prepared chunk index、positive max contribution、depth/shoulder、endpoint / lateral water 测试验收。
- 可观测性风险：计划过 foundation 被误报为已成形，或只写 applied ledger 吞掉 skip / defer / failure。v0.3 必须同时核对 `foundationPlanned/materialized/applied`、fragmentOutcomes、terrain activation trace 和激活 preview。
- 本轮自动测试不能替代区域形态与真实材质效果的人工审阅；生活感切片必须额外由人工判断农业、商业、行政及其活动关系是否可读。
