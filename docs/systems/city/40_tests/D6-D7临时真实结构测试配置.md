# D6-D7 临时真实结构测试配置

## 定位

本文给后续实现 agent 一个临时测试夹具口径，用来在 TerraSense 正式 `StructureProfile.jsonl` 完整接入前，先完成 D6 / D7 的开发、自动测试、预览图和真实游玩验收。

临时配置允许功能语义错配，例如把神庙、小屋或哨塔暂时映射给港口、市场或市政核心。但 D7 真实放置入口必须是 Minecraft configured structure，也就是 `/place structure <structure_id>` 能识别的结构 registry ID。

## 先纠偏

`minecraft:village/plains/houses/plains_meeting_point_4`、`minecraft:village/plains/houses/plains_weaponsmith_1` 这类 ID 是村庄 NBT template 路径，不是 `/place structure` 的 configured structure ID。

它们可以用于 TerraSense 单模板画像或未来 template debug，但不能作为 D7 临时真实放置验收的 `structureId`。

D6-D7 临时真实夹具必须走完整结构入口：

```text
/place structure <configured_structure_id>
/ts_structure_assembly_scan <configured_structure_id>
```

对应画像必须是：

```text
sampleType = structure_assembly
placementKind = minecraft_place_structure
```

## 底线

| 项 | 要求 |
| --- | --- |
| 结构 ID | 必须是当前 MC / mod 环境中真实存在的 configured structure registry ID，可由 `/place structure` 自动补全或 `/ts_structure_ui` 确认。 |
| 放置能力 | D7 真实验收只接受 `/place structure` 等价入口，不接受 NBT template 路径或 jigsaw pool ID。 |
| `placementKind` | 必须是 `minecraft_place_structure`。 |
| `sampleType` | 必须是 `structure_assembly`。 |
| 尺寸配置 | `fixedFootprint`、`visibleAreaCost`、`clearanceBlocks` 必须来自 TerraSense `structure_assembly` 扫描结果或同等真实测量，不得照抄单模板尺寸。 |
| 预览图 | D6 必须输出结构选择预览和固定落点预览；D7 必须输出起点候选 / 放置 trace 预览。 |
| debug 标记 | 临时 catalog 必须标记 `catalogMode=debug`，不得伪装成 TerraSense official export。 |
| 语义错配 | 允许，但必须在 `reason` 或 `debugNotes` 说明是临时映射。 |

## 推荐候选 configured structure

下表是临时夹具候选，不是硬编码清单。后续 agent 必须先在当前客户端 / modpack 中确认 ID 存在，再用 TerraSense 扫描产出真实 footprint。

| 临时用途 | configured structure ID | 建议模式 | 使用口径 |
| --- | --- | --- | --- |
| 市政 / 广场核心临时代替 | `minecraft:desert_pyramid` | `fixed_footprint` | 固定结构候选；实际 footprint 必须来自 `structure_assembly` 扫描。 |
| 市场 / 地标临时代替 | `minecraft:jungle_pyramid` | `fixed_footprint` | 固定结构候选；适合测试尺寸过滤、旋转和落点预选。 |
| 港口 / 水岸临时代替 | `minecraft:swamp_hut` | `fixed_footprint` | 语义可错配；用于测试小型固定结构靠水 / 近水规则。 |
| 防御 / 工坊临时代替 | `minecraft:pillager_outpost` | `variable_area` 或审核后 `fixed_footprint` | 若扫描结果显示变体或附属结构不稳定，先按 `variable_area` 使用。 |
| 住宅 / 村镇填充 | `minecraft:village_plains` | `variable_area` | 村庄类结构群不要求完整长满；按剩余可见面积比例和重试预算生成。 |
| mod 村庄 / 城市结构 | 例如 `trek:village/plains` | `variable_area` 或审核后 `fixed_footprint` | 仅在当前环境 registry 中存在时使用。 |

如果这些原版 ID 在当前环境不可用，允许换成任意已加载的 configured structure，但必须记录替换原因，不得退回 template 路径。

## Debug catalog 生成流程

后续 agent 可以在实现仓库测试资源中生成一个 debug catalog，例如：

```text
src/test/resources/city/d6/debug_structure_profile_catalog.json
```

生成顺序必须是：

1. 用 `/place structure` 自动补全或 `/ts_structure_ui` 确认 configured structure ID 存在。
2. 用 `/ts_structure_assembly_scan <configured_structure_id>` 扫描完整结构。
3. 从 TerraSense 工作区读取真实 `placement_command`、footprint、origin offset、height、palette 和预览图引用。
4. 对 `fixed_footprint` 填写扫描得到的 `fixedFootprint`、`visibleAreaCost`、`allowedRotations` 和 `clearanceBlocks`。
5. 对 `variable_area` 填写 `expectedAreaRange`、面积预算建议和失败 / 少生成容忍策略。

字段形状如下，示例中的 footprint 值必须由扫描器写入，不能人工凭感觉填写。`0` 只是未替换哨兵值，真正加载测试资源时必须校验失败：

```jsonc
{
  "schemaVersion": "city_structure_profile_catalog.v0.1",
  "catalogMode": "debug",
  "source": {
    "sourceType": "debug_catalog",
    "debugCatalogPath": "src/test/resources/city/d6/debug_structure_profile_catalog.json",
    "basis": "TerraSense structure_assembly scan",
    "notes": "Temporary /place-structure fixtures for D6-D7 implementation."
  },
  "structures": [
    {
      "structureId": "minecraft:desert_pyramid",
      "placementKind": "minecraft_place_structure",
      "sourceProfileRef": "terrasense://structure_assembly__minecraft__desert_pyramid/data.json",
      "profileType": "single",
      "sampleType": "structure_assembly",
      "footprintMode": "fixed_footprint",
      "functionTags": ["civic_core", "market", "harbor_or_waterfront"],
      "styleTags": ["vanilla_debug"],
      "placementTags": ["inside_zone", "near_road"],
      "usageTags": ["public_core"],
      "qualityTags": ["debug_usable"],
      "fixedFootprint": {
        "widthBlocks": 0,
        "depthBlocks": 0,
        "heightBlocks": 0
      },
      "visibleAreaCost": 0,
      "allowedRotations": ["NONE", "CLOCKWISE_90", "CLOCKWISE_180", "COUNTERCLOCKWISE_90"],
      "clearanceBlocks": 2,
      "placementCommand": "place structure minecraft:desert_pyramid <x> <y> <z>",
      "debugNotes": "Temporary civic/harbor placeholder; semantic mapping may be wrong but structure is real /place structure input."

  }
}
```

## D6 最小验收配置

最小 D6 测试至少包含：

| 功能区 | 固定结构候选 | 非固定结构候选 |
| --- | --- | --- |
| `civic_core` | `minecraft:desert_pyramid` | `minecraft:village_plains` |
| `market` | `minecraft:jungle_pyramid` | `minecraft:village_plains` |
| `harbor_or_waterfront` | `minecraft:swamp_hut` 临时代替 | `minecraft:village_plains` |

验收要求：

- D6 能读 debug catalog。
- D6 能拒绝 `sampleType=single_template` 或 `placementKind!=minecraft_place_structure` 的真实 D7 候选。
- D6 能根据 D5 `buildable_area_map.json` 过滤掉尺寸超出的固定结构。
- D6 能生成 `fixed_placement_candidate_set.json`。
- AI / Codex 只选择 `landingCandidateId`。
- D6 能生成 `structure_choice_preview.png` 和 `fixed_placement_preview.png`。

## D7 最小验收配置

D7 最小真实游玩验收只要求：

1. 固定结构从 `PlannedFixedPlacementMap` 通过 `/place structure` 等价入口完整放置。
2. 剩余结构生成 `StartCandidateSet`。
3. 至少 1 个 `variable_area` configured structure 真实放置成功。
4. 失败候选写入 trace。
5. trace 中记录 `placementKind`、`placementCommand`、成功 / 失败 reason。
6. 输出预览图，能看出固定结构 footprint、剩余起点候选、成功 / 失败结构。

## 预览图要求

D6 / D7 的临时配置必须优先服务可视验收。

| 图 | 必须显示 |
| --- | --- |
| `structure_choice_preview.png` | 功能区、候选固定结构、候选非固定结构和过滤原因摘要。 |
| `fixed_placement_preview.png` | D5 可建区、固定结构候选 footprint、AI 选中的 `landingCandidateId`、冲突 / 风险标记。 |
| `start_candidate_preview.png` | D7 剩余可建区、`StartCandidateSet`、被抽中的候选、失败候选。 |
| `placed_structure_preview.png` | 已成功放置结构、失败结构、固定 / variable 区分。 |

## 不允许

- 不允许用不存在的结构 ID 做验收。
- 不允许把 NBT template 路径当成 D7 真实 `structureId`，例如 `minecraft:village/plains/houses/plains_weaponsmith_1`。
- 不允许把 jigsaw pool ID 当成 D7 真实 `structureId`。
- 不允许 D7 临时真实验收使用 `sampleType=single_template` 或 `sampleType=jigsaw_assembly`。
- 不允许只写 JSON 不生成预览图。
- 不允许 debug catalog 混进 official TerraSense export。
- 不允许功能错配没有说明。
- 不允许固定结构尺寸只凭感觉填写；必须来自 TerraSense `structure_assembly`、同等真实扫描结果或人工实测记录。
