# LandUse Owner 事务失败粒度过大

## 状态

已定位，待修复。

## bug原因：

失败隔离粒度过大：LandUse 将整个 owner 内的 BASE、CROP、BOUNDARY 绑定为同一成败边界，任一局部 block 操作不可落地都可能取消其他正常操作。

错误未分级：可局部跳过的目标占用与不可写、快照失败、写入失败等系统错误共用 owner 失败路径。

## 解决方案：

按影响范围拆分事务：将独立 block 或依赖相连的小组作为最小成败单元，局部失败不取消无关操作。

按失败类型分级：内容冲突记录局部 skip，只有无法保证一致性的系统错误才扩大回滚范围。
