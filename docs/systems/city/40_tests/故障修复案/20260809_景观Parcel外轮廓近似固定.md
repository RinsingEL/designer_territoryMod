# 景观 Parcel 外轮廓近似固定

## 状态

代码与自动回归已修复，待重新规划后的新区块视觉验收。实现仓库故障编号：`CITY-DL-20260809-01`。

## 现象

真实 run `landscape_relay_playtest_20260807_v3` 已能冻结 1 个 Foundation、16 个景观 Parcel 和 66 个非空内部接力 region，但不同 Landscape 的外部 Area mask 仍高度接近圆形或菱形，整体外观变化有限。

同一现场的面积 trace 显示：6 个农田 Parcel 全部为 512 blocks、7 个花田 Parcel 全部为 256 blocks、3 个林场 Parcel 全部为 768 blocks。它们各自的 `preferredAreaBlocks` 实际存在明显差异，例如农田为 231/302/327/478/512，花田包含 101/163/164/183/231/240/242；实际面积却统一命中各 Profile 的 max。

## 根因

- 正式分层路径复用了 legacy `StableLandUseExpander`。
- 该扩张器只以 `maxAreaBlocks` 和 action budget 作为停止条件；`preferredAreaBlocks` 只参与队列优先级，不是完成目标。
- 平坦或近等成本地形上的全局累计成本队列按 seed 距离向外传播，稳定 jitter 幅度很小，因此自然收敛为近似曼哈顿/欧氏距离球。
- Parcel 内 `RelayRegionGrowthClassifier` 只对既有 `memberSpans` 分配角色，不可能修正外部 mask。

## 修复契约

- 正式 Foundation/Landscape 路径新增 `LandscapeParcelExpander`；`StableLandUseExpander` 只保留给显式 legacy/debug STANDARD groups。
- 每个 Parcel 从唯一根 seed 做四邻接逐格生长。可用空间充足时精确停在 `preferredAreaBlocks`；`maxAreaBlocks` 只作为不可突破的防御上限。
- frontier 排序综合地形代价、terrain/preferred patch bias、局部同 Parcel 邻接、稳定多尺度连续扰动和方向关系，不使用固定圆、菱形、矩形、bbox、全局距离环或预制 mask。
- 相同输入必须完全确定；改变稳定 seed 必须能改变外轮廓；required 共同竞争仍与输入遍历顺序无关。
- frontier 提前耗尽时允许实际面积处于 min..preferred；低于最小可执行面积继续使用 required hard fail / optional 零占地 skip，不修改 Parcel 内区域接力契约。

## 自动验证

- `LandscapeParcelExpanderTest.openParcelStopsAtPreferredAreaInsteadOfFillingMaximum`：开放地形的 173-block 目标精确停在 preferred，不再增长到 320 max，且结果四邻接连通。
- `stableSaltProducesDeterministicButDifferentOrganicSilhouettes`：固定 salt 完全复现，改变 salt 后 claims 不同，外壳不退化为中心对称距离球。
- `requiredParcelCompetitionIsIndependentOfInputOrder`：required Parcel 输入反序后 claims 与计数不变。
- `CityOutdoorBlueprintCompilerTest.layeredPlanningUsesNoCorridorsAndKeepsOneAreaPerParcelOwner`：正式分层集成场景中 7 个 Landscape Parcel 的 `claimedAreaBlocks` 全部等于各自 preferred。
- LandUse 算法、规划服务、SurfacePrint 和预览相关测试组通过，legacy `StableLandUseExpanderTest` 保持通过。

## 新区块验收目标

用相同 Blueprint、更新后的实现和未生成 owner chunks 重新执行 `city_plan_land_use`，先比较 trace 中每个 Parcel 的 requested preferred/max 与 claimed，再检查 `land_use_preview.png`：

- 非受阻 Parcel 的 claimed 应等于自身 preferred，不应按景观类型整齐命中同一个 max。
- 农田、花田、林场外壳应保持单源连通但呈现不同凹凸、偏移和伸展；不得仍是一批近似同心圆/菱形。
- Parcel 内部 66 个接力 region 的父子、阶段占比和完整覆盖契约继续成立。
