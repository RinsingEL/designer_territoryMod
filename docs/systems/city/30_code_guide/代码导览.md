# City 系统代码导览

## 当前状态

City D2 (C0 CitySiteContext)、D3 (C1.5 CityLandformReviewPackage)、D4 (C2/C3 功能区草案实体化)、D5 (C4 道路 / 边界 / 缓冲区计划与 WorldEdit 执行入口)、D6 (结构选择与固定落点规划) 和 D7 (固定结构优先放置 + 剩余结构起点候选生成) 已实现到自动测试可通过。D3 会写出 `landform_review_map.png` 与 `city_landform_review_package.json`；D4 会写出功能区 JSON、统计、预览图和质量报告；D5 会写出道路 / 边界 / 操作计划、可建区域图、综合预览图、可建性预览图和执行报告；D6 会写出结构画像、过滤候选、AI 选择计划、固定落点候选 / 选择、规划固定结构图、结构池图和预览图；D7 会写出 `StartCandidateSet`、`PlacedStructureMap`、`StructureGenerationTrace` 和预览图。

D5 已在快速启动存档 `新的世界` 中完成一次 HTTP 实机回归：WorldEdit 7.2.15 加载成功，`city_plan_d5` 生成计划与预览，`city_execute_d5` 写出 `WorldMutationReport` 并请求保存世界。每次 WorldEdit 依赖升级后至少复测一次 `city_plan_d5` -> `city_execute_d5`。

## HTTP / MCP 入口

| 入口 | 说明 |
|---|---|
| `POST /realm/city/plan_d2` | 从已有 W/T run 的 CitySeed 生成 CitySiteContext |
| `POST /realm/city/plan_d3` | 生成 CityLandformReviewPackage（含局部 GIS 刷新与 review PNG） |
| `POST /realm/city/plan_d4` | 读取 D3 落盘包，接收 PatchGroupPlan，实体化 FunctionZonePatch / FunctionZoneMap / FunctionZoneTerrainStats |
| `POST /realm/city/plan_d5` | 读取 D3/D4 产物，生成 RoadIntent / BoundaryIntent / BuildOperationPlan 和综合预览图，不改世界 |
| `POST /realm/city/execute_d5` | 读取 D5 BuildOperationPlan，要求 `confirmWorldMutation=true`，通过 WorldEdit 后端真实修改世界 |
| `POST /realm/city/plan_d6` | 读取 D4/D5 产物和 TerraSense 导出快照，接收 AI 提交的 StructureChoicePlan / FixedPlacementSelectionPlan，生成 PlannedFixedPlacementMap、StructurePoolMap 和预览图，不改世界 |
| `POST /realm/city/execute_d7` | 读取 D6 产物，优先完整放置 fixed_footprint，程序生成 variable_area 的 StartCandidateSet，输出 PlacedStructureMap / StructureGenerationTrace / 预览图；`executeStructurePlacement=false` 时只做 dry-run |
| MCP `city_plan_d2` | MCP 工具，调用上述 D2 端点 |
| MCP `city_plan_d3` | MCP 工具，调用上述 D3 端点 |
| MCP `city_plan_d4` | MCP 工具，提交外部 AI/Codex 生成的 PatchGroupPlan |
| MCP `city_plan_d5` | MCP 工具，生成 D5 计划和预览 |
| MCP `city_execute_d5` | MCP 工具，显式确认后执行 D5 世界修改 |
| MCP `city_plan_d6` | 提交 TerraSenseStructureProfileSource，以及外部 AI/Codex 生成的 StructureChoicePlan / FixedPlacementSelectionPlan |
| MCP `city_execute_d7` | 执行 D7；默认 dry-run，设置 `executeStructurePlacement=true` 才真实调用 `/place structure` |

端点适配规则：

- 未显式传 `cellStepBlocks` 时，从 `world_survey_manifest.json` 恢复 W/T 采样步长。
- `anchorBlock` 优先使用 T4 `city_seed_registry.json` 中的 `anchorBlock`，避免用默认 cellStep 重算错位。
- D2/D3 会读取 `realm_territory_map.json` 中同 `realmId` 的 owned cells 参与 `territoryCheckResult`。
- D3 输出目录为 `run/realm_debug/<runId>/city_d3_<citySeedId>/`，其中 `landform_review_map.png` 会写入 `reviewMapImage` 与 `debugRefs`，`city_landform_review_package.json` 供 D4 读取。
- D4 输出目录为 `run/realm_debug/<runId>/city_d4_<citySeedId>/`，包含 `patch_group_plan.json`、`function_zone_map.json`、`function_zone_terrain_stats.json`、`function_zone_preview.png`、`quality_report.json`。
- D5 输出目录为 `run/realm_debug/<runId>/city_d5_<citySeedId>/`，包含 `road_intent.json`、`boundary_intent.json`、`build_operation_plan.json`、`buildable_area_map.json`、`city_planning_preview.png`、`city_buildability_preview.png`、`quality_report.json`；执行后追加 `world_mutation_report.json`。
- D5 模板目录为 server root 下 `geomantia_templates/d5/`；缺少 `gate_small.schem` / `dock_marker.schem` 等小模板时只记录 skipped / warning。
- D6 读取 TerraSense 正式导出快照：优先 `StructureProfile.jsonl`，可降级 `C3_5_StructureCatalog.preprocessed.json`，临时验收可用显式 debug catalog；D6 不直接读取 TerraSense `ScanWorkspace.structures/*` 原始目录。
- D6 输出目录为 `run/realm_debug/<runId>/city_d6_<citySeedId>/`，包含 `terrasense_profile_source.json`、`structure_profile_catalog.json`、`filtered_structure_catalog.json`、`structure_choice_plan.json`、`fixed_placement_candidate_set.json`、`fixed_placement_selection_plan.json`、`planned_fixed_placement_map.json`、`structure_pool_map.json`、`structure_choice_preview.png`、`fixed_placement_preview.png`、`quality_report.json`。
- D7 输出目录为 `run/realm_debug/<runId>/city_d7_<citySeedId>/`，包含 `start_candidate_set.json`、`placed_structure_map.json`、`structure_generation_trace.json`、`start_candidate_preview.png`、`placed_structure_preview.png`、`quality_report.json`。
- D7 真实执行只接受 MC configured structure registry 中存在的 `structureId`；NBT template 路径、jigsaw pool ID 和 TerraSense 原始模板路径不得作为 D7 真实 `structureId`。

## 禁止误用

- 不把 `docs/90_archive/` 下旧 C 阶段文档视为当前实现指南。
- 不把旧 AI image 总规链路恢复为默认主线。
- 不让入口层直接复制功能区落图算法。
- 不把 C5-C8 的结构物化逻辑塞进 C1-C4 规划器；D5 只落地道路、边界、缓冲区和小型基础设施模板。
- 不让 City 规划层直接调用 WorldEdit API；D5 只能通过 `WorldMutationBackend`。
- 不在 D5 触发 jigsaw 或放置住宅/市场/神庙等功能建筑。
- 不在 D6 调用 `/place structure`、解 jigsaw、paste template 或输出最终结构坐标；D6 只做 TerraSense 导出快照读取、结构选择、固定结构预选落点选择和非固定结构剩余面积预算。
- 不在 D7 接受 AI 坐标、AI 重试、AI 逐 piece 决策；剩余结构起点只能来自程序生成的 `StartCandidateSet`。
