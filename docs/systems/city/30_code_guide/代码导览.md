## 未来入口建议

实现时建议按系统边界建立入口，具体 package 名以实现仓库结构规范和现有代码风格为准。

| 入口 | 说明 |
| --- | --- |
| HTTP / MCP `city_plan_generate` | 从 `CitySeed` 或 `CitySiteCandidate` 生成 `CityPlanningPackage`。 |
| HTTP / MCP `city_plan_data` | 读取城市规划总包和预览图索引。 |
| HTTP / MCP `city_landing_intent_generate` | 从规划总包生成结构落地交接包。 |
| Forge 调试命令 | 针对当前玩家附近或指定 `cityId` 生成 / 查看规划产物。 |
| 自动测试 runner | 使用 synthetic 地貌和真实存档分别验证规划链。 |
