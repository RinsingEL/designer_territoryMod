# City 系统代码导览

## 当前状态

City D2 (C0 CitySiteContext)、D3 (C1.5 CityLandformReviewPackage) 和 D4 (C2/C3 功能区草案实体化) 已实现到自动测试可通过。D3 会写出 `landform_review_map.png` 与 `city_landform_review_package.json`；D4 会写出功能区 JSON、统计、预览图和质量报告。D5-C8 尚未实现。

真实 Minecraft/MCP 游玩验收尚未完成。

## 实现包结构

```
systems/city/
  domain/
    model/
      CityScale.java              - 规模枚举（HAM/VILL/TOWN/CITY）+ T4 兼容映射
      BlockPoint.java             - Block 坐标 record
      BlockBounds.java            - 包围盒 record，含 overlap/contains 判断
      PlanningGrid.java           - 局部规划网格，含坐标转换
      EntryCandidate.java         - 入口候选
      TargetScale.java            - 目标规模
      MetricsSummary.java         - 地貌指标摘要
      CityFunctionType.java       - D4 功能区类型枚举
      CitySiteContext.java        - D2 主输出：城市局部上下文
      PatchMemberCell.java        - D3/D4 共享的 GIS patch 成员 cell 薄索引
      LandformPatchSummary.java   - GIS patch 摘要，含 mapLabel/areaClass/facts/memberCells
      CityLandformReviewPackage.java - D3 主输出：地貌审查包
      PatchGroupPlan.java         - D4 输入：外部 AI/Codex 提交的 patch group 草案
      FunctionZonePatch.java      - D4 输出：City 功能区 patch
      FunctionZoneMap.java        - D4 输出：功能区图
      FunctionZoneTerrainStats.java - D4 输出：功能区地形统计
      CityQualityReport.java      - D4 质量报告
    config/
      CityPlanningConfig.java     - 配置 record（ScaleRadius/AreaThresholds/标签映射）
  application/
    CitySiteContextBuilder.java   - D2 服务，从原始参数装配 CitySiteContext
    CityLandformReviewBuilder.java - D3 服务，patch 过滤/标签分配/邻域检测/事实生成
    CityFunctionZoneBuilder.java  - D4 服务，PatchGroupPlan 校验、实体化和统计聚合
  infrastructure/json/
    CityJson.java                 - Gson 单例
  infrastructure/preview/
    CityLandformReviewMapRenderer.java - D3 地貌审查图 PNG 输出
    FunctionZonePreviewRenderer.java   - D4 功能区成员 cell 预览图 PNG 输出

platform/http/
  CityPlanningEndpointHandler.java - D2/D3/D4 HTTP 端点实现，读取 city_seed_registry.json、world_survey_manifest.json、realm_territory_map.json 和 D3 落盘包
```

## HTTP / MCP 入口

| 入口 | 说明 |
|---|---|
| `POST /realm/city/plan_d2` | 从已有 W/T run 的 CitySeed 生成 CitySiteContext |
| `POST /realm/city/plan_d3` | 生成 CityLandformReviewPackage（含局部 GIS 刷新与 review PNG） |
| `POST /realm/city/plan_d4` | 读取 D3 落盘包，接收 PatchGroupPlan，实体化 FunctionZonePatch / FunctionZoneMap / FunctionZoneTerrainStats |
| MCP `city_plan_d2` | MCP 工具，调用上述 D2 端点 |
| MCP `city_plan_d3` | MCP 工具，调用上述 D3 端点 |
| MCP `city_plan_d4` | MCP 工具，提交外部 AI/Codex 生成的 PatchGroupPlan |

端点适配规则：

- 未显式传 `cellStepBlocks` 时，从 `world_survey_manifest.json` 恢复 W/T 采样步长。
- `anchorBlock` 优先使用 T4 `city_seed_registry.json` 中的 `anchorBlock`，避免用默认 cellStep 重算错位。
- D2/D3 会读取 `realm_territory_map.json` 中同 `realmId` 的 owned cells 参与 `territoryCheckResult`。
- D3 输出目录为 `run/realm_debug/<runId>/city_d3_<citySeedId>/`，其中 `landform_review_map.png` 会写入 `reviewMapImage` 与 `debugRefs`，`city_landform_review_package.json` 供 D4 读取。
- D4 输出目录为 `run/realm_debug/<runId>/city_d4_<citySeedId>/`，包含 `patch_group_plan.json`、`function_zone_map.json`、`function_zone_terrain_stats.json`、`function_zone_preview.png`、`quality_report.json`。
