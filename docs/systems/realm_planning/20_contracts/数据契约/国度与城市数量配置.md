# 国度与城市数量配置

用户确认：国度数量配置化，每国城市采用最少/最多范围，由 AI 在范围内决定，数量包含首都。

## 文件与默认值

与现有 world_survey.json 同属世界级配置：`<realm_debug所在目录>/config/geomantia/realm_planning.json`。常规客户端即 `<存档>/config/geomantia/realm_planning.json`。程序首次读取时自动创建，可在首次规划前预先放置。

```json
{
  "realmCount": 3,
  "minCitiesPerRealm": 1,
  "maxCitiesPerRealm": 4
}
```

realmCount 为1～12的整数，沿用现有协议上限。城市数满足1≤min≤max，均包含唯一首都；两值相同即固定数量。默认范围为本次首版默认值，不表示过去已有城市范围限制。

## 生效与反馈

- T1提示AI提交配置数量的国度，正式HTTP提交复核数量一致；不会由工具偷偷补成3。
- 新T4会话冻结cityCountRequirements，模型看到范围后选城市；追加超过最大值、结束时少于最小值均返回当前数量、要求范围与调整方向。
- 地形、间距和未生成区域要求不变。选不到足够合法地点时不能凭空造城市，应报告候选不足供调整数量或选址。
- 修改文件影响下一次尚未开始的规划。已存在的国度不因修改自动增删；新T4会话使用新范围，已开始会话使用其快照。旧会话没有数量快照时维持原行为，不追溯拒绝已有成果。
- 实现入口：RealmPopulationConfig、ProviderPlanningDiscovery、PreparedRealmDesignTurn、RealmT4PatchPlanningService；调试用旧自动验收入口不冒充正式AI流程。
