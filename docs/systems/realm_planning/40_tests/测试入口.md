# 国度规划系统测试入口

## 定位

本文记录国度规划系统 v1.1 的测试与结构校验口径。当前最小实现已落地，本文同时作为实现仓库回归入口。

## 测试分层

| 层级 | 目标 | 推荐入口 |
| --- | --- | --- |
| 契约校验 | 字段、类型、必填、枚举和 schemaVersion。 | JVM 单元测试或 JSON schema 校验。 |
| 坐标换算测试 | `gridX/gridZ` 与 `blockX/blockZ` 双向换算，特别是负坐标。 | JVM 单元测试。 |
| T2 校验测试 | 合法坐标接受，跨大陆 / 跨海 / 禁用 patch / 冲突坐标拒绝。 | JVM 单元测试。 |
| 比例归一化测试 | 多国度 `scalePlan` 在同一大陆内归一化，且尊重 min / max。 | JVM 单元测试。 |
| T3 扩张测试 | 固定 fixture 多国度扩张稳定，不串状态。 | JVM 单元测试或 synthetic runner。 |
| T3 模型对照测试 | `quota_frontier` 与 `action_budget` 同输入均可运行，strict 默认 action model。 | JVM 单元测试。 |
| T3 质量测试 | 连通扩张、飞地修复、孔洞统计、自然边界贴合。 | JVM 单元测试或 synthetic runner。 |
| T3 行动力质量测试 | budget / terrain identity / wildland / contested 指标进入 score manifest。 | JVM 单元测试或真实验收报告。 |
| W Tag Audit 测试 | v1.5 对抽样点做局部精确扫描，验证 `cliff` / `steep` / `coastal` tag 的 precision / recall；v1.6 以 W coarse cell 为抽样单位，同时输出代表点、point reference 和 cell reference。 | JVM 单元测试、`runTagAudit=true`、`realm_tag_audit` 的 HTTP / MCP 验收。 |
| T4 名册测试 | 首都必定存在，非首都城市 ID 稳定且不生成城市实例。 | JVM 单元测试。 |
| T4 分布测试 | 城市不撞点，满足规模半径、角色关系和图距离约束。 | JVM 单元测试或 synthetic runner。 |
| 评分阻断测试 | 坏 W / 坏 T3 / 坏 T4 不得以端到端 `passed=true` 放行。 | JVM 单元测试。 |
| 真实游玩验收 | 通过 MCP / Forge GameTest / Forge 命令从 W 跑到 T4，输出完整验收报告、分片扫描 manifest 和预览图。 | `realm_run_acceptance`、`./gradlew.bat runGameTestServer`、`/geomantia realm acceptance`。 |

## 最小 fixture

| fixture | 用途 |
| --- | --- |
| `two_continents` | 校验 T2 不允许跨大陆选点，T3 不串大陆。 |
| `coastal_realm` | 校验亲水国度能选择海岸 patch，T4 能生成港口类候选城市。 |
| `negative_coords` | 校验负坐标下 grid / block 换算使用 floor 语义。 |
| `conflicting_seeds` | 校验两个国度种子过近时，后选坐标被拒绝或要求重试。 |
| `area_ratio_normalization` | 校验国度比例以目标大陆可分配 land cell 为分母，不使用 MC 理论世界边界。 |
| `noisy_cliff_map` | v1.2 校验 `cliff` 过量和单格 patch 过多会触发评分阻断。 |
| `fragmented_territory` | v1.2 校验非海权国最大连通块过低会触发 T3 阻断。 |
| `city_overlap` | v1.2 校验同格或半径重叠城市会触发 T4 阻断。 |

## 关键断言

| 断言 | 阶段 |
| --- | --- |
| `WorldSurveyContext.cellStepBlocks`、`gridOriginBlock` 必填。 | W |
| `WorldSurveyContext.sealed = true`，且 `world_survey_manifest.json.failedTileCount = 0`。 | W |
| v1.2 中 `microSampleStrideBlocks`、`baseLandform`、`landformTags`、clean continent / patch id 可追溯。 | W |
| v1.3 分片 W 中 `microSamplingImplemented=true`、`microSampleCount>0`，并写出 `world_feature_grid.json`。 | W |
| v1.3 固定 stride micro-sampling 必须在 `world_survey_manifest.json` / `world_survey_context.json` / `acceptance_report.json` 中记录 `microSampleBudget`、`microSampleBudgetPerCell` 和 `adaptiveSampling=false`，不得把固定采样伪装成自适应加密。 | W |
| v1.3 修改 `microSampleStrideBlocks` / `localSlopeRadiusBlocks` 等采样配置后，同 runId 不得误复用旧 tile cache 或旧 `world_feature_grid.json`。 | W |
| v1.5 高 step W 中，正式 `cliff` tag 必须由 micro `slopeStats` 支撑；coarse cliff 只能作为 `cliff_candidate` / `micro_contradiction` 诊断 tag。 | W |
| v1.5 开发期 `runTagAudit=true` 时必须写出 `tag_audit_samples.json` 和 `tag_audit_report.json`，报告包含 `cliff/steep/coastal` precision / recall、cliff FP/FN 样例、`sampleLayerCounts`、`sampleSeed` 和 `microContradictionAcceptedRate`；样本必须给出局部精扫中心 `blockX/blockZ` 与可传送复核的 `tpCommand`。 | W |
| v1.6 W 输出应包含 `terrainMetrics`、`landformEvidence`、`landformConfidence` 和 `overlayTags`，其中 `relativeHeightRank` / `scanHeightRank` 不能单独作为 `ridge` / `plateau` / `lowland` 的唯一证据。 | W |
| v1.6 `plateau` 必须同时具备局部平坦、区域高位、核心面域连续性和相对外圈抬升；合成小平顶土坡不得被判为 `plateau`，宽平台应能被判为 `plateau`。 | W |
| v1.6 Tag Audit 样本必须输出 `representativePoints`、`pointReferenceTags`、`cellReferenceTags`、`cellReferenceBaseLandform`、`cellReferenceMetrics`、`mixedCell` 和 `representativePointMismatch`；报告必须输出 `samplingUnit=w_coarse_cell`、`cellTagMetrics`、`baseLandformMetrics`、`mixedCellRate` 和 `representativePointMismatchRate`。 | W |
| v1.6 水边分类中，扫描边界截断水体应允许 `boundary_truncated` / `open_water_unknown`，不得只因触边就给高置信 `seacoast/coastal`。 | W |
| `RealmCandidateMapPackage` 必须包含候选图路径、grid 图例、允许 patch 和选择规则。 | T1 |
| `RealmCoordinateSelection.validation.status = rejected` 时必须有 `errors[]`。 | T2 |
| T3 不接受未通过校验的 `RealmSeed`。 | T3 |
| 同一 `normalizationGroup` 内 `targetAreaRatio` 应归一化到可解释范围，并记录归一化前后值。 | T3 |
| 同一输入多次扩张结果一致。 | T3 |
| 不同 run / 维度 / 大陆扩张结果不共享可变全局状态。 | T3 |
| strict T3 默认 `expansionModel=action_budget`，并输出 `owned/wild/contested/blocked/unreachable` 状态摘要。 | T3 |
| 非海权国 `largestComponentRatio` 应不低于质量阈值，飞地 / 孔洞指标进入 `score_manifest.json`。 | T3 |
| `CitySeedRegistry` 中每个 `citySeedId` 唯一。 | T4 |
| `CitySeedRegistry` 不包含城市内部边界、道路、功能区或结构落点字段。 | T4 |
| `CitySeedRegistry.citySeeds[].anchorGrid` 必须落在同 realm 的 owned territory 内，`score_manifest.subScores.T4.offTerritoryAnchorCount=0`。 | T4 |
| 城市种子除显式复合 / 卫星关系外不得同格重叠，并满足规模半径和图距离约束。 | T4 |
| `RealmCityCandidateMapPackage.candidateMapImage` 必须指向单国度 owned territory 裁剪图，`mapScope=realm_owned_territory`，且 `gridLegend.cellStepBlocks` 与 W step 保持一致。 | T4 |
| `score_manifest.json` 中任一硬阻断为 true 时，端到端验收不得通过。 | 验收 |

## 验收命令口径

当前已接入：

```text
./gradlew.bat test
./gradlew.bat runGameTestServer
cd country_designer_mcp
npm run build
```

如需在已启动的 MC 服务端 / 客户端中手动验收：

```text
/geomantia realm status
/geomantia realm acceptance [planningRadiusBlocks] [cellStepBlocks]
```

MCP / HTTP 主验收入口：

| MCP 工具 | HTTP 路径 |
| --- | --- |
| `realm_status` | `GET /realm/status` |
| `realm_w_refresh` | `POST /realm/w/refresh` |
| `realm_t1_prepare` | `POST /realm/t1/prepare` |
| `realm_t2_select_coordinate` | `POST /realm/t2/select_coordinate` |
| `realm_t3_expand` | `POST /realm/t3/expand` |
| `realm_t4_build_registry` | `POST /realm/t4/build_registry` |
| `realm_run_acceptance` | `POST /realm/acceptance/run` |
| `realm_tag_audit` | `POST /realm/tag_audit` |

真实游玩验收入口见 `真实游玩验收计划.md`。`realm_run_acceptance` 是 W / T 端到端验收主入口；Forge GameTest 用真实 `ServerLevel` 覆盖同一条业务链。
