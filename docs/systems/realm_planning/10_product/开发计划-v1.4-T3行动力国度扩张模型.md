# 国度规划系统 v1.4 开发计划：T3 行动力国度扩张模型

## Summary

本轮目标是替换当前 T3 的 quota 面积过渡模型，让国度扩张从“按比例切完整大陆”改为“由国度行动力、地形消耗、补给距离、竞争压力和自然屏障共同决定”。

核心变化：

```text
当前：scalePlan.targetAreaRatio -> quota -> frontier 领取 cell -> rebalance 吃满大陆
目标：expansionBudget + terrainCostProfile -> frontier 消耗行动力扩张 -> 行动力耗尽 / 屏障 / 竞争失败后停止
```

v1.4 不改变 T1 / T2 “AI 看候选图选 grid 坐标”的主线，也不进入 C 阶段城市或建筑落地。它只重构 T3 的国度范围生成模型。

## 背景

v1.2 真实验收中，T3 已解决大量飞地和不连通问题，但仍存在设计缺陷：

- 每个国度最终面积主要由 `scalePlan.targetAreaRatio` 归一化 quota 决定。
- `expansionStyle` 只影响“往哪里长”，没有真正影响“能长多大”。
- `allowUnclaimedLand=false` 会让国度倾向吃满目标大陆所有可分配陆地。
- `rebalanceAreaQuotas` 会把面积拉回 quota，削弱地形消耗和国度特色。

这会导致国度像行政切图，而不是有能力边界、地形适应性和文明扩张特性的势力。

## Scope

本轮包含：

- 新增 `expansionBudget` / 行动力预算模型。
- 由 `RealmProfile.expansionStyle` 和国度 archetype 派生 `terrainCostProfile`。
- T3 frontier 从“填 quota”改为“消耗行动力”。
- 支持 wild land、contested land、blocked / unreachable land。
- 输出每国预算使用率、地形消耗分布、停止原因和未占领区域比例。
- 更新 `RealmTerritoryMap`、`t3_report.json`、`score_manifest.json` 的 T3 指标。

本轮不包含：

- 不改 T1 / T2 AI 选点主流程。
- 不生成城市实例、道路、建筑或功能区。
- 不要求 W/GIS v1.3 全部完成后才能做 synthetic 算法测试，但真实验收应优先使用 v1.3 W 结果。
- 不让 AI 填 Dijkstra 裸参数；AI 只给高层国度风格和偏好。

## 目标体验

国度范围应该自然体现差异：

| 国度类型 | 预期扩张表现 |
| --- | --- |
| 平原农耕国 | 在平原、河谷、低坡地扩张快，遇到山脉和深林明显收缩。 |
| 山地 / 矮人王国 | 山地、ridge、矿区消耗低，可以深入山系，但平原扩张不一定强。 |
| 海贸国 | 沿海岸、河口、港湾扩张强，可以有限跨海建立据点。 |
| 游牧国 | 平原和草地扩张距离远，城市密度低，荒野缓冲更多。 |
| 宗教 / 圣地国 | 扩张可能围绕圣地、山谷、湖泊或遗迹，不必追求大面积。 |

最终地图应允许：

- 国度之间存在荒野缓冲。
- 深山、雪山、荒漠、沼泽、危险遗迹带不属于任何国度。
- 大国确实更大，但不是无视地形均匀吃满。
- 小国可以因为地形优势守住山谷、港湾或盆地。

## 数据模型建议

### RealmProfile.scalePlan

`scalePlan` 保留，但从硬配额降级为软目标和合理性范围。

| 字段 | 新语义 |
| --- | --- |
| `priority` | 量级：`minor`、`normal`、`major`、`empire`，影响基础行动力预算。 |
| `targetAreaRatio` | 软目标，用于评分和 AI 叙事，不直接转成 quota。 |
| `minAreaRatio` / `maxAreaRatio` | 结果合理范围；strict 下超出可 warning 或 hard block。 |
| `normalizationGroup` | 仍用于同大陆 / 大区内比较。 |

### 新增 ExpansionBudget

建议由程序派生后写入 `RealmSeed` 或 T3 report：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `baseActionBudget` | number | 基础行动力。 |
| `budgetMultiplier` | number | 来自国度量级、时代、AI 高层设定的倍率。 |
| `effectiveActionBudget` | number | 最终可消耗预算。 |
| `softStopThreshold` | number | 超过后扩张优先级下降。 |
| `hardStopThreshold` | number | 超过后停止扩张。 |
| `maxClaimCost` | number | 单个 cell / edge 过高成本阻断。 |
| `wildlandTolerance` | number | 周边保留荒野倾向。 |

### 新增 TerrainCostProfile

AI 不直接填底层消耗表。程序根据 `expansionStyle`、国度 archetype 和 W 地貌派生：

| 地形 / 边 | 平原国 | 山地国 | 海贸国 |
| --- | ---: | ---: | ---: |
| lowland / plain | 1.0 | 1.3 | 1.1 |
| forest | 1.4 | 1.5 | 1.3 |
| upland / hill | 1.8 | 0.9 | 1.7 |
| ridge / mountain | 3.0 | 1.0 | 3.2 |
| steep / cliff tag | 5.0 或阻断 | 1.8 | 5.0 或阻断 |
| shore | 1.0 | 1.5 | 0.6 |
| river edge | 1.1 | 1.3 | 0.8 |
| water crossing | 阻断 | 阻断 | 按 `seaCrossingPolicy` |

### TerritoryCell 状态

`RealmTerritoryMap` 应从“每个 land cell 必须有 owner”扩展为：

| 状态 | 说明 |
| --- | --- |
| `owned` | 被某国稳定控制。 |
| `wild` | 可通行但未归属。 |
| `contested` | 多国影响力接近，争议区。 |
| `blocked` | 地形或规则上不可扩张。 |
| `unreachable` | 当前所有国度行动力都无法到达。 |

## 算法流程

### 1. 准备 T3 输入

- 读取 accepted `RealmSeed`。
- 过滤同 `normalizationGroup` / 目标大陆 land cell。
- 为每个国度派生 `ExpansionBudget`。
- 为每个国度派生 `TerrainCostProfile`。

### 2. 初始化 frontier

每个国度从 seed cell 开始：

```text
frontier item:
  realmId
  cell
  parent
  cumulativeCost
  remainingBudget
  pathLength
  terrainCostBreakdown
```

### 3. 行动力扩张

每次扩张到邻接 cell 时：

```text
edgeCost = baseMoveCost
         + terrainCostProfile[cell.baseLandform]
         + tagCost[cliff/steep/wet/rugged]
         + barrierCost[edge]
         + supplyDistancePenalty
         + compactnessPenalty
         - affinityBonus
```

若满足任一条件则停止或跳过：

- `cumulativeCost + edgeCost > hardStopThreshold`
- `edgeCost > maxClaimCost`
- 水体 / cliff / 山脉硬阻断
- 跨海策略不允许
- 补给断裂或走廊过窄

### 4. 多国竞争

同一 cell 被多国 frontier 到达时：

- 成本明显更低者占有。
- 成本接近时可标记为 `contested`。
- `borderPressure` 高的国度可提高争夺倾向，但不能无视行动力。
- 不再用全局 rebalance 强行把 cell 迁给面积不足的国度。

### 5. Wild land 保留

未被任何国度成功 claim 的 land cell 保留为：

- `wild`：可达但无人稳定控制。
- `blocked`：高成本屏障或规则阻断。
- `unreachable`：行动力不足无法到达。

wild 比例进入报告和评分，不应默认视为失败。

### 6. 后处理

后处理只修 bug 型问题：

- 小型 disconnected fragment。
- 明显孔洞。
- 单 cell 锯齿。
- 不合理跨海孤点。

后处理不得把所有 wild land 强行填给附近国度。

## 产物与指标

### t3_report.json

新增：

| 字段 | 说明 |
| --- | --- |
| `budgetUsedRatio` | 每国行动力使用比例。 |
| `averageClaimCost` | 平均占领成本。 |
| `maxClaimCost` | 最高单格占领成本。 |
| `terrainCostBreakdown` | 平原、山地、水体、森林等消耗分布。 |
| `stopReasonSummary` | 行动力耗尽、屏障阻断、竞争失败等。 |
| `wildlandRatio` | 未归属陆地比例。 |
| `contestedRatio` | 争议区比例。 |
| `blockedRatio` | 不可扩张区域比例。 |
| `ownedAreaRatio` | 已归属陆地比例。 |

### score_manifest.json

T3 子分新增：

| 指标 | 用途 |
| --- | --- |
| `budgetCoherenceScore` | 面积是否能由预算解释。 |
| `terrainIdentityScore` | 国度是否占据符合自身特性的地貌。 |
| `wildlandScore` | 是否保留合理荒野。 |
| `contestedReasonabilityScore` | 争议区是否合理。 |
| `overExpansionPenalty` | 是否穿越过高成本地形。 |

## 接口影响

MCP / HTTP `realm_t3_expand` 建议新增可选字段：

| 参数 | 说明 |
| --- | --- |
| `expansionModel` | `quota_frontier` 或 `action_budget`，默认后续切到 `action_budget`。 |
| `wildlandPolicy` | `none`、`limited`、`open_world`。 |
| `contestedPolicy` | 是否允许输出 contested cell。 |
| `budgetScale` | 调试倍率，默认 `1.0`。 |

`realm_run_acceptance` strict 模式应默认使用 `action_budget`，但开发过渡期可保留 `quota_frontier` smoke 对照。

## 实现步骤

### Step 1：模型并存

- 保留当前 quota frontier 实现作为 `quota_frontier`。
- 新增 `action_budget` 实现，不直接删除旧逻辑。
- T3 report 标记 `expansionModel`。

### Step 2：预算与地形成本派生

- 从 `ScalePlan.priority` 派生基础预算。
- 从 `ExpansionStyle` 派生 terrain cost profile。
- 写入 T3 debug report，先不改变地图输出。

### Step 3：行动力 frontier

- frontier item 携带 cumulative cost。
- 单步扩张消耗预算。
- 输出 `owned / wild / blocked / unreachable`。

### Step 4：多国竞争与 contested

- 成本接近时输出 contested。
- `borderPressure` 只影响争夺，不突破硬屏障。
- report 中记录 contested 原因。

### Step 5：后处理收窄

- 删除或弱化强 quota rebalance。
- 后处理只修明显拓扑错误。
- repair log 区分 topology repair 和 forced quota move，后者不应出现在 action model。
- 兼容 `quota_frontier` 的面积修正只扫描跨国边界候选，使用增量领土计数和局部边界更新；每次转移必须满足 donor 超额、receiver 未达 quota，并严格减少总面积误差。禁止每移动一格就重新执行 `国度数 × 全大陆 cell` 扫描，也禁止在已达 quota 的国度之间振荡直到撞迭代上限。

### Step 6：评分与验收

- 更新 T3 score。
- strict 验收要求国度特性可解释，而不是面积刚好接近 quota。
- 人工预览图需要显示 owned / wild / contested / blocked。

## 测试计划

### Synthetic

| 用例 | 预期 |
| --- | --- |
| 平原 + 山脉屏障 | 平原国停在山前，山地国可深入山脉。 |
| 海岸大陆 | 海贸国沿岸扩张，非海权国不跨海。 |
| 大荒野大陆 | wild land 保留，不被强行吃满。 |
| 双国夹山谷 | 山谷可能 contested，边界可解释。 |
| 小国盆地 | 小国行动力耗尽后停在局部区域。 |

### JVM / 接口

- 同一输入多次 action model 输出稳定。
- `expansionModel=quota_frontier` 与 `action_budget` 可对照运行。
- `quota_frontier` 至少覆盖 12 国、约 4096 粗 cell 的规模回归：两次运行各自在 10 秒门限内完成、结果一致、所有国度有且只有一个领土连通分量，quota repair move 不超过 territory cell 数。
- T3 report 包含预算、成本、wild / contested 指标。
- score manifest 在过度扩张时能阻断。

### 真实验收

- 使用 v1.3 Dregora 标准 W 结果或当前 8192 smoke W 结果。
- 至少配置 3 个差异明显的国度：
  - 平原农耕国
  - 山地 / 矮人国
  - 海贸国
- 人工检查：
  - 是否保留荒野。
  - 山地国是否更适应山地。
  - 平原国是否在山脉 / 水体前收缩。
  - 国界是否由成本和竞争自然形成。

## 通过标准

| 类别 | 标准 |
| --- | --- |
| 模型 | strict T3 默认使用 `action_budget`。 |
| 特性 | 不同 `expansionStyle` 在相同地图上产生可见差异。 |
| 荒野 | `wildlandRatio` 可配置并进入 report。 |
| 争议区 | `contested` 可输出、可解释、可关闭。 |
| 拓扑 | 非海权国最大连通块仍满足质量阈值。 |
| 评分 | 过度跨山 / 跨海 / 吃满荒野会进入 hard block 或 warning。 |
| 兼容 | T4 能消费 action model 输出，只在 owned territory 内生成城市种子。 |

## 2026-06-12 实际验收结果

- 标准档 run：`run/realm_debug/realm_v13_v14_real_16384_20260612`。
- strict 验收默认使用 `expansionModel=action_budget`，最终 `acceptance_report.passed=true`、`score_manifest.totalScore=82.95`、`hardBlocks=[]`。
- T3 子分 `70.5`，`ownedAreaRatio=0.2341`、`wildlandRatio=0.7357`、`blockedRatio=0.0301`，符合“保留荒野，不强行吃满大陆”的方向。
- T3 status count：`owned=5957`、`wild=18717`、`blocked=765`、`contested=3`。
- 三个自动国度均形成可玩 owned 领地且单连通：
  - `realm_green_court_2=1180`
  - `realm_stone_march_1=2797`
  - `realm_salt_kingdom_0=1980`
- T4 输出 `citySeedCount=7`、`capitalCount=3`，所有城市种子锚点都落在对应 owned territory 内。
- 本次调试明确了 strict action model 的额外质量口径：
  - 不能让国度无 owned 领地或只有首都点也通过。
  - 竞争覆盖不能切断旧 owner 连通性。
  - 自动验收选点应优先选择有局部陆地腹地、且远离已选种子的可扩张坐标。
  - Dregora 中普通 steep / cliff tag 应主要表现为高成本，不应默认全部变成硬墙；极端 barrier 才硬阻断。

## 风险

- 如果 W/GIS 地貌仍然把 cliff / mountain 判错，action model 会继承错误成本。
- budget 参数过多可能变成“AI 填裸参数”；必须靠模板派生。
- wild land 引入后，T4 城市候选可能变少，需要适配城市数量策略。
- contested cell 会影响边境城市和道路系统，需要在 T4 / C 阶段明确消费口径。

## 后续衔接

v1.4 完成后，T4 应调整为：

- 只在 `owned` territory 内生成有限城市。
- `contested` 可生成边境堡、争议矿区、战场遗迹等候选。
- `wild` 可交给野外地牢、迷宫、怪物巢穴、远征资源点系统消费。

这样国度系统不会吃掉整个开放世界，反而为野外内容保留空间。
