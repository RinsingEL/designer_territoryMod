## AI 需求总结

### 附属模组定位

本案为**设计中案**，负责冒险内容分布这一独立职责链，尚未接管实现。

大陆邻近关系、档位封顶与外海规则采用本轮授权下的设计决定；其余需求沿用用户已确认方向。

以**附属 mod**承载整合包作者配置的冒险分布规则，结合现有世界中的大陆、附属近海、人烟区与荒野，决定不同地方可能出现什么怪物和探索结构，并让生成地点能够被 NPC 委托参考。

### 按大陆邻接层次逐档推进

以玩家初始大陆为起点，按大陆之间的邻接层次向外推进，**每向外一层进入下一档**：初始大陆为第一档，第一层邻近大陆为第二档，再向外一层为第三档，以此类推。

**初始大陆及其附属近海始终为第一档，即最初级难度**；初始区域再大，也不会使首层邻近大陆跳档。分档不再采用到初始位置的固定距离阈值，也不再需要最近岸线计距与初始区域跨度扣除规则。

**每块大陆及其附属近海整体使用同一个档位**。档位由世界地理中的邻接层次决定，不随玩家实际绕路、往返或到访顺序改变。大陆和近海都可以承载整合包作者配置的探索内容。

### 大陆邻近关系与层次认定

采用**大陆中心所代表的空间邻近关系**。把地图上的位置按最近的大陆中心划为各自的邻近范围；两个范围共享一段边界时，对应大陆互为邻居，仅在一个点相碰不算。这个范围只用于认定大陆邻居，**不改变实际大陆、附属近海或外海的归属**。

从初始大陆出发，按**到达目标大陆所需的最少邻接跨越次数**确定层次。可以通过多条路线到达时取跨越次数最少的一条，不按玩家实际航行路线升级，也不让环形路线重复加档。

因此，第一层邻居全部为第二档，而不只是玩家最先登陆的那一块大陆。若两块大陆之间隔着宽阔外海但仍是空间邻居，也只推进一档；**大陆档位表达探索层次，不表达航程长短**，途中外海的危险内容独立配置。

### 整合包作者配置各档内容

整合包作者决定**各档位使用的怪物池与探索结构池，以及相应刷新和分布规则**。不由模组硬编码某种怪物或某座地牢属于第几档。

作者按第一档起连续配置内容档位。**地理层次超过最高已配置档位时，使用最高档内容**，不循环回低档、不自动增加怪物数值，也不因超出档位而变成空白区域。例如作者只配置五档，则第五档及更外围大陆都使用第五档内容。

### 五类作者配置文件

第一版按以下**五类 JSON**组织整合包作者配置：

| 文件 | 作者配置的内容 |
| --- | --- |
| `distribution.json` | 分布总入口：各档位陆地、附属近海分别引用哪些怪物池和结构池，以及外海引用哪些池。 |
| `mob_pools.json` | 怪物池：怪物种类、选择权重、成群数量、刷新条件、频率和数量限制。 |
| `structure_pools.json` | 结构池：结构种类、选择权重、生成条件、分布密度和间距。 |
| `settlement_rules.json` | 人烟区规则：城市、村庄、道路周围的限制范围，以及禁止或允许的冒险内容。 |
| `generation_control.json` | 生成接管名单：哪些怪物和结构交给本附属管理，以及是否保留它们原有的随机生成。 |

**一个文件可以定义多个池或规则，多个档位可以复用同一个池**，不要求每个档位复制一整套配置文件。陆地与附属近海虽共用所属大陆的档位，仍可引用不同内容池。

**大陆档位结果、探索结构坐标等属于系统生成的存档数据**，不算在这五类作者配置中。NPC 委托配置由委托系统独立承载，不混入上述文件。

本节确定作者配置的文件分工，具体 JSON 字段与格式在配置契约中另行定义。

### 性能要求

分档应保持**低运行开销**，在大陆关系确定后形成可复用的档位结果。普通刷怪和结构生成直接使用所属区域的档位，避免每次重新计算全局大陆关系，不因玩家移动反复重算。

### 外海使用独立内容配置

不属于任何大陆附属近海的**外海使用一套独立内容配置**，由作者直接指定外海的怪物池、探索结构池及刷新和分布规则。外海不随大陆邻接层次升档、不继承最近大陆档位，也不默认套用大陆最高档。

作者通过选择危险的海洋生物与探索结构体现深海凶险，而不是自动提高怪物属性。**同一套外海规则可以包含不同强度和主题的内容**，其出现机会由作者配置，无需再维护第二套距离分档。

初始大陆的附属近海仍属第一档，只有离开附属近海进入外海后才使用外海内容配置；其他大陆的近海同样继续使用所属大陆档位。外海不作为大陆推进层次中的额外一档。

### 人烟与荒野决定内容出现的空间

区分**有人烟的地方与荒野**，利用现有城市保护能力，避免随机冒险结构侵入受保护的建设范围。荒野区域按作者配置的档位与内容池，随机出现相应怪物和探索结构。

例如，作者可以把「地牢浮现之时」中的某个结构加入第一档结构池，使它有机会出现在第一档荒野；把「突变生物」中的某种怪物加入第二档怪物池，使它有机会出现在第二档大陆的荒野。

这些只是作者配置的例子，**不代表本案固定绑定上述模组或固定分配这些内容的档位**。

### 档位表达内容差异

**档位用于组织冒险内容，不等同于怪物等级。** 玩家偏好的差异来自怪物机制、种类、外观和探索环境，不以单纯堆高怪物血量、伤害作为分层核心。

作者通过选择不同怪物和结构组成各档内容池，使玩家在不同区域遇到不同的冒险。换皮或主题不同的怪物也有探索价值，不要求所有内容都必须具有复杂机制。

### 记录探索地点，供经典委托引用

**探索结构实际生成的位置能够记录，并供委托系统参考**，让委托与世界里的冒险地点关联。

委托方向是经典冒险目标：

- **讨伐某个目标**，例如某种危险怪物。
- **清理某处地点**，例如营地或地牢。
- **帮 NPC 寻找材料**，材料可能来自野外采集、怪物掉落，也可能位于地势险要的地方。

材料获取的挑战可以来自路途、环境和战斗，不要求全部转化为击杀任务；委托本身也不要求围绕某种特殊战斗机制设计。本案保存分布与委托的关联需求，具体委托发布和完成规则仍需后续讨论。
