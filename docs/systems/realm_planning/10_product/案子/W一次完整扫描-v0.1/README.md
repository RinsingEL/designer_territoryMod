## AI 需求总结

### 一次完成扫描

W 对本次配置的世界规划范围执行 **一次完整扫描**，完成后形成后续 T 阶段使用的统一地形与 Patch 结果。W 不按照城市开发进度逐圈扩张，也不承担城市任务排序。
