## AI 需求总结

### 进入世界后启动规划

使用 Mod 进入世界后，系统开始衔接一条连续的世界自动规划流水线。首先执行 **W 一次完整扫描**，并在扫描完成后形成供后续规划使用的世界总览；城市推进不得把 W 改成逐城或逐圈重复扫描，也不要求玩家或 Agent 分别启动多个独立队列。

### 国度与城市数量配置

国度数量和城市密度允许配置，后续 T 阶段与城市设计使用本次世界采用的配置形成实际国度和城市；配置不改变 T3 必须统一扩张以及逐国、逐城自动推进的顺序。

### T1 / T2 与 T3 的统一前置流程

W 完成后，先让本次世界规划范围内的**全部国度完成 T1 / T2**，形成参与扩张的国度核心；随后由 T3 对全部国度执行一次**统一扩张**。任何国度都不得因为先进入调度队列而提前完成 T3 或先占领土地，T3 完成前也不得进入 T4 和城市设计。

### T3 完成后的国度推进顺序

统一 T3 完成后，国度以其相对世界 **0,0** 的距离从近到远排列，一次只推进当前国度；当前国度没有完成前，不进入更远的国度。

### 当前国度完成 T4 后设计城市

系统在统一 T3 已经完成的前提下，为当前国度执行 T4 并确定该国需要设计的城市。当前国度的城市确定后，立即进入该国的城市设计，不等待其他国度先完成 T4。

### 国度内逐城循环

当前国度的城市按其相对世界 **0,0** 的距离从近到远排列，一次设计一座。城市完成 D4 提交后，同一条自动流水线继续完成后续必要程序阶段，直到城市进入 **WAITING_FOR_GENERATION**，不要求玩家或 Agent 再启动另一条队列；随后检查该国是否还有未设计城市，有则继续下一座，没有才把当前国度视为完成。

### 跨国度循环

一个国度的全部城市都到达 **WAITING_FOR_GENERATION** 后，系统按照既定距离顺序进入下一个国度，重复该国 T4 和逐城设计流程，直到本次世界规划范围内的国度全部完成；已经完成的统一 T3 不得按国度重复执行。

### Agent 与 User Provider 边界

User Provider 最后接入。在此之前，需要 AI 判断的 T 选址和城市设计由现有 Agent 处理，程序阶段与循环调度自动衔接；某个决策或城市推进失败时停在当前位置并提醒 Agent，不得跳过失败对象继续向后运行。以后接入 User Provider 时，它接替相同的 AI 决策位置，不改变 W、国度顺序和城市循环。
