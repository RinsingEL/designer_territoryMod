## AI 需求总结

### 初始活动区

新世界以 **0,0** 为中心保留默认半径 **2048 格**的玩家初始活动区，这里不设计城市和国度；该半径允许整合包作者配置。

### 首批城市距离

第一批城市从距离原点至少 **3072 格**的位置开始，该距离允许整合包作者配置。

### 区域进入限制

初始活动区外，只有已经完成设计、生成安全并正式解锁的地方才能进入。尚未解锁的区域不仅**禁止 TP**，也必须阻止玩家通过步行、飞行或载具继续跑图；边界需要提供玩家能够感知的阻挡或警告，例如世界边界式阻挡，或在接近后出现黑暗等效果并把玩家送回安全区域。限制必须确保玩家及其视距不会提前生成未来城市所在区域，避免城市完成设计后无法正常生成落地。

### 大陆及附属海洋形成地理区域

在国度划分阶段形成用于开放的地理分区。**大陆及其附属海洋**应作为完整区域来考虑，玩家进入后能在这片区域内正常活动，不再只开放一座城市及一条到达它的旅行走廊。

### 大洋分成多个开放区域

大陆附属海洋之外的大洋也要形成区域，**不能因为海水连通，就把全世界海洋统一归为一个大洋区域**。不同大洋区域可以分别开放；具体边界应能让玩家理解自己正位于哪片区域。

### 按完整区域逐个开放

**整片大陆的所有城市都完成设计并准备好生成方案后，才一起解锁大陆及其附属海洋的战争迷雾和通行范围**，不因其中一座城市完成就提前开放大陆。解锁无需预先把大陆所有方块生成出来，玩家进入后按已准备好的方案生成。尚未完成的城市待建范围必须保持不被提前加载生成，不能只靠地图黑色蒙版或限制玩家脚下位置；邻近已开放区域的视距加载也必须受到保护。本案采用首次生成时建城的方向，不采用先放行地形再补建城市的方案。

### 每座城市具有完整城市范围与郊区

每座城市都要有明确的整体范围，容纳形成的建筑、道路、台地和景观，并拥有外围郊区活动空间。开放后的范围要足够完整，不能城市还没有逛完就撞到未开放边界，也不能只围住建筑本体而没有外围空间。

### 城市及郊区之间不得重叠

选址时就为城市与郊区预留足够范围，**两座城市的 top patch 预览覆盖范围不得有公共区域**，不能只按城市中心点之间的距离判断是否足够远。若新城市与既有预留范围冲突，应调整新城市位置；没有足够空间时，不在该处追加城市。**AI 只能在原始 top patch 预览图覆盖范围内设计**。以城市中心将完整预览覆盖范围的宽、高扩大到原来的 **1.5 倍**作为安全保护范围，外圈只为防止邻城规划和提前加载相互影响，不能当作新增设计用地、郊区建设配额或额外外扩空间。两座城市扩大后的保护范围不得重叠；同样大小、沿同一轴排列的预览范围，对应中心间距至少为原预览宽度的 1.5 倍，其他排列和不同大小城市仍以保护范围不重叠为准。

### 仍需讨论的边界细节

采用用户确认的默认：近海归最近大陆，远海划成多个连续海域，近海分界距离可配置；地理开放区域不强制与国度政治边界重合。1.5 倍表示保护范围的整体宽、高放大，不是每侧再增加半张预览图。区域边缘仍需多大生成保护距离，以及这一保护范围是否足以覆盖实际视距加载影响，留待核对；不能仅凭 1.5 倍就认定已经保证生成安全。
