## AI 需求总结

### 地图身份

为玩家提供名为 **冒险者地图** 的物品，玩家通过该物品进入地图 GUI，**不再占用固定热键**。它作为查看世界规划结果和当前自动规划进度的统一入口，既承载玩家可理解的国度、城市与地理信息，也可以显示用于验收和排错的规划状态；首版继续使用基础 GUI 控件，美术资源以后再替换接入。

### 粗略地图

地图主体必须渲染能够辨认世界地形、群系、国度和城市相对位置的**粗略地图**，不能继续只用空白面板和抽象节点代替实际地理底图。粗略地图只使用当前规划已经形成并允许揭示的地理结果，不为了显示地图扫描精细方块、生成新区块或提前揭示尚未开放的外围区域。

### 拖动浏览

玩家可以**按住鼠标左键拖动地图内容**，平移查看其他位置。松开后保留浏览位置，缩放和进度刷新仍围绕当前浏览位置展示；地形、城市和玩家标记保持位置对应，未开放区域继续保持黑色蒙版。

### 实时玩家位置

地图打开期间持续显示当前人物的真实位置，并让位置标记随玩家移动及时更新。玩家标记使用方向箭头，实时跟随玩家的水平面朝向旋转。玩家位置只作为覆盖在地图上的动态标记，不得把规划完成但尚未落地的城市或未揭示区域误画成已经存在的世界内容。

### 地图性能

打开地图、缩放和玩家移动时不得造成明显卡顿。底图直接复用 W 已经扫出的粗略预览结果，不要求 W 扫出多少像素就在界面逐像素渲染多少像素；显示颗粒度随缩放档位调整，只取得玩家当前视口范围并对范围内节点做 LOD，不能每次发送和遍历整张世界及全部节点。规划结果没有变化时应复用已形成的底图数据，玩家位置变化不得触发世界重扫，地图显示也不得阻塞玩家正在游玩的服务器。

### 初始地图范围

玩家最开始只能看到世界 **0,0 周围的一圈范围**，与初始活动区域形成一致的开局认知。W 即使已经在后台扫描更大的规划范围，也不得因此直接向玩家揭开整张世界地图。

未开放范围必须覆盖为黑色蒙版。蒙版逐格复用服务端实际的初始活动区和已开放完整地理区域判定，不另造一套“看得见但进不去”的客户端边界；普通图层不显示蒙版外城市节点，Debug 图层可以显示节点用于排错，但不能揭开其地形。

### W 阶段显示

地图可以显示 W 当前是否正在扫描、已经完成多少以及世界总览是否已经形成。W 的扫描进度使用实际完成情况表示；W 完成后形成地形与群系底图，但尚未完成国度规划的外围区域继续保持未揭示状态。

底图必须读取 W 的真实 `world_feature_grid` 粗扫结果并按固定上限降采样；W 已覆盖整个规划矩形不等于玩家已经探索或开放整个矩形。地图不得以“扫描格存在”为揭示条件，也不为消除块状视觉去加载区块或做方块级扫描。

### T 阶段与国度揭示

地图显示当前 T 阶段。T 使用 **T1、T2、T3、T4** 等实际阶段表达进展，不使用虚假的线性百分比。T1 / T2 可以显示各国度的准备状态，T3 则必须显示为**全部国度统一扩张**，不得表现成某个先处理的国度已经先占领土地。统一 T3 完成后，系统再按国度推进 T4；每当一个国度完成 T4，该国的范围、名称以及已经确定的城市便在地图上显示，尚未完成 T4 的国度继续隐藏。

### 城市状态显示

地图标明当前正在设计的城市和当前城市阶段，并区分排队、设计中、**WAITING_FOR_GENERATION** 与已经完成生成。规划完成但尚未落地的城市不得显示成已经存在于世界中的城市。

### 玩家信息与 Debug 信息

普通地图层优先显示地形、群系、国度边界、城市位置和开放状态。Debug 信息作为可切换的附加层，显示 W 进度、当前国度的 T 阶段、当前城市、城市设计阶段、等待 Agent 和失败状态；普通玩家界面不直接暴露内部错误码或文件信息。

### 与区域开放的关系

区域开放以[大陆大洋分区开放与城市郊区隔离](../大陆大洋分区开放与城市郊区隔离-v0.1/README.md)为唯一依据，按整片大陆及附属海洋或独立大洋区域开放。地图显示的城市开放状态必须与实际规划区域开放结果一致。尚未开放的城市不能因为出现在地图候选或调试信息中就被当成可到达城市，已开放城市与不可传送区域也不能显示相反状态。

### 当前世界范围

冒险者地图只显示当前存档的 W、T、国度和城市结果，不能混入其他存档已经完成的地图区域或城市状态。W/T/City 运行产物、自动规划队列和地图读取根必须归属当前 world root；游戏实例级配置可以共享，但实例目录中的其他存档规划产物不得作为空存档的 fallback。客户端切换服务器或存档后也不得先展示上一连接的缓存快照。
