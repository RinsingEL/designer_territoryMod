# 世界设定与矛盾

**设计中案 · 2026-10-14**。创世时把文明、国度与城市的构思沉淀为这个世界唯一的设定，并加入尚未解决的矛盾，供居民、委托、剧情和游记共同取材。总纲见[异世界冒险体验](../../../../../10_product/异世界冒险体验/README.md)。

## 符合这片地理的文明

<small>原话：“现在我就是感觉我们LLM对地理、程序、配置等等的理解能力、创意性已经很好了，所以我希望加入一个类似动态策划的，每次创建游戏的时候都设置符合这个世界的文明、能够让玩家体会到我在感受这个随机出来的世界”</small>

**AI 总结：** 现有第一题的文化圈与国度构思、第二题的全国城市设计，已经让文明依据地理而生。本案在此基础上，把这些构思整理成一份完整的世界设定：各文明的来历、信仰与习俗、彼此关系、各城的定位与特色。之后所有系统只读取与自己相关的部分，保证前后一致。玩家选择带入前世时，以前存档的传说也在此时写进这个世界的历史，见 Realmsaga 的[游记与前世传说](../../../../../addons/realmsaga/02_游记与前世传说.md)。

## 世界有悬而未决的矛盾

**AI 总结：** 设定里除了描述，还包含两三条尚未解决的矛盾：国度之间的争端、文明内部的分歧，或威胁整个世界的隐患。矛盾是剧情、传闻和部分委托的来源，让世界读起来像一个正在发生的故事。玩家在游戏中通过传闻、书籍和 NPC 闲聊逐渐了解它们。

## 文明的生活方式由设定决定

**AI 总结：** 每个文明的常见职业、商品偏好、委托风格、说话方式以及擅长的玩法，在创世时随设定一起定下，所属城市直接继承，城市内容配置因此只需说明本城的特别之处。擅长的玩法不与风格硬绑定，规则同[城市物品池与多商品交易](../../../../../addons/realmfolk/需求案/05_城市物品池与多商品交易.md)。

## 在创世阶段完成

<small>原话：“LLM我目前直接打算用最强的agent，因为识图能力要求很高”</small>

**AI 总结：** 世界设定由最强的 Agent 在创世阶段结合地图完成。游戏进行中不改写设定本身；世界因玩家和剧情发生的变化另行记录，并与设定一起作为后续内容的依据。
