# T2 与 T4 坐标选址

**设计中案 · 待开发 · 2026-10-14**。T2 选国度首都核心、T4 选城市地址时，由 AI 直接看地图给出世界坐标，不再先由程序筛出 Top Patch 候选再挑选编号；做法与当前 D4 一致。用户已确认方向，等待排期接管。接管实现后，[Patch 探索式选址](../Patch探索式选址-v0.1/README.md)与 [T4 城市候选分级精扫选址](../T4城市候选分级精扫选址-v0.1/README.md)退役。

## 用坐标代替 Top Patch

<small>原话：“如果是top patch，这个你可以稍微看看git，我目前应该是已经把D4里的top patch给删掉了，原因是我发现现在是LLM其实对坐标的理解能力很厉害了，以前我之所以做top patch就是为了给LLM搭脚手架，减轻他的识图任务，而现在已经不需要了 ，所以T4选择城市地址、D4选择阵列地址，完完全全都可以使用普通的坐标的（就像现在的D4）”</small>

**AI 总结：** 适用于 T2 首都与 T4 城市。Top Patch 原本是帮 AI 识图的脚手架，现在 AI 读坐标图的能力已足够，不再需要。T4 选城改为：程序提供带坐标刻度的本国地形、水体与群系总览图，AI 看图后直接给出首都与各城市的世界坐标及选址理由；程序负责检查坐标在本国国土内、不落水、与其他城市保持间距，并把结果交给 D3 局部复核。D3 局部复核仍是城市能否落地的最终依据。地形总览沿用已有的生成器原生粗地形。

## T2 首都同样用坐标

<small>原话：“是的，T2首都和T4城市我认为都可以用坐标，这个只需要写进案子里就行了，并标记为待开发（话说这种开发到一半需要查缺补漏的需要增加新的状态吗）”</small>

**AI 总结：** T2 为每个国度选首都核心时，同样由 AI 看世界总览图直接给出坐标和理由，程序检查坐标在陆地上、彼此有足够距离；后续 T3 国土扩张以这个坐标为起点。T2 与 T4 都不再依赖 Top Patch 候选，Patch 只作为地貌数据在图上呈现。
