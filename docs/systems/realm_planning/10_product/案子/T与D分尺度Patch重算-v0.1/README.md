## AI 需求总结

### 各尺度重新计算Patch

W、T和D处在不同观察尺度时，**每个尺度都要根据该尺度看到的地形重新形成自己的Patch**；上一级Patch只负责提供搜索范围和来源关系，不能把上一级较粗的边界直接放大后当成本级Patch。

### T阶段候选Patch

T阶段进入国度或大陆范围后，应在T自己的尺度重新看地形并生成候选Patch，候选数量、面积、边界和预览高亮都以这次结果为准，不能继续显示W阶段规整的大格子外形。

### D阶段城市Patch

D3继续使用自己的城市尺度重新生成Patch；同一种连续地貌即使跨过内部扫描分区，也应视为同一个连续Patch，不能因为扫描分区边界被人为切碎。D4继续使用D3产出的城市尺度Patch。
