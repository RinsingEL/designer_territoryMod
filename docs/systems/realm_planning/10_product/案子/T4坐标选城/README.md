# T4 坐标选城

**设计中案 · 2026-10-14**。T4 为国度选城市地址时，由 AI 直接看地图给出世界坐标，不再先由程序筛出 Top Patch 候选再挑选编号；做法与当前 D4 一致。接管实现后，[Patch 探索式选址](../Patch探索式选址-v0.1/README.md)的 T4 部分与 [T4 城市候选分级精扫选址](../T4城市候选分级精扫选址-v0.1/README.md)退役。

## 用坐标代替 Top Patch

<small>原话：“如果是top patch，这个你可以稍微看看git，我目前应该是已经把D4里的top patch给删掉了，原因是我发现现在是LLM其实对坐标的理解能力很厉害了，以前我之所以做top patch就是为了给LLM搭脚手架，减轻他的识图任务，而现在已经不需要了 ，所以T4选择城市地址、D4选择阵列地址，完完全全都可以使用普通的坐标的（就像现在的D4）”</small>

**AI 总结：** Top Patch 原本是帮 AI 识图的脚手架，现在 AI 读坐标图的能力已足够，不再需要。T4 选城改为：程序提供带坐标刻度的本国地形、水体与群系总览图，AI 看图后直接给出首都与各城市的世界坐标及选址理由；程序负责检查坐标在本国国土内、不落水、与其他城市保持间距，并把结果交给 D3 局部复核。D3 局部复核仍是城市能否落地的最终依据。地形总览沿用已有的生成器原生粗地形。
