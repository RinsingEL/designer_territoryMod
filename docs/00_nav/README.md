# 全局导航

`00_nav/` 只负责把任务送到正确的领域、角色和真值入口，不承载开发流程正文、规范细则、系统现状或历史计划。

## 开局读取

1. 读取本页和 `task_router.md`，确定本轮唯一活动角色。
2. 通过 `domain_map.md` 进入目标 system / tool 的 `README.md`。
3. 按角色只读取一份 `01_workflows/` 流程，再按任务读取目标系统的 `10_product/`、`20_contracts/`、`30_code_guide/` 或 `40_tests/`。
4. 只有任务确实触发规范或共享契约时，才读取 `02_standards/` 或 `03_shared_contracts/`。

## 导航文件

| 文件 | 只回答 |
| --- | --- |
| `task_router.md` | 这是什么任务、由哪个角色处理、下一份文档读什么。 |
| `domain_map.md` | 任务属于哪个系统或工具，入口在哪里。 |
| `repo_map.md` | 内容应写入实现仓库还是文档仓库。 |

## 全局目录

| 目录 | 内容 |
| --- | --- |
| `01_workflows/` | 开发、验收、诊断、修复、发布等执行流程。 |
| `02_standards/` | 角色权限、仓库结构、文档编写和提交规范。 |
| `03_shared_contracts/` | 跨系统共用的数据或接口契约。 |
| `systems/`、`tools/` | 各领域当前方案、契约、代码导览和测试真值。 |

任何新增细则都应写入其唯一归属文档；本目录只增加链接，不复制正文。
