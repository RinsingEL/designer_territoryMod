# 全局导航

任务从用户当前需求开始，导航只帮助定位领域，不承担角色、阶段门或强制阅读顺序。

## 读取方式

1. 能直接从代码和用户描述判断范围时，不必先读导航。
2. 无法判断领域时读取 `domain_map.md`，再进入目标 system / tool README。
3. 只读取当前任务直接涉及的需求案、契约、代码入口或测试入口，不默认加载全部文档层。
4. 按任务需要使用三份项目规则，不声明活动角色，也不因流程切换中断同一项工作。

## 导航文件

| 文件 | 用途 |
| --- | --- |
| `task_router.md` | 判断本次只需要哪类文档或项目规则。 |
| `domain_map.md` | 定位目标系统、工具和跨系统产品主线。 |
| `repo_map.md` | 判断内容属于实现仓库还是文档仓库。 |

项目规则位于 `../01_workflows/`：需求案、真实游玩 Agent Loop、开发与 Bug 留档。
