# 任务读取路由

本页是项目工作流标题、准确路径和触发条件的唯一索引。需要进入项目开展读取、修改、测试或真实游玩时先读本页；它不定义角色或强制阶段流转。

## 工作流索引

只有当前任务命中“读取条件”时才读取对应正文，不得为了熟悉项目而预加载全部工作流。

| 工作流标题 | 准确路径 | 读取条件 |
| --- | --- | --- |
| 需求案规则 | `../01_workflows/需求案规则.md` | 编写、整理或修改需求案时。只分析或实现既定需求时不读。 |
| 真实游玩 Agent Loop 规则 | `../01_workflows/真实游玩AgentLoop规则.md` | 通过 MCP 进行真实游玩、游戏内预览或验收时。普通自动化测试不读。 |
| 开发与 Bug 留档规则 | `../01_workflows/开发与Bug留档规则.md` | 修改实现、配置、测试、MCP、项目工作流，或确认发现/修复 Bug 时。纯只读分析且尚未确认 Bug 时不读。 |
| 需求案清理与真值收敛规则 | `../01_workflows/需求案清理与真值收敛规则.md` | Session 时间戳检查输出 `DUE` 且用户同意启动清理后。输出 `OK` 或用户未同意时严禁读取。 |

## 项目材料路由

| 当前任务 | 读取内容 |
| --- | --- |
| 理解功能目标和玩家行为 | 目标领域 `10_product/`。 |
| 修改字段、schema、配置或接口 | 目标领域 `20_contracts/`。 |
| 定位实现入口 | 必要时读取 `30_code_guide/代码导览.md`，优先以代码为准。 |
| 执行已有测试 | 目标领域 `40_tests/测试入口.md`。 |
| 继续同一开发任务或任务交接 | 实现仓 `E:\Mod_Dev\StructureBinder\dev_docs\README.md`，再读取对应范围的 `active/` 任务记录。 |
| 排查已登记 Bug | 实现仓 `E:\Mod_Dev\StructureBinder\dev_docs\README.md`，再读取对应系统或工作流的 `故障索引.md` 和直接关联记录。 |
| 普通需求理解、新任务定位或实现验收 | 不读取 `dev_docs/` 历史记录。 |

## 定位兜底

无法从用户描述直接定位材料时，依次读取 `domain_map.md`、目标 system / tool README，再选择当前任务需要的文档层。仍无法命中时，只在已锁定的领域目录内使用 `rg` 搜索；不得先扫描全部需求案、全部文档仓库或整个 `dev_docs/`。

同一任务可以连续完成开发、聚焦验证和结果展示，不需要切换角色。MCP 真实游玩期间仍必须保持工具使用者边界。
