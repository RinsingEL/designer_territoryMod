# 任务读取路由

本页只帮助选择必要材料，不定义角色或强制阶段流转。

| 当前任务 | 读取内容 |
| --- | --- |
| 编写或修改需求案 | `../01_workflows/需求案规则.md` 和用户原始描述。 |
| 真实游玩、MCP 调用、游戏内预览 | `../01_workflows/真实游玩AgentLoop规则.md` 和目标工具说明。 |
| 修改实现、测试、MCP 或工作流 | `../01_workflows/开发与Bug留档规则.md`，并建立任务记录。 |
| 发现或修复 Bug | `../01_workflows/开发与Bug留档规则.md`，登记故障索引。 |
| 理解功能目标和玩家行为 | 目标领域 `10_product/`。 |
| 修改字段、schema、配置或接口 | 目标领域 `20_contracts/`。 |
| 定位实现入口 | 必要时读取 `30_code_guide/代码导览.md`，优先以代码为准。 |
| 执行已有测试 | 目标领域 `40_tests/测试入口.md`。 |

同一任务可以连续完成开发、聚焦验证和结果展示，不需要切换角色。MCP 真实游玩期间仍必须保持工具使用者边界。
