# 路线图

**唯一的全局进度页 · 2026-10-14 建立。** 列出每条职责链现在走到哪一步、下一个版本里程碑要做什么。各案的需求以案子正文为准，本页只记录状态；接管、完成或验收时同步更新本页。

状态取值：`设计中` → `已接管` → `开发中` → `待游戏验收` → `完成`。身份的含义见[需求案规则](../01_workflows/需求案规则.md)，版本规则见[版本规则](../02_standards/版本规则.md)。
