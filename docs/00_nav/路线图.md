# 路线图

**唯一的全局进度页 · 2026-10-14 建立。** 列出每条职责链现在走到哪一步、下一个版本里程碑要做什么。各案的需求以案子正文为准，本页只记录状态；接管、完成或验收时同步更新本页。

状态取值：

| 状态 | 含义 |
| --- | --- |
| `设计中` | 还在讨论，需求可能变化。 |
| `待开发` | 用户已确认方向，等待排期接管。 |
| `开发中` | 已接管为实现当前案，正在实现。 |
| `部分实现` | 已有可用的实现，但与案子要求还有缺口；必须在本页或案子里列出缺口，补完前不算完成。 |
| `待游戏验收` | 实现与自动测试完成，等待真实游玩验收。 |
| `完成` | 游戏验收通过。 |身份的含义见[需求案规则](../01_workflows/需求案规则.md)，版本规则见[版本规则](../02_standards/版本规则.md)。

## 0.3 开发版实机记录 · 2026-10-15

实现仓 `addons/realmfolk/docs/居民生活试玩.md` 保存图文结果。118 项 Java、24 项 Python 测试通过；独立真实客户端场景通过正式快速配置生成 13 常住居民和 2 访客，验证工作、睡眠、进食、坐姿、避雨、商店、治安打断、拆床换床、堵门恢复与存档重载。

旧自然城市副本已验证真实设施导入及人物兼容；发现部分建筑高台缺少连续入口、旧人口超过实际床位。程序如实报告缺口；副本补台阶后的睡眠通过，不代表原城市素材已经修复。全城连续往返、新导出清单随自然生成落地整链、全部 Mod 家具适配仍需后续覆盖。当前交付可试玩开发版；主模组保持 0.2.0，尚未宣告 0.3 里程碑达成。
