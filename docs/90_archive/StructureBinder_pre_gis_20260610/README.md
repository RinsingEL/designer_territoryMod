# StructureBinder pre-GIS 历史归档

本目录恢复自文档仓库提交 `b1e33c7`，即 `76c3d82` 大规模 GIS 方案定基线与旧文档清理之前的状态片段。

该归档用于保留旧 city / workFlow 设计资产，方便后续重建城市、国度、工作流阶段时查阅。它不作为当前真值来源。

## 恢复内容

- `city/10_product/`
  - 旧城市主模块、C 链重构、道路接口、次级结构等产品方案。
- `city/20_contracts/`
  - 旧 C8/C9、道路接口、次级结构、C 链配置表等契约草案。
- `city/30_code_guide/`
  - 旧城市模块代码导览和功能实现说明。
- `city/40_tests/`
  - 旧城市模块验收、影响面和手动测试资料。
- `workFlow/`
  - 旧 W/T/C 阶段工作流文档。

## 使用边界

1. 当前有效方案仍以 `docs/systems/`、`docs/tools/` 和 `docs/00_nav/` 为准。
2. 本目录只读参考，不直接参与当前实现任务验收。
3. 若要把旧设计重新纳入主线，应按当前从 0 到 1 流程重写到对应系统文档中。
4. 旧文档中的 AI image、逐步 AI 求解、旧 C 链字段和旧 workflow 名称，均需要按地貌驱动 GIS-C 链重新评估。
