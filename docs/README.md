# Designer Territory Mod 文档

本仓库保存 Geomantia 当前有效的需求案、稳定契约、必要代码入口、测试入口和项目协作规则。实现代码与开发/Bug 留档位于 `E:\Mod_Dev\StructureBinder`。

## 阅读原则

- 从用户当前需求开始，不要求先声明角色或加载固定文档组合。
- 无法判断领域时使用 `00_nav/domain_map.md`。
- 只读取当前任务直接需要的文档；用户最新确认的原话和示意图优先于既有需求案。

## 目录职责

| 目录 | 职责 |
| --- | --- |
| `00_nav/` | 系统、工具和仓库定位。 |
| `01_workflows/` | 需求案、真实游玩 Agent Loop、开发与 Bug 留档三项规则。 |
| `02_standards/` | 仓库结构、代码导览和提交等工程规范。 |
| `03_shared_contracts/` | 跨系统稳定数据或接口契约。 |
| `10_product/` | 跨系统产品主线。 |
| `systems/` | 各系统的当前需求、契约、代码入口和测试入口。 |
| `tools/` | 各工具的当前需求、契约、代码入口和测试入口。 |

## 三项项目规则

- `01_workflows/需求案规则.md`
- `01_workflows/真实游玩AgentLoop规则.md`
- `01_workflows/开发与Bug留档规则.md`

需求案不得混入实现、测试和过程记录。开发与 Bug 过程统一写入实现仓库 `dev_docs/`，不作为当前功能真值，也不默认进入后续任务上下文。
