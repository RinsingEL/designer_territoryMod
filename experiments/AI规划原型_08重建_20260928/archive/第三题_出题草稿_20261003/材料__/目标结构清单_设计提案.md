# 面向第三题的目标结构清单

状态：2026-10-03 讨论提案。本文重新设计“应该提供什么素材”，不是现有资产盘点，不表示任何条目或换皮能力已经完成，也不接管正式实现案。编号仅用于讨论，不是可提交的结构 ID。原 534 条索引仍仅用于核对存量。

## 设计出发点

第三题需要把城市设定转成可落地的空间。素材应帮助 AI 回答“缺什么功能、需要怎样的空间、选哪个建筑、如何组合”，而不是让它在数十个相似店名中猜测。

建议保留现有 12 类风格：蒸汽朋克、地中海、沙漠、矮人、精灵、空艇幻想、魔法学院、游牧、北欧、海洋幻想、哥特、废土拾荒。中式等仍是额外待补方向；松霁要求的中式门廊不能用精灵标签代替。

**核心是一种在本城布局中的作用，填充是一种重复布置方式，不应永久绑定建筑大小。** 一座小议事屋可以是村庄核心，一座大公寓可以是重复住宅。下文列出适合承担核心的候选，实际选哪些由城市定位决定。

通用建筑共用的是用途分类和选择逻辑。各风格应分别设计形体，不能拿同一栋盒子换色后宣称完成 12 种风格。也不要求每种风格都制作下列所有类型。

## 换皮分成三件事

| 标记 | AI 可以决定什么 | 边界 |
| --- | --- | --- |
| 材 | 在作者限定的部位选择材料组合，如屋面、柱梁、墙面、基础、布篷 | 不改变几何、入口和通路；不是无范围的全局方块替换 |
| 用 | 在作者允许的用途包中选择，如通用街铺→布店 | 改招牌、展示和适配的静态内装；必须具备对应空间，不能只改名字 |
| 型 | 选择独立做好的形体版本，如直排、转角、带院 | **这是不同结构版本，不属于换皮**；占地和入口可能不同，需重新参与布局 |

材与用都应有完整默认方案，不强迫 AI 从零配置每个方块。街铺等被标为“用途可配置”的建筑，选中时必须明确保留默认用途或指定允许的新用途；材可直接沿用全城方案。交易与居民行为仍属于第四题。

## A. 高频通用建筑：优先把这 12 类做好

这是选材主干。尺寸暂用小／中等相对级别，具体占地和层高在样板建模后确定，避免先用统一网格压平所有风格。

| 编号 | 基础结构 | 必须体现的空间差异 | 用途配置范围（建议） | 材 | 独立形体版本与阵列条件 |
| --- | --- | --- | --- | --- | --- |
| A01 | 小型独户住宅 | 独立入口、起居与睡眠、少量储物 | 默认住宅；内部生活摆设可选，不随意改作店铺 | 是 | 紧凑／带小院；独立间距，不能默认贴墙 |
| A02 | 连排住宅单元 | 面街入口、连续街墙、后侧采光或院落 | 默认住宅 | 是 | 中段／端头／转角；只有明确允许贴邻的侧面能拼接 |
| A03 | 合住屋／集体住舍 | 共用起居、多个独立睡眠空间、共用通道 | 旅工宿舍／学徒住舍／常住合居；不自动等于旅馆 | 是 | 直形／院落形；较大配套，不必村村建 |
| A04 | 单层通用街铺 | 前场展示交易、后场储物，顾客与店主均可通行 | 杂货／布匹／木器／工具零售／干货；只卖不产 | 是 | 窄面深进／宽面浅进；转角为独立版本 |
| A05 | 前店后宅／下店上宅 | 店面与居住动线分开，私人储藏完整 | 与 A04 相同；以家庭经营为主 | 是 | 前后分隔／上下分隔；不得只在店里塞一张床 |
| A06 | 前店后作的轻作坊 | 接待、工作台、原料与成品区，有搬运路线 | 裁缝／皮具装配／小型木器／工具手工修补；仅作者逐项确认的工序 | 是 | 紧凑铺面／带工作院；大锯木、鞣制、熔炉另选专用建筑 |
| A07 | 通用小仓房 | 存货区、收发入口、装卸净空 | 粮袋干货／木箱杂货／布料工具，按不同内装选择 | 是 | 独立／贴后院；散装料、冷藏和危险物不在通用范围 |
| A08 | 通用摊位／小棚铺 | 摊主位置、顾客面、背后补货空间 | 蔬果／干货／布匹／小器物；选陈列包 | 是 | 单摊／成对背靠背；熟食火源需要另做适配版本 |
| A09 | 公共小厅／服务屋 | 入口等候、小型会面或办理空间、储物 | 公告与接待／社区议事／行会办事；无专门设备的公共用途 | 是 | 独立／临街；不是医院、学校等用途的万能替身 |
| A10 | 小型食肆 | 前厅就餐、后厨、食材储存与服务通道 | 茶食／普通饭食；烘焙等专用工艺需已做好的设备版本 | 是 | 单厅／带外摆；不通过换名提供住宿 |
| A11 | 小型客栈 | 接待、公共休息、客房及后勤；明确是否自带厨房 | 基础住宿／带餐食住宿，仅在相应空间具备时选择 | 是 | 紧凑／庭院；床位容量后续核定 |
| A12 | 作业棚／有顶院棚 | 有顶开放作业或暂存场，留搬运面 | 木料整理／工具维修台／货物分拣；仅静态作业表达 | 是 | 独立棚／沿院棚；不能冒充封闭车间或大型设备 |

**优先复用 A04、A05、A06、A07、A08。** 这些最容易把几十个店名收敛成少数有明确空间区别的基础结构。A04 的工具店不生产工具；A06 的修补铺不自动具备锻造炉。

A01—A03 的形体多样性比不断换家具更重要。住宅往往占城镇面积的大头，只做一个住宅外壳会使其他优质素材也被重复感淹没。

## B. 条件性专业建筑：功能需要才展开

以下不强行归入万能店铺。它们的生产流程、设备或场地关系会影响结构。

| 编号 | 结构类型 | 与通用建筑不可互换的原因 | 可配置范围 |
| --- | --- | --- | --- |
| B01 | 炉火工坊 | 炉体、排烟、防火隔离、操作与原料区 | 材有限；锻造／窑烧／玻璃等分作独立工艺版本，不靠招牌切换 |
| B02 | 大件木作与锯料院 | 长料通道、大件加工区、露天堆料 | 材；家具装配／木材加工只有各自设备与空间成立时才提供用途包 |
| B03 | 苗圃／温室／育种庭 | 苗床、采光、水源与维护通道 | 材；树苗／草药／花卉按种植条件标注，温室与露天是不同形体 |
| B04 | 农舍与农事院 | 农具、收获暂存、田地出入口；房屋与田地分开 | 材；作物选择是独立种植单元的配置，不把整片农田焊进农舍 |
| B05 | 畜栏与饲养棚 | 圈栏、饲料、进出和隔离要求 | 材；只允许适配的动物类别，马厩不能随意换成任意畜舍 |
| B06 | 磨坊／加工房 | 明确加工设备与输送，动力条件可能改变选址 | 材；水磨、风磨、独立加工房是不同结构与场地条件 |
| B07 | 疗养屋／诊疗所 | 等候、诊疗、休养分区 | 材；静态空间用途，不承诺治疗行为 |
| B08 | 学舍／书室 | 教学或阅读空间、藏书与采光 | 材；小型教学／阅读可配置，共用前提是两种内装已适配 |
| B09 | 码头与岸边货棚 | 水陆高差、靠泊面与装卸路线 | 材；货运／客运是经验证的版本，不按风格名强制配水岸 |
| B10 | 驿站与交通院 | 旅人、货物、交通工具停靠和回转空间 | 材；车马／空艇／铁路需独立设施与入口条件 |
| B11 | 警戒屋／小岗楼 | 视线、值守、器械和出入口关系 | 材；不能把所有文化都默认布置城墙与军事设施 |

## C. 少量核心：按城市主旨挑选

建议核心先覆盖三个“职责”，每种风格先做其中最有表现力、最常用的少数样板；**不是每个城市固定放三座**。

| 核心职责 | 何时需要 | 需要表达的结构与空间 |
| --- | --- | --- |
| 公共组织 | 城市需要共同议事、行政或大型集会空间 | 公共到达、聚集中心、过渡空间和周边街道关系 |
| 产业／交换中心 | 城市设定强调某种生产、市场或交通 | 专门作业或交换空间、货流、服务配套关系；必须对应真实城市职能 |
| 文化／景观中心 | 城市设定确有文化活动或重要景观 | 明确可使用的公共空间、可辨认轮廓与到达序列；不默认所有城都有神殿 |

同一种通用客栈、市场或公共小厅也可以担任小聚落核心。先判断功能，不能先塞一个巨大地标，再围着地标找城市理由。

### 12 类风格的核心候选与建筑语言

以下是本提案的美术方向，描述希望做出的形体，不是对现有模型质量的认证。每行列出可选题材，不是必建清单。

| 风格 | 建筑结构应体现什么 | 核心候选（选择性制作） | 通用填充应延续什么 |
| --- | --- | --- | --- |
| 蒸汽朋克 | 砖石承重体与外露金属构架、大跨厂房、天窗与设备空间 | 工业会馆、中央制造厅、条件成立的交通总站 | 锯齿或分段屋面、厂窗、装卸口；住宅不能只复制厂房 |
| 地中海 | 厚墙与开口节奏、遮阴拱廊、坡瓦屋面和内庭 | 市场柱廊、公共庭院会馆、商贸交易院 | 有深度的街廊、露台与院落，避免只换白墙蓝窗 |
| 沙漠 | 内向庭院、厚墙、小外窗、遮阳过渡空间、平顶或穹顶组合 | 商队客院、集市厅、储水公共庭 | 窄巷街面与内院差异；水设施要有条件，非任意地块装饰 |
| 矮人 | 厚重基座、短跨粗柱、深门洞、层次明确的承重与锻造构件 | 石柱议事厅、公共锻造院、矿业交换厅 | 紧凑可靠的体量与加工细节；不是所有建筑都做成地下矿坑 |
| 精灵 | 先选内部语言：高幻想的轻盈柱架与曲线廊桥，或林间童话的不对称屋体与地形嵌合 | 枝拱议事厅、工艺庭院、公共花园长廊 | 住宅和店铺同样保持比例、屋面与构架特色，不能只加叶子 |
| 空艇幻想 | 轻构架、拉索、悬挑与垂直交通；区分普通地面街区与泊航设施 | 航行会馆、缆索泊塔、装配厅 | 屋面、支架与雨棚构造呼应；普通住宅不附赠无用途停机台 |
| 魔法学院 | 塔楼与普通体量搭配、连廊院落、采光与研究空间 | 大书库、教学会堂、观测庭 | 学舍、住舍与街铺有不同空间；晶体颜色不是风格主体 |
| 游牧 | 帐篷或毡房构架、织物覆盖、围合营地与可理解的组装方式 | 议事大帐、交换营地、行旅接待帐 | 住帐、铺帐、工作棚的入口和内部用途不同；不强做砖石连排街 |
| 北欧 | 长屋体量、清晰木构架、坡屋顶、石基与炉火空间 | 长厅、手工业会馆、条件成立的船修厅 | 街铺、住宅延续木构比例；内陆聚落不用强制长船装饰 |
| 海洋幻想 | 曲面或放射体量、壳肋构架、层台与明确的干湿边界 | 壳拱集会厅、潮岸交易院、海事会馆 | 把壳肋和层台做进形体；地面可用版与涉水版分开 |
| 哥特 | 尖拱、竖向窗组、陡屋面与扶壁等构件按尺度使用 | 市民会堂、大书库、纪念花园厅 | 小住宅不需要大教堂全部构件，靠比例与开口形成家族感 |
| 废土拾荒 | 可读的原骨架、拼接加建、结构补强与材料再利用 | 拆解交换院、修复工坊、居民公共厅 | 支撑与修补有逻辑；不靠随机堆杂物表达废土 |

“精灵”仍保留为顶层风格；内部两个方向可以先选一个做整套样板，不急着同时建两套。其他带主题的风格也必须落实形体，而不是用设施名代替建筑语言。

## D. 城市连接与小型配套：单列，别塞进住宅填充池

| 类型 | 为什么第三题需要它 | 复用与换皮 |
| --- | --- | --- |
| 门廊／雨棚／短连廊 | 形成店前过渡与公共建筑接近空间 | 材；直段、转角、端头为独立形体，需匹配高度与入口 |
| 院墙／围栏／院门 | 明确前后院和公私边界 | 材；按连接端拼接，不随机撒在地块内 |
| 台阶／坡道／小平台 | 连接入口与地形 | 材；长度、高差有实际适配范围，不是自动解决任意坡度 |
| 小桥 | 连接有明确对岸与高差的路径 | 材；跨度与宽度对应独立规格 |
| 公共水点／洗涤点 | 补足公共服务空间 | 材与已适配的静态用途；是否供水另行验证 |
| 长椅／灯具／路标／公告牌 | 补充使用、照明与方向信息 | 材；标志内容可配，不改变结构功能 |
| 树池／花架／小庭园 | 组织停留与绿化空间 | 材与适配植物；不用于掩盖建筑本体缺乏风格 |
| 装卸平台／货架／木料架 | 让工坊与仓房外部服务关系可见 | 材与陈列；需留搬运通路 |

这些按道路、入口、庭院等空间关系布置。灯、树和长椅不与住宅竞争同一“随机填充池”，也不应用它们填满剩余全部空地。

## AI 最终应看到的功能树

```text
城市设定 → 风格选择（必要时确定内部方向）
├─ 居住 → 独户 / 连排 / 合住 → 具体形体 → 材料方案
├─ 商贸 → 街铺 / 店宅 / 摊位 → 明确保留或更换用途 → 材料方案
├─ 生产 → 轻作坊 / 作业棚 / 专业工艺建筑 → 适配用途 → 场地条件
├─ 旅居餐饮 → 食肆 / 客栈 / 交通驿站 → 明确服务范围
├─ 公共服务 → 小厅 / 学舍 / 疗养 / 警戒 → 对应实际需求
├─ 仓储与供给 → 小仓 / 农事 / 苗圃 / 畜栏 → 对应实际需求
├─ 核心候选 → 公共 / 产业 / 文化 → 只有城市需要才选
└─ 连接与配套 → 门廊、围栏、台阶等 → 根据已选建筑与地形补齐
```

不要首轮向 AI 展开所有建筑、所有用途包和每个方块替换选项。先显示能满足当前功能的基础类型，再展开少数具体版本；给“保留默认”一个明确且完整的选项。街铺允许混合用途的阵列要列出具体用途成员，不能把一个配置复制成整条同名商街。

每个候选至少要让 AI 看懂：实物图、占地与高度、入口和可贴邻面、默认用途、可配置用途、场地条件、不可替代的专门设施。材质变体折叠在同一结构下；改变占地、入口或内部流线的形体变体分开显示。

## 松霁用这份清单怎么解题

| 第二题需求 | 先找的结构类型 | 需要作出的选择 |
| --- | --- | --- |
| 居民日常生活 | A01、A02，必要时 A03 | 选择符合地形和街区密度的住宅形体，不先定人口 |
| 木器与工具修补 | A06＋必要的 A12；大件生产才展开 B02 | 木器制作与工具手修是否可共用既有用途包；需要炉火则另选 B01 |
| 织物修补 | A06 或有适配工作区的店宅版本 | 选择裁缝用途，不为一个行业再设计整套城市骨架 |
| 日用品交换 | A04／A05，少量 A08 | 每个实例明确杂货、工具或布匹等用途，避免重复堆店 |
| 旅人食宿 | A11；厨房不足才补 A10 | 核对餐食空间，避免已有完整客栈又无理由加同功能建筑 |
| 树苗与木材交换 | B03、A07、A12 | 苗圃与堆料需要各自场地，不能把树装饰当作树苗生产 |
| 聚落公共中心 | A09 或一座小型工艺／议事核心 | 根据服务关系决定，不强制宏大精灵神殿 |
| 中式门廊与精灵枝叶 | 带合适形体的建筑及配套构件 | 需要真实构造支持；单纯替换木材不能完成这一混合语言 |

这是一份需求到素材类型的推导，不预定建筑数量、具体 ID 或布局结果，也不是新的第三题答卷。

## 建议先制作的样板组

先选一个风格完成 **8 个基础原型：独户住宅、连排住宅、街铺、店宅、轻作坊、小仓、客栈、公共小厅**。连排中段与端头是必须分别验证的形体，因此“8 个原型”不是“8 个 NBT”的数量承诺。店铺至少展示两个空间确实适配的用途，住宅至少展示两个有形体差异的版本。

这组样板能先验证居住、商业、生产、仓储、旅居与公共空间的组合，以及材料换皮和用途配置是否真能减少选材负担。苗圃、重工设施与具体城市需要的配套按缺口补充。精灵风格适合先做这轮质量样板，但若直接服务松霁，还必须处理其中式构造要求。

优先检查四件事：远看能否认出风格；不同功能是否真的改变空间；重复布置时是否有合理的街道与入口关系；换用途后是否仍能解释每个房间与设备。通过后再扩展第二风格和更多核心，不先追求把 12 类风格全部铺满。
