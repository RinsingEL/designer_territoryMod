从 [第三题 A 题面](../题目/03_单城结构与阵列设计.md) 开始，依次读：

1. [松霁城市卡](松霁城市卡.md)
2. [目标建筑类型与配置菜单](设计准备_建筑菜单.md)

按 [答卷模板](设计准备_答卷模板.md) 输出建筑需求方案。这些材料足以开始本轮；正式结构池、实物预览、D3 和编译入口不是 A 的启动条件。目标菜单和风格建议仍可在试题中修订，不是已实现能力。

## 讨论者按需展开

- [完整目标结构清单提案](目标结构清单_设计提案.md)：通用、专业、核心和连接配套的设计思考。只沿用旧风格名称，所有内部定义均可重新设计。
- [换皮与用途配置约定](换皮与用途配置.md)：材料与静态用途的边界。
