## 目录各放什么

| 目录 | 内容 |
|---|---|
| `data/题目/` | 各题的编辑源文件；要改要求，改这里 |
| `data/第一题_国度设定/` | 第一题地图、风格、功能与玩法资料 |
| `data/第二题_领土内城市选址/` | 当前第二题的完整独立资料；题目.md是源文件的导出副本 |
| `result/` | 各题的统一答卷保存目录，以及迁址起点和成功的真实扩张结果 |
| `archive/` | 旧答卷、未考虑初始大陆的起点、被阻断的尝试、旧A/B采样；仅查历史 |
| `tools/` | 生成与实机操作脚本，见其中说明 |
