## 读图限制

全部是 `prior` 生成器先验，并非已加载方块测量或施工验收。每块仍有 5568 格带 edgeDirty（约 34%），边缘邻域指标不完整；对照图白框仅示意距边缘 48 方块的核心区，不代替逐格有效性判定。未知分类仍按返回保留。高度图分别自动缩放，跨图不能直接用相同灰度比较绝对高度；坡度图也应查各自 manifest 的数值范围。

当前没有逐格数值导出，原始产物是预览与统计；不能据此完成碰撞、供水、通航或可施工面积验证。图层不自动带世界气候或群系，请结合本包世界图使用。

## 调用记录

GET /realm/status 与 /gis/status 确认当前存档和在线玩家，服务 ready。POST /gis/refresh 的每次请求与返回均保存在本目录。

1. A/B 初扫：步长 16；各 1024 格完成，960 格 edgeDirty，分辨率不足以作为最终局部资料。
2. A/B 细扫：改步长 4；请求点在分块边角，各 14545 格完成但分块仍有 1839 格 pending。
3. A/B 完整采样：将请求中心移到对应分块中心，维持 radiusChunks=32、步长 4；两处最终 16384 格完成、pending=0、failed=0。最终产物以“完整返回”和 A/B 图层为准。

API 请求 radiusChunks=32 不代表交付了中心两侧各 512 的完整正方形，实际范围以返回 region 为准。没有把旧温湿度回填指纹问题算作已修复；本次直接调用局部采样，未覆盖原 W 图包。
