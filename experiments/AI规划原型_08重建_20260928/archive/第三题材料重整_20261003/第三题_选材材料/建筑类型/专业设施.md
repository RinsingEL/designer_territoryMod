# 条件性专业设施

只为明确的城市需求展开。专业设施的工艺与场地要求，不能靠改名或换材获得。

| 类型 | 必须说明的条件 |
| --- | --- |
| 炉火工坊 | 炉体、排烟、防火与操作空间；锻造、窑烧等工艺分别适配 |
| 大件木作院 | 长料通道、加工区、堆料与装卸 |
| 苗圃／温室 | 苗床、采光、水源与维护通道；露天与温室分别设计 |
| 农事院／畜栏 | 农具、收获暂存或饲料、圈栏与进出；不把整片农田固定在房屋上 |
| 磨坊／加工房 | 明确设备和动力条件，水磨与风磨不是材料变体 |
| 疗养屋／学舍 | 诊疗休养或教学阅读空间，不由普通小厅自动替代 |
| 码头／交通驿站 | 水陆高差或交通工具停靠、回转、装卸条件 |
| 警戒屋 | 值守、视线与出入口关系，不默认所有聚落都需要 |

本题尚不验证精确地形与运行机制，可留下场地和工艺缺口；不要把风格名称当成建设上述设施的理由。
