# 连接与配套

| 类型 | 用来处理什么关系 |
| --- | --- |
| 门廊、雨棚、短连廊 | 入口过渡、店前停留、建筑间联系 |
| 院墙、围栏、院门 | 公私边界与院落进出 |
| 台阶、坡道、平台、小桥 | 入口高差或路径连接，需要后续场地核对 |
| 公共水点、座椅、灯牌 | 公共服务、停留与识别 |
| 树池、花架、小庭园 | 绿化、遮蔽与庭院关系 |
| 装卸平台、货架、木料架 | 仓房与作坊外部服务，保留搬运通路 |

根据已提出的建筑与空间关系选择配套，不拿装饰填满所有空地。连廊转角、桥梁跨度等是形体规格，材料换皮不改变连接条件。绿化不能代替建筑本体的风格构造。
