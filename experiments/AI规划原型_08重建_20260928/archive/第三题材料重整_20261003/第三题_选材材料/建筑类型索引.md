# 建筑类型索引

下列都是目标类型提案，不是现成结构池。按城市需求选择分类阅读，不要求每类都建。编号只用于讨论，不是运行时结构 ID。

| 需要判断什么 | 按需打开 |
| --- | --- |
| 独户、连排、合住与重复住宅 | [居住](建筑类型/居住.md) |
| 街铺、店宅、摊位和用途配置 | [商贸](建筑类型/商贸.md) |
| 轻作坊、仓房、作业棚及专业工艺边界 | [生产与仓储](建筑类型/生产与仓储.md) |
| 餐食、住宿、公共服务与本城核心 | [旅居与公共](建筑类型/旅居与公共.md) |
| 农事、苗圃、特殊设备、交通等条件性设施 | [专业设施](建筑类型/专业设施.md) |
| 入口过渡、连接与庭院配套 | [连接与配套](建筑类型/连接与配套.md) |

核心是本城中的作用，不是固定的大建筑类别。可重复建筑也可以在某个小聚落中成为核心。菜单无法表达需求时，说明缺项或建议调整，而不是勉强归类。

同一功能在各风格里的形体表达、适配与换皮范围，见 [20 种新风格清单](风格索引.md)。按需展开，不沿用旧模型标注。

风格不附带核心或行业，使用者、职能与环境的组合见 [设计组合](设计组合.md)。
