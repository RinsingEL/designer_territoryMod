# 共有生活与城市职能

这份资料补充各国共有的生活与生产需求。功能大类可用于机械、魔法及其他文化背景；国度已有的文化和模组倾向决定这些需求如何被处理。奥伦仍以维伦工匠文化、Create、Immersive Engineering、Chipped 为主要设计方向。

## 通用职能

| 职能领域 | 可考虑的需求 |
|---|---|
| 农业与食品 | 种子和作物、畜群、食物加工、储备、居民与旅客饮食 |
| 材料与制造 | 建材、工具、日用品、加工、维修和回收 |
| 商贸与运输 | 集散、采购、交换、仓储、运输与旅途补给 |
| 居住与公共服务 | 常住生活、照护、公共事务和基础供应 |
| 知识与技艺 | 教育、研究、工艺传承、记录和作品交流 |
| 旅行与探索 | 旅居、休憩、探索准备、归来补给与收藏 |

这些是思考维度，不是预先分配的城市类型。一座城市可以兼具多个职能，多座城市也可以承担相同职能；无需每类安排一城，不必另交一张分类表。考虑城市服务的周边村落、生产地和旅行范围，不把所有生产都塞进城市内部。

## 原版生活与地方物产

原版的作物与种子、食物、木石建材、羊毛、工具等，同样可以成为城市生产、消费与交换的内容，不必为每项活动寻找一个额外模组。可在设计中选择具体的作物、食品和材料，说明居民生产或消费什么、玩家可以参与什么。

地方特色可以来自作物选择、加工方式、食物偏好、交易内容或技术使用。国家之间、城市之间都允许重复；相似环境采用相似作物和生计是正常结果，不需要人为制造互斥特产。共有生活也不要求每座城都自给自足。

地图为地方选择提供理由，但文化偏好和发展计划也是合理的设计依据。可以写明计划种植、加工或交易的内容；这些不等于扫描已证实存在农场、产量或资源储量。气候适应可以作为创作设定，不能据此宣称原版已经实现对应的作物气候限制或增产机制。具体供水、种植和材料条件统一留待落地核验，不必因此回避具体生产内容。

## 与国度倾向的关系

先考虑居民和玩家的需求，再结合当地条件与奥伦的技术传统形成城市定位。机械制造不只是制作更多机器，也可以支持共有生活和地方生产；模组组合应解释其作用，不能成为每城反复排列的三个名字。

保留奥伦既定模组倾向作为主要方向，允许城市按职能突出不同部分，原版活动自然参与。无需每城使用全部模组，也不靠不断新增模组制造区别；若确有必要提出额外模组，应标为待核验补充，不假定已安装或联动。

本资料是规划参考，不是现有资源、配方、NPC 服务或运行设施的清单。具体空间组织留到单城设计。
