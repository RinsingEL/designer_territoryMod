# 整体与局部换皮

这是设计约定，尚不表示运行时已实现。

- 结构声明：哪些部位属于哪个材料槽、默认值及允许选项。未标注部位保持原样。
- 整体方案：A 可按全城或明确的风格范围设置槽默认值；只应用于匹配范围且兼容的槽，不逐栋重复填写。
- 局部精修：B 选定结构后，仅记录需要覆盖的槽；未覆盖部分继续继承整体方案。

优先级：结构默认 → 全城方案 → 所属风格方案 → 单个实例覆盖。混合风格实例明确采用哪份风格方案，不按文件顺序猜测。删除局部覆盖即恢复继承。

例：全城木构用云杉、阶梯屋面用深色橡木阶梯；某客栈只将饰面改为靛蓝，其他继承。无木构槽的石塔不受木构设置影响。不兼容的选值记待处理，不能宣称替换成功。

槽按建筑部位标记，不能无差别替换全模型中的同种方块；屋顶替换不应连带改动家具。统一换材不改变形体，也不统一商铺用途或内装。
