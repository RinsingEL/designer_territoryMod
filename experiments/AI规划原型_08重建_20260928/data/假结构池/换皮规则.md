# 换皮与用途选择

条目声明可换槽与选项。A 定整体方案，B 再选结构与局部精修，继承规则见 [整体与局部换皮](整体与局部换皮.md)。实际替换程序不属于假池。

| 选项组 | 可选值 |
| --- | --- |
| 木构 | 橡木、云杉、深色橡木 |
| 石构 | 浅石、灰石、深石 |
| 框架 | 木架、石架、金属饰面架 |
| 墙面 | 木板、浅色填充、深色填充、砖面 |
| 阶梯屋面 | 橡木阶梯、云杉阶梯、深色橡木阶梯、石砖阶梯、红砖阶梯 |
| 板状覆面 | 木板、石板、金属饰面板 |
| 织物 | 米白、赭红、靛蓝 |
| 透光围护 | 实体、半透光、透明 |
| 饰面 | 本色、赭红、靛蓝、叶绿 |

- **换材**：只修改条目列出的槽，选值限对应组；未局部修改则继承整体方案，无适用方案才用结构默认值。组代表假池中的同形构件，不代表任意真实方块都可互换。位置、朝向、台阶形状和连接关系保持。
- **换用途**：从条目的用途列表中选一个，或明确保留默认；同时采用对应的展示、工作台与储存内装。一个实例一个主用途，共享用途须说明空间。
- **换形体**：从形体版本选一个。转角、额外厨房、上下分层等改变几何，不算换皮。

B 配置例：选定街铺的“布匹零售＋转角”，仅将屋面覆盖为“阶梯屋面:石砖阶梯”，其余继承。

B 记录具体编号、形体、用途和局部差异；A 不填逐栋配置。店宅的住宅功能不能被零售用途配置抹掉。
