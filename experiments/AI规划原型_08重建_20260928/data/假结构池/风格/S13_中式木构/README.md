# 中式木构

以柱梁开间组织空间，以屋面、出檐、台基和院落建立层次。宫殿、书院、祠庙、衙署、会馆、戏台与园林表达文化身份，庄园、客栈承担完整生活功能；小宅、街铺保持日常尺度。本提案选取一套可发展的木构语言，不概括所有中国建筑。

2026-10-05 按“核心指文化代表性”的确认补为 **22 项：8 项文化核心、2 项特色功能主体、8 项可配置配套、4 项基础通用建筑**。本轮新增 16—22 七项文化核心；不新增填充。假结构条目不承诺尺寸或容量；实际首版 NBT 和尺寸另见实现仓 `asset_catalogs/original_civilizations/S13_chinese_timber/`。

## 文化身份、功能区角色与布置方式

- **文化核心**：宫殿、书院、宗祠、庙宇、衙署、会馆、戏台院、园林。空间和活动共同表达文化身份，并非仅指大型建筑，也不要求每城配齐。
- **特色功能主体**：大庄园是居住与园艺经营主体，中型客栈是旅居主体。保留完整设计及已做模型，但不因完整或体量大就归入文化核心。
- **可配置配套**：店铺、作坊、货仓、食肆、棚摊与种植棚。复用布局，以成套商品、器具及内装配置区分用途。
- **基础通用建筑**：小宅、沿街院宅、合住宿舍、街坊议事厅。用途明确，不另造行业身份。

上述用于读池。具体功能区中的主体／配套角色、独栋／成组／重复布置另行决定，不与文化核心互斥：伐木屋可为伐木区主体，店铺可成组形成街市，宗祠也可能服务一个居住街坊。“填充”只描述规划时的布置用法，不作为文化价值等级。

## 换皮与默认配置

**材料换皮**沿用[整体与局部换皮](../../整体与局部换皮.md)：结构默认 → 全城方案 → 所属风格方案 → 单个实例覆盖。通用默认为构架=木构:云杉、墙面=墙面:浅色填充、屋面=阶梯屋面:深色橡木阶梯、饰面=饰面:本色；只应用条目声明的槽，允许值见[换皮规则](../../换皮规则.md)。宫殿的饰面默认为赭红。

**用途换皮**采用条目列出的成套配置，同时更换商品、招牌、工作器具、储存和展示陈设。只要选择“布匹店”等现成配置即可，不必另建一个建筑编号；必备空间、入口和通路保持。

**部件主题换皮**面向完整建筑内部的具名部件。例如大庄园的“种植棚”可由葡萄换成葫芦或花藤，“院侧店铺”可选择商品配置。完整布局和主体功能保持，相关部件按同一主题更换内装。全城材料方案不自动统一每家店的商品或每座庄园的园艺主题。

条目所列部件已包含在完整方案内，引用配套编号表示复用其配置，不重复计为一栋额外建筑。固定部件位使用条目指定的形体；增建店铺、改变厨房或移动院落等需选择已列形体，未列出的改动记录为设计需求。

B 配置示例：`MOCK-S13-14｜前宅后园｜庄园居住与园艺经营｜种植棚=葫芦棚；院侧店铺=布匹店；院侧货仓=布料｜饰面=饰面:靛蓝`。其余采用部件默认与整体材料继承，园艺主题和店铺商品可独立选择。A 仍只定整体需求与材料方向，不必逐栋配置。

## 编号沿用

01—12 沿用编号；03 明确为合住宿舍，04 扩展为含院侧形体的通用店铺，06 明确为可配置作坊，09 收敛为街坊议事厅，11 升级为固定含餐饮的中型客栈。13—15 为上一批新增条目；本轮 16—22 新增文化核心，14 大庄园归居住、11 中型客栈归公共与旅居，既有编号与模型保持。旧方案中的 11“基础住宿／紧凑客舍”不自动视为新版中型客栈，重新选用时需核对新版完整空间；历史答卷保持原记录。
