# 中式木构 · 生产与园艺

本页均为可配置配套；选用途或主题时同时采用相应器具、储物与陈设。材料槽的默认与继承见[风格说明](README.md#换皮与默认配置)。

## MOCK-S13-06 · 侧院作坊

- 分类：**可配置配套**。功能：接单、轻手作或维修、成品交付。
- 固定空间：接单交付处、工作间、原料与成品分区、可独立隔开的清洁作业间；顾客等候不占用工作通道。
- 形体：默认 **带工作院**；可选封闭工作间／带工作院。
- 用途配置：默认 **小型木作**，从下表选一项。各配置使用已有分区，保持主入口和通路。
- 材料槽：构架、墙面、屋面、饰面。
- 边界：手工作业配置不包含熔炼、锻造、鞣制或大规模原木锯解。

| 配置 | 具体工作 | 成套内装 |
| --- | --- | --- |
| 小型木作 | 制作、修补桌椅与柜架等木器 | 木作台、木料架、组装台、成品暂存；清洁间存放图样和样品 |
| 工具手修 | 拆装、换柄与简单手工修补 | 手修台、工具挂架、零件柜、待修与已修货架 |
| 织物修补 | 修补衣物和布制品 | 清洁作业间放缝补桌、布料柜与挂衣架，其余区域收件、存件 |
| 皮具装配 | 使用已处理皮料制作或修补小件皮具 | 裁料台、手缝台、皮料柜、配件与成品架 |

## MOCK-S13-12 · 沿院作业棚

- 分类：**可配置配套**。功能：遮蔽条件下的开放作业、搬运与短期暂存。
- 固定空间：棚下作业面、搬运面、暂存架，不封闭主通道。
- 形体：默认 **沿院**；可选独立／沿院。
- 用途配置：默认 **货物分拣**；货物分拣=分拣台、分类筐与待运箱，木料整理=料架与整理台，工具手修=手修台、挂架与零件箱。封闭洁净作业选择作坊，棚内不设置高温设备。
- 材料槽：构架、屋面、饰面。

## MOCK-S13-15 · 园艺种植棚

- 分类：**可配置配套**。功能：沿棚架种植与养护，按主题用于采收或观赏；可独立使用，也可作为庄园或宫殿庭院的内部部件。
- 固定空间：攀援棚架、种植带、养护通路、器具位与采收或修剪暂存位。
- 形体：默认 **沿院棚架**；可选沿院棚架／独立棚架。棚顶为植物攀援面，通路和棚架轮廓保持。
- 主题配置：默认 **葡萄棚**，从下表选一项。主题同时替换植物外观、采收或养护陈设，不必重新选择整个庄园。
- 材料槽：构架、饰面；植物由主题配置控制，不套用阶梯屋面换材。

| 主题 | 主要用途 | 成套变化 |
| --- | --- | --- |
| 葡萄棚 | 葡萄种植、养护与采收 | 葡萄藤叶与果串、采收筐、果实暂存箱 |
| 葫芦棚 | 葫芦种植、养护与采收 | 葫芦藤叶与果实、收获筐、葫芦暂存架 |
| 花藤棚 | 庭院观赏、养护与修剪 | 花藤与花簇、养护器具、修剪收集筐；不保留果实产出用途 |

以上为假结构主题及空间说明，实际植物表达、作物行为与产能需在实物制作时落实。
