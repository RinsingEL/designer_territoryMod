# 功能标签

| 分类文件 | 标签 | 找什么 |
| --- | --- | --- |
| 居住.md | 居住 | 独户、组合、合住 |
| 商业.md | 零售、储存 | 街铺、店宅、摊位 |
| 生产.md | 轻手作、维修、接待、开放作业、暂存 | 作坊、作业棚 |
| 仓储.md | 储存、收发 | 小仓 |
| 公共与旅居.md | 会面、接待、餐饮、住宿 | 小厅、食肆、客栈 |

进入所选风格后按分类读取。同一条目可有多个标签；标签用于检索该原型可配置的空间用途，不代表一个实例同时启用所有用途；最终用途以所选配置为准，也不表示 NPC 或生产行为已实现。客栈的餐宿形体增加餐饮标签，不能由基础住宿用途直接换出厨房。

苗圃、炉火工坊、码头等专用设施和连接构件暂未列为可选假结构；需要时记录缺项及必要空间，不把普通商铺改名替代。
