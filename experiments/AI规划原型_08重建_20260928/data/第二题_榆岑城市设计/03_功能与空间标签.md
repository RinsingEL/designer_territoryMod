# 功能与空间标签素材

参考当前 Structure Studio 的 `function_terms`、`planning_role`、场地说明与设计笔记整理。这里给出可组合的语义素材，不列结构 ID、尺寸、入口或固定建筑清单。功能词取自现有作者资料；分组和空间关系词是本次归纳，不是新增的程序字段。

| 饮食与生产 | 农田种植、棚架种植、温室种植、菌菇培育、蜂蜜加工、乳品加工、盐鱼加工、烘焙、茶饮、餐饮 |
| 林牧与园艺 | 林务管理、种子保管、种子销售、畜群照护、饲草储存、园艺换盆、花草销售 |
| 手艺与维修 | 工具维修、车辆维修、船舶维修、皮具修补、裁缝、织毡、编织、木器制作、陶器制作、灯具制作、装订 |
| 加工与回收 | 冶炼、矿料转运、宝石加工、晶石加工、玻璃加工、机械拆解、材料回收、旧物研究 |

| 学习与知识 | 教学、自习、阅览、文献保管、档案管理、制图抄录、实验、天文观测、气象观测 |

同一功能可以有多种风格与组织方式，也可以在多个文化圈中出现。这里的“场所”不代表对应机器、交通、魔法或 NPC 服务已实现；具体玩法能力参考独立的模组素材。

## 空间与关系标签

以下从 Studio 的设计说明归纳，供表达生活场景和空间关系，不是固定排布模板。

| 维度 | 标签举例 |
|---|---|
| 空间形态 | 围院、沿街、长厅、拱廊、庭园、露天场地、高低错落、阶地、架空、栈桥、塔楼 |
| 聚落组织 | 住商相邻、院落共享、沿路集聚、公共空间居中、生产生活分区、多点服务、季节驻留 |
| 使用关系 | 客货分流、前店后作、前公众后受控、生产与仓储相邻、接待与补给相邻、学习与实践相邻 |
| 场地联系 | 临水接驳、岸陆分界、沿坡分层、林间留空、遮阴通风、防寒围合、跨高差连接 |
| 规划角色 | 地标、组团组成、日常填充；是本轮描述用词，具体运行时角色以 Studio 原字段为准 |

## 使用方式

T1 用这些词说明“居民做什么、生活空间有什么关系”，不必枚举全部标签。后续讨论城市时，再按城市需求组合功能并解释相邻、分离与联系的理由。选择具体结构留到需要验证资产与场地的阶段。
