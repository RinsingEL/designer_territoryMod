# 第三题 B：逐项设计与阵列验证（待准备）

承接 A 的功能、风格和整体材料方案，由用户与答题 Agent 逐个建筑或建筑组讨论、设计和看图，不要求一次交出整城定稿。

每轮：

1. 选一个待设计需求，讨论空间、合用关系及场地条件。
2. 查询并确认具体结构、形体、入口和尺寸；继承整体换皮，仅配置局部例外及具体用途内装。
3. 设置位置、朝向；需要阵列时，在执行前确认池成员、数量与参数。
4. 调用实现仓同一份布局／阵列算法，编译并查看本轮预览。
5. 用户反馈与 Agent 自查分别记录；区分素材不足、设计参数问题和算法问题。调整后重新编译看图，保留旧版。
6. 本项讨论收敛后继续下一项，并复查与已有部分的连接、碰撞和整体效果。

启动前需真实素材及引用、尺寸／入口／地形标注、地形输入和可调用的编译预览入口。所用换皮能力须核实；不支持的配置标记待实现，不伪造效果。

不另写阵列算法替代；保留参数、编译结果、预览和问题证据，逐步判断算法是否满足设计。缺材料或工具出错如实暂停对应步骤。结果仅供实验，不自动写入游戏；居民、容量与动态运行交第四题。
