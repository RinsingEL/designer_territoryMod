# 风格标签素材

参考当前 Structure Studio 作者资料中的 `civilization` 风格标注和设计笔记。下面是视觉与空间表达的素材，不是国家、文化圈或居民种族的分类；功能标签另见 `03_功能与空间标签.md`。

## 现有作者资料中的风格

风格名按 Studio 保留；后两列为对设计笔记的归纳，不要求照单全选。

| 风格标签 | 材料与视觉词 | 形态与空间词 |
|---|---|---|
| 蒸汽朋克 | 砖石、铜、深色金属、玻璃、铆接感 | 挑高大厅、拱肋、钟塔、装卸院 |
| 地中海 | 浅色墙面、橙陶屋面、蓝绿檐口、帆布 | 拱廊、庭院、遮阴、水岸平台 |
| 沙漠 | 赭色、厚墙、织物、连续屋面 | 围院、深门楼、遮阴廊、风塔 |
| 矮人 | 厚重石构、金属构件、矿业器械意象 | 低重心体量、作业前场、独立货运空间 |
| 精灵 | 木构、树体、根盘、自然形态 | 林间住宅、生活空间与植被交织 |
| 空艇幻想 | 柱梁、石墩、缆索、系留桅杆 | 高架泊台、上下分层、步梯接驳、理货廊 |
| 魔法学院 | 学院式建筑、晶石与仪式符号 | 庭院、窄翼、高厅、露天仪式空间、公共与研究空间分区 |
| 游牧 | 暖白毡面、橙赭织带、深木、粗石 | 大帐、圆形帐居、露天石阵、营地 |
| 北欧 | 木构、船舶意象、桩桥 | 高跨长厅、低侧翼、临水作业面 |
| 海洋幻想 | 浅色壳肋、青绿表面、贝壳形拱顶 | 放射或分瓣空间、水陆分区、潮门、滨水平台 |
| 哥特 | 浅石、彩窗、尖拱、扶壁 | 高挑主空间、低翼、庭院、纪念空间 |
| 废土拾荒 | 旧机梁、齿轴、氧化铜、浅木、布棚、补丁 | 旧骨架再利用、后加生活空间、修补痕迹 |

“矮人”“精灵”等是当前素材的风格名称，不强制居民种族；哥特也不必对应亡灵或墓城。任何风格都可以承载普通家庭、饮食、手艺和公共生活。

## Studio 已列出的候选方向

以下出现在风格清单中，尚未建模，作为创作候选单独列出：

| 风格标签 | 可用联想 |
|---|---|
| 中式 | 院落、街巷、门廊、院墙、园林 |
| 日式 | 町屋、木构、庭园、临街生活 |
| 欧洲中世纪 | 木构与石构、街巷、工匠生活、公共集会空间 |

候选联想是创作提示，不是已有资产清单。可以混合或提出其他风格，也可以让多个国家共享风格，再通过历史、工艺、生活习惯和地方环境形成差异。
