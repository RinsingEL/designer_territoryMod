# 作答循环

1. 读城市设定，整理功能需求及其依据；事实不足时查前题交接。
2. 读风格索引，确定主风格、辅助表达及各自作用。需要了解可选建筑类型时，再按功能查假池，不遍读全池。
3. 提出功能合用／分开关系及整体换皮方案，保存 v01。不要求具体编号、形体、单栋用途内装或局部材料配置。
4. 自查：需求有无遗漏或重复？风格是否被误当种族／行业？整体换皮是否仅作用于兼容槽？是否提前锁定无依据的建筑数量或布局？
5. 有问题就回查材料并另存修订版；每轮区分自查与用户反馈，不编造外部评价。
6. 交付最终方案及待讨论项，停下讨论。收到反馈可在本次目录继续；B 的逐项设计另行启动。

允许读本目录、假池、指定前题材料及自己的本次结果；可用文件工具，不调用网络、游戏或外围代码。池外功能可以提出并标记待补素材。人口、尺寸和场地未知时不虚构精确数量或落位。
