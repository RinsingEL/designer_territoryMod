# T1｜文化圈与国度设计

## 世界概述

这是一片海路串联、内陆被丘岭与谷地分隔的世界，冷暖和干湿带横穿陆块，并不服从南北纬度。居民靠农作、手艺、航行与远征维持生活，机械和魔法都能进入普通家庭。早年的跨海迁居留下共享的营造传统，各国又因地形与生活选择形成地方变化。城市是村落、工场和荒野之间的服务节点，玩家既可旅行求学，也可安家生产。

下列文化、国家、生计与社会习惯均为创作设定；分布栏的地形、冷暖及干湿依据本次 W 图粗读，群系只采用 W04 的推断性质。建筑材料是设计选材与供给需求，不代表当地已有资源。共设五个文化圈、十一个国度，分布描述不构成正式国界。

## 必要补充

### 会影响城市设计的关系

| 关系 | 对空间与玩家体验的影响 |
|---|---|
| 跨海文化联系 | 萨维拉、贝莱萨、梅里萨共享接待和岸上作业传统，哈尔维与之通婚、交换手艺；各地需要能接纳外来船具、饮食和建材样品的公共空间。它们构成旅行目的地网络，尚不等于已有安全航线或自动船班。 |
| C6 内部协作 | 萨维拉提供海上接待，奥伦侧重加工维修，斯凯恩侧重冷带日常生活与行旅整备；这是城市服务的侧重差异，各地仍保留基础厨房、修补和建材获取，避免玩家为每件日用品跨国奔波。 |
| C82 与 C56 的地方交换 | 纳希尔与榆岑可交换织物、器皿、食材和庭园作品；贝莱萨与塔希兰之间可设置短住和转交活动空间。往来线路及供货数量不预定，人口和产量也不由气候图推算。 |
| 工匠传统的两种组织 | 奥伦偏向可现场观看的师徒作业，维伦偏向收件、库存与规格档案；前者需要示范面与安全观看空间，后者需要清晰的受理前场和设备后场。相同技术可在两国使用。 |
| 未纳入国度的地区 | C134、C157 暂作地方社群与后续旅行留白，C6、C82、C76 等陆块内部也保留无明确国属的荒野；不要求每个编号都有国家，不给未扫描区域补画疆域。 |
